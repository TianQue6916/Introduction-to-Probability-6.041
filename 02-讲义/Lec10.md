### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Review（复习：从离散到连续的词典）</span>

**阅读（Readings）**：教材 Section 3.6；开始 Section 4.1。

**复习（Review）**——第 2 章的离散机器与第 3 章的连续机器逐行对应（左：离散，右：连续）：

| 离散 | 连续 |
|:---:|:---:|
| $p_X(x)$ | $f_X(x)$ |
| $p_{X,Y}(x,y)$ | $f_{X,Y}(x,y)$ |
| $p_{X|Y}(x \mid y) = \dfrac{p_{X,Y}(x,y)}{p_Y(y)}$ | $f_{X|Y}(x \mid y) = \dfrac{f_{X,Y}(x,y)}{f_Y(y)}$ |
| $p_X(x) = \displaystyle\sum_y p_{X,Y}(x,y)$ | $f_X(x) = \displaystyle\int_{-\infty}^{\infty} f_{X,Y}(x,y)\, dy$ |

无论离散连续都通用的两件工具：$F_X(x) = P(X \le x)$，以及 $\mathrm{E}[X]$、$\mathrm{var}(X)$。

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.165–167；§3.6, p.179–182</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 这一页的词典不是为了换记号，而是在回答一个可判定的问题：概率 $P$ 是原始对象，PMF（probability mass function，分布列，即离散随机变量在各取值点上的概率）与 PDF（probability density function，概率密度函数，即单位长度上摊开的概率质量）只是把同一个 $P$ 编码进两类空间的两套坐标卡；而 CDF（cumulative distribution function，累积分布函数，即 $F_X(x) = P(X \le x)$）与 $\mathrm{E}[X]$、$\mathrm{var}(X)$ 只读 $P$ 本身，所以它们一行都不用改。
>
> 为什么必须换编码，因果链是这样的：离散空间的单个点可以携带正质量，于是"每点多少概率"这张表能把 $P$ 完全编码；一旦连续化，任何单点的概率都退化掉，整张表变成处处为零，加起来是 0 而不是 1，信息全丢。还没被压成零的量只剩下"一个区间里装了多少概率"，而区间概率除以区间长度、再让长度趋于零，极限就是密度 $\frac{dF_X}{dx}$。编码既然从点质量换成了单位长度上的质量，汇总方式就必须从求和换成积分：求和是在数点，积分是在量长度，两者做的是同一件事——把不需要的那个自由度汇掉。反过来同样会失败：把离散变量的分布列当密度去积分，因为单点集的长度为零，只会积出 0，总质量凭空消失。
>
> 量纲能把这件事钉死：若 $X$ 以小时计，$f_X$ 的单位是每小时的倒数，$f_X(2) = 0.3$ 读作"2 小时附近，每 1 小时宽度上摊着 0.3 的概率"，所以 $P(2 \le X \le 2.1) \approx 0.3 \times 0.1 = 0.03$；而 $\mathrm{E}[X]$ 的单位仍是小时，这正是"期望不必改"的量纲证据。密度值大于 1 也毫不违规，因为它不是概率。
>
> 拿几何对指数来逐行翻译：geometric（几何分布）$p_K(k) = (1-p)^k p$ 数的是"第几次才成功"，exponential（指数分布）$f_T(t) = \lambda e^{-\lambda t}$ 量的是"要等多久"，二者都靠无记忆性活着。取 $p = 0.2$，$P(K \ge 3) = 0.8^3 = 0.512$，量级是"过半的等待不少于 3 次"；取 $\lambda = 2$（以小时计），$P(T > 1.5) = e^{-3} \approx 0.0498$，量级是"只有 5% 的等待超过 1.5 小时"。同一句"等待无记忆"，一边写成乘法 $(1-p)^n$，一边写成指数 $e^{-\lambda t}$，就是求和到积分的活标本：$T$ 超过一个整数小时的倍率固定为 $e^{-\lambda}$，与已经等了多久无关。
>
> 跨课程连接有两处。其一是 Strang 的 18.065：difference matrix（差分矩阵）是把导数离散化的算子矩阵，网格加密时它逼近微分算子；这里的选择与此同源——离散世界的求和与差分，在加密的极限下变成积分与求导，区别在于差分矩阵研究的是函数的光滑性，而求和换积分处理的是总量恒为 1 的概率如何重新分摊。其二是 CSAPP 第 2 章的 floating point（浮点）表示：可表示数在数轴上并不均匀，ulp（unit in the last place，末位单位）随指数翻倍而翻倍，$|x|$ 每翻一倍，单位长度上的可表示点数就减半——这与"密度是单位长度上的量"完全同构，区别是浮点密度属于确定性的表示能力，不归一成 1，也不该归一。
>
> 所以带走一句话：只问累计概率或平均值时，直接用 CDF 与期望公式，一个积分都不用重新学；只有要问"某点附近有多密"时才换密度，换的时候盯住被汇掉的是点质量还是长度质量。本讲后面四种贝叶斯变体、以及导出分布的两步走，全部踩在这条判据上。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The Bayes variations（贝叶斯法则的种种变体）</span>

离散情形的贝叶斯法则（乘法公式代换分子）：
```math
p_{X|Y}(x \mid y) = \frac{p_{X,Y}(x,y)}{p_Y(y)} = \frac{p_X(x)\, p_{Y|X}(y \mid x)}{p_Y(y)}, \qquad p_Y(y) = \sum_x p_X(x)\, p_{Y|X}(y \mid x).
```
**例**：$X \in \{1, 0\}$——天空中有/没有飞机；$Y \in \{1, 0\}$——雷达上有没有记录到点什么。

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.165–167</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证）:**</span> 这条注要钉死的是：贝叶斯法则不是新公理，而是同一张联合分布表的两种切法被逼平的结果，所以它能被验算、也必须被验算。
>
> 机制只有一行乘法公式：$p_{X,Y}(x,y) = p_X(x)\, p_{Y|X}(y \mid x)$ 说的是"先定 $X$、再在 $X$ 条件下定 $Y$"，$p_Y(y)\, p_{X|Y}(x \mid y)$ 说的是"先定 $Y$、再倒推 $X$"；两者描述的都是同一张二维表上的同一格，因此恒等，把 $p_Y(y)$ 除过去就是贝叶斯法则。分母的角色是归一化：未归一化的分子 $\tilde p(x) = p_X(x) p_{Y|X}(y \mid x)$ 把所有 $x$ 加起来恰好等于 $p_Y(y)$，除掉它之后各项和为 1，才能当作新的先验进入下一轮。忘了除会怎样？质量表还是那张表，但和不为 1，下一次迭代就变成"每轮凭空缩放一次"，几轮之后数值溢出或下溢。工程里同一件事叫 logits 与 softmax：logits 是未归一化的后验，softmax 只是把分母补上。
>
> 赔率形式比差分式更耐用：$\frac{p_{X|Y}(1 \mid 1)}{p_{X|Y}(0 \mid 1)} = \frac{p_X(1)}{p_X(0)} \cdot \frac{p_{Y|X}(1 \mid 1)}{p_{Y|X}(1 \mid 0)}$，即后验赔率等于先验赔率乘似然比。代入先验 $0.05$、灵敏度 $0.99$、误报率 $0.10$：先验赔率 $0.05/0.95 \approx 0.0526$，似然比 $0.99/0.10 = 9.9$，后验赔率 $0.521$，换回概率 $0.521/1.521 \approx 0.343$，与直接算一致。这个乘法读法解释了三成这个反直觉数字：9.9 倍的证据很强，但 1 比 19 的先验太悬殊，乘完仍然只有一半对一半略多。把先验换成 $0.5$，同样的 $9.9$ 倍似然比立刻给出后验 $0.908$——证据没变，变的是先验。
>
> 赔率形式还顺手回答了"多看几次能不能救回弱先验"：若两次报警在给定 $X$ 的条件下独立，后验赔率就是先验赔率乘两个似然比，$0.0526 \times 9.9^2 \approx 5.16$，概率升到 $0.838$；三次是 $51.0$，概率 $0.981$。串行更新一次乘一个因子，与一次乘完完全等价——这条等价性只在"条件于 $X$ 独立"时成立，误把它当成无条件独立是最常见的误用，因为两次误报往往同源（同一只鸟、同一片杂波），此时乘性叠加会把证据重复计数。
>
> 反过来做设计题：要让后验达到 0.9，先验至少要多高？解 $0.99p / (0.99p + 0.1(1-p)) \ge 0.9$，即 $0.99p \ge 0.09 + 0.801p$，得 $p \ge 0.476$。也就是说，在误报率 10% 的量级下，无论证据多强，先验低于四成七就摸不到 90% 的后验——这个数字是选雷达参数时的硬约束，不是修辞。
>
> 历史值得记一句，因为它解释了为什么这条公式叫 Bayes：Thomas Bayes 的《An Essay towards solving a Problem in the Doctrine of Chances》是他 1761 年去世后由 Richard Price 整理、1763 年送到皇家学会的，处理的是二项分布参数反推这一特例；一般形式的条件概率版本由 Laplace 1774 年的回忆录独立给出。所以"贝叶斯法则"是后来的追认，不是 1763 年就有的完整定理。
>
> 跨课程连接：CSAPP 第 4 章的 branch prediction（分支预测）是这条公式的定性工程版——预测器维护历史统计（先验）并叠加本次分支的局部历史（证据）来更新信念，但它只比较两个候选的相对大小，从不做除法，因为判决只需要赔率，不需要概率；这就是"只为比较就可以省掉分母"的活例子。区别在于预测器输出的是硬判决而非概率，更新用的是饱和计数器而非乘性重加权，而且它的先验是硬件写死的初值。收束一句：贝叶斯法则的可验算之处在分母，可用之处在赔率。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Continuous counterpart（连续的对应版本）</span>

```math
f_{X|Y}(x \mid y) = \frac{f_{X,Y}(x,y)}{f_Y(y)} = \frac{f_X(x)\, f_{Y|X}(y \mid x)}{f_Y(y)}, \qquad f_Y(y) = \int_x f_X(x)\, f_{Y|X}(y \mid x)\, dx .
```
**例**：$X$：某个信号，"先验" $f_X(x)$；$Y$：$X$ 的含噪版本（noisy version）；$f_{Y|X}(y \mid x)$：噪声模型。

> <span style="color:#7f8c8d;">Bertsekas §3.6, p.179–181</span>

**例**：$X$：离散信号，"先验" $p_X(x)$；$Y$：$X$ 的含噪版本；$f_{Y|X}(y \mid x)$：连续噪声模型。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Continuous X, Discrete Y（连续 X、离散 Y）</span>

```math
f_{X|Y}(x \mid y) = \frac{f_X(x)\, p_{Y|X}(y \mid x)}{p_Y(y)}, \qquad p_Y(y) = \int_x f_X(x)\, p_{Y|X}(y \mid x)\, dx .
```
**例**：$X$：连续信号（如光束的 intensity（强度）），"先验" $f_X(x)$；$Y$：受 $X$ 影响的离散随机变量（如 photon count（光子计数））；$p_{Y|X}(y \mid x)$：该离散随机变量的模型。

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.169–172</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> mixed case（两种混合情形，即 $X$ 与 $Y$ 一个离散一个连续、既不是纯离散也不是纯连续的搭配）唯一会翻车的地方是"求和还是积分"，而判据只有一条：被边缘化掉的那个变量是离散的，就求和；是连续的，就积分。
>
> 为什么判据必须长这样：边缘化是"沿着不需要的坐标把质量汇总起来"，可汇总的方式取决于该坐标上质量的计量方式。离散变量把质量堆在可数个点上，每个点携带一个正数，所以汇总就是逐个相加；连续变量在任何单点上的质量为零，只有长度区间里才有正质量，所以汇总必须是对长度的积分。两种搞反各有确定的失败模式：对连续 $X$ 用求和，你要在不可数个点上逐个取 $f_X(x_k)$，实际能取到的有限个点贡献为零，结果恒等于零，整条曲线被抹平；对离散 $X$ 用积分，$\int p_X(x) \cdots dx$ 是在零长度的点集上积分，同样得零，全部质量凭空消失。所以"点概率乘密度"并不违和，它只是"一个离散因子配一个连续因子"，量纲由分母统一掉。
>
> 例甲（离散 $X$、连续 $Y$）：$p_X(1) = 0.3$，$p_X(0) = 0.7$；$Y$ 在 $X = 1$ 时服从 $U[0,1]$，在 $X = 0$ 时服从 $U[2,3]$，两段支撑不重叠。混合密度是 $f_Y(y) = 0.3$ 当 $0 \le y \le 1$，$f_Y(y) = 0.7$ 当 $2 \le y \le 3$，其余为零，积分 $0.3 + 0.7 = 1$ 自检通过。后验拿来检验：观测到 $y = 0.5$，$p_{X|Y}(1 \mid 0.5) = 0.3 \times 1 / 0.3 = 1$，因为 $0.5$ 落在只有 $X = 1$ 才能产生的那一段上，一次观测就把先验 0.3 顶到 1；观测到 $y = 2.5$，后验是 0，对称。真正的卡点在 $1 < y < 2$ 这段：那里 $f_Y(y) = 0$，后验的公式给 $0/0$，无定义。这不是公式写坏了，而是"条件化在一个密度为零的点上"本身需要另立规矩（回到 CDF 的差商取极限），混合情形里这种空档常常被忽略。
>
> mixture（混合密度，即若干概率密度按非负权重相加）之所以叫混合而不是平均，是因为权重之和为 1、每项各自非负，所以积分仍是 1，它自己就是一个合法密度；这也带来一个可嵌套的性质——把几个混合密度再混一次，还是混合密度，只是权重变成复合权重，所以"先按设备混合、再按场景混合"这类两层模型不必重新推导。若分量从有限个变成可数个，写法从加法变级数，收敛性就是唯一新增的要求；再进一步，若权重本身来自一个连续先验，就回到例乙那条积分式，两种情形在此处接上。
>
> 例乙（连续 $X$、离散 $Y$）：把归一化的光束强度取 $X \sim U[0,1]$，给定 $X = x$ 时"至少收到一个光子"这个指示变量 $Y \sim \mathrm{Bernoulli}(x)$。分母是 $p_Y(1) = \int_0^1 x\, dx = 0.5$，于是 $f_{X|Y}(x \mid 1) = x / 0.5 = 2x$（$0 \le x \le 1$），积分 $1$ 自检通过。读法：观测到"有光子"之后，强度后验从平坦变成向右抬升的线性密度，$P(X > 0.5 \mid Y = 1) = \int_{0.5}^{1} 2x\, dx = 0.75$，比先验的 $0.5$ 高出 25 个百分点——一次二值观测就把分布推歪了这么多，这正是光子计数实验里"看到一个计数就敢说光源不暗"的定量版本。
>
> 跨课程连接：CSAPP 第 6 章 cache 的地址拆分恰好是同一套算法。32 位地址被切成 tag、set index、block offset，cache 只保留 set index 这个离散坐标，offset 那 6 位被"汇掉"——在硬件假设 block 内 64 字节等可能出现时，汇掉它就是 64 个等权项相加再归一，形式上是求和；若把 offset 当连续量处理，同样的汇掉就写成积分。区别在于 cache 的均匀假设是设计前提，不是从数据里估出来的先验，所以它永远是求和而不是积分。收束一句：先看被消掉的是点还是长度，再决定写 $\sum$ 还是 $\int$，两个混合公式都不用背。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">What is a derived distribution（什么是导出分布）</span>

- 它是"一个或多个具有已知概率规律的随机变量的函数"的 PMF 或 PDF。例如下图：

> <span style="color:#7f8c8d;">图：单位正方形上的均匀联合密度 $f_{X,Y}(y,x) = 1$（横轴 $x$、纵轴 $y$）；"求 $g(X,Y) = Y/X$ 的 PDF"就是一次导出分布计算（下一讲完整求解）。</span>

- 求出 $g(X,Y) = Y/X$ 的 PDF，就涉及 deriving a distribution（导出一个分布）。
- 注意：$g(X,Y)$ 本身是一个随机变量。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.202</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 导出分布的第一性原理只有一句：随机变量的函数仍是随机变量，它的分布不是被"算"出来的，而是被 $g$ 从原空间"搬"过来的——原来在平面上哪块区域有多少质量，搬完之后在 $z$ 轴上就在对应的位置有多少质量。
>
> 把这句话展开成可操作的因果链：$(X,Y)$ 落在小方块 $dA$ 里的概率是 $f_{X,Y}(x,y)\, dA$，$g$ 把方块整块挪到 $z = g(x,y)$ 附近的某个位置上，密度就是"单位 $z$ 长度上累积了多少被搬来的方块"。于是任何关于 $Z$ 的概率都写成同一个积分：$P(Z \in B) = P((X,Y) \in g^{-1}(B))$，会算右边这个二重积分，就会算一切导出分布；下一讲的公式、卷积、$\max$ 与 $\min$ 的分布，全是这一句的特例。
>
> 为什么标准做法是"先求 CDF、再求导"，而不是直接猜密度？因为 CDF 只依赖概率本身，$F_Z(z) = P(Z \le z)$ 对任何 $g$ 都良定义，不需要 $Z$ 有密度；而密度要求 $F_Z$ 在该点可微。顺序反了就会凭空造出不存在的密度。举一个会让直接法失效的例子：$X \sim U[0,1]$，$Z = \min(X, 0.5)$——在 $x \ge 0.5$ 那一整段上 $g$ 是常数，于是 $P(Z = 0.5) = P(X \ge 0.5) = 0.5$，一半的质量被压成一个原子，$F_Z$ 在 $0.5$ 处跳了 0.5。此时 $Z$ 没有密度，只有"密度加一个点质量"的混合描述；若一上来就假设 $f_Z$ 存在，会得到一条积分不等于 1 的曲线，还找不到错在哪。
>
> 用本页那个会切出两种几何形状的函数把数算实：单位正方形上 $f_{X,Y} = 1$，$Z = Y/X$。当 $0 \le z \le 1$，区域 $y \le zx$ 是一个底为 1、高为 $z$ 的三角形，$F_Z(z) = z/2$；当 $z \ge 1$，区域 $y \le zx$ 是整个正方形挖掉左上角三角形 $y > zx$，后者的面积是 $\int_0^{1/z} (1 - zx)\, dx = 1/(2z)$，所以 $F_Z(z) = 1 - 1/(2z)$。取两个数核对：$F_Z(0.5) = 0.25$，$F_Z(2) = 1 - 0.25 = 0.75$，在 $z = 1$ 处两段都给出 $0.5$，拼得上。求导得 $f_Z(z) = 1/2$（$0 < z < 1$）与 $f_Z(z) = 1/(2z^2)$（$z > 1$），积分 $0.5 + 0.5 = 1$ 自检通过。
>
> 还有一个反方向的示范：有些期望根本不必先求分布。设 $X$、$Y$ 独立同分布且连续为正，令 $W = X/(X+Y)$，则 $1 - W = Y/(X+Y)$ 与 $W$ 同分布（交换两个字母，联合分布不变），于是 $\mathrm{E}[W] = 1 - \mathrm{E}[W]$，得 $\mathrm{E}[W] = 1/2$，一个积分都没算。这条对称性论证正是下一页"何时不必求出导出分布"的前奏：分布难求而期望好求时，绕开分布是正解，不是偷懒。
>
> 这个例子真正的教训在尾部：$P(Z > 1000) = 1/(2 \cdot 1000) = 0.0005$ 看着很小，但 $\mathrm{E}[Z] = \int_1^\infty z \cdot \frac{1}{2z^2}\, dz = \int_1^\infty \frac{dz}{2z}$ 是对数发散，期望根本不存在。也就是说"平均每个点的斜率"这件事没有意义，尽管每条射线上斜率都有限；直接用 $\iint (y/x)\, dx\, dy$ 算也会在 $x = 0$ 一带同样发散，两条路一致地告诉你：重尾不是计算失误，是模型性质。凡是打算用样本均值估计 $Y/X$ 的场合，这一条先看。
>
> 跨课程连接：CLRS 的随机化快排里，pivot 的位置是 $U \sim U[0,1]$ 经 $\lceil nU \rceil$ 映到 $\{1,\dots,n\}$，导出分布是离散均匀 $1/n$——$n = 10$ 时 $P(\text{rank} = 1) = P(U \le 0.1) = 0.1$，因为映射把长度为 $0.1$ 的区间整段压成一个点，质量直接堆上去。对比之下 $Y/X$ 只在每条射线上取常值，射线是一维集合、面积为零，所以它不会产生点质量，只改密度。区别就在这里：分片常数的映射产出 PMF，连续映射产出 PDF，而两者都服从同一条搬运规则。收束一句：导出分布不是新工具，是把"求区域面积"换个坐标系再做一遍。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">When not to find them（何时不必求出导出分布）</span>

- 若只想计算期望，就不需要 $g(X,Y)$ 的 PDF：
```math
\mathrm{E}[g(X,Y)] = \iint g(x,y)\, f_{X,Y}(x,y)\, dx\, dy .
```

> <span style="color:#7f8c8d;">Bertsekas §3.4, p.161–164</span>

---

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">How to find them（如何求导出分布：离散情形）</span>

- 对 $Y = g(X)$ 的每个可能取值求出概率质量：
```math
p_Y(y) = P(g(X) = y) = \sum_{x:\, g(x)=y} p_X(x) .
```

> <span style="color:#7f8c8d;">图：每个 $x$ 经函数 $g$ 映到 $y$ 轴上的对应点；若干个 $x$ 挤进同一个 $y$ 时，把它们的概率质量相加、堆到该点。</span>

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.213–215</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The continuous case（连续情形）</span>

**两步走（two-step procedure）**：
- 先求 $Y$ 的 CDF：$F_Y(y) = P(Y \le y)$；
- 再求导：$f_Y(y) = \dfrac{dF_Y}{dy}(y)$。

**例**：$X$ 在 $[0, 2]$ 上 uniform（均匀）分布，求 $Y = X^3$ 的 PDF。
- 解：
```math
F_Y(y) = P(Y \le y) = P(X^3 \le y) = P(X \le y^{1/3}) = \frac{y^{1/3}}{2},
```
```math
f_Y(y) = \frac{dF_Y}{dy}(y) = \frac{1}{6\, y^{2/3}} .
```

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.211–213</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证）:**</span> 两步走之所以是"两步"而不是"一个公式"，根子在合法性：你手上只有 $X$ 的分布，任何关于 $Y$ 的概率都必须先翻译成关于 $X$ 的事件，才谈得上用 $f_X$ 去积。
>
> 翻译的合法性条件是单调性。写成式子：$F_Y(y) = P(g(X) \le y) = P(X \in g^{-1}((-\infty, y]))$，这一步是定义而非技巧——$Y$ 的分布本来就是 $X$ 的分布被 $g$ 推过去的像。当 $g$ 严格递增时，$g^{-1}$ 把区间还成区间，事件变成 $X \le y^{1/3}$ 这样可以直接查 CDF 的形状；当 $g$ 不单调，$g^{-1}$ 会分裂成好几段，必须逐段相加，这就是本注要补的机制。
>
> 求导为什么一定成立：$F_Y = F_X \circ g^{-1}$，链式法则给 $f_Y(y) = f_X(x) \cdot |(g^{-1})'(y)|$，而反函数求导说 $(g^{-1})'(y) = 1/g'(x)$，代入即得 $f_Y(y) = f_X(x) / |g'(x)|$。也就是说，下一讲那条"一般公式"这里已经推完了：它不是新定理，是两步走的副产品，两端各自乘上"长度伸缩因子"而已。绝对值出现的原因，与 $Y = aX + b$ 那一注同源——递减分支上区间反了向，导数带负号，而密度不能为负。
>
> 把数算实：$X \sim U[0, 2]$，$Y = X^3$，$F_Y(y) = y^{1/3}/2$（$0 \le y \le 8$），$f_Y(y) = \frac{1}{6} y^{-2/3}$。三个点核一遍：$F_Y(0.125) = 0.25$、$F_Y(1) = 0.5$、$F_Y(3.375) = 0.75$，对应的 $x$ 是 $0.5$、$1$、$1.5$，正是 $X$ 的三分位，端点 $y = 8$ 对应 $x = 2$。中位数是 $1$，也就是说一半的质量落在 $y \le 1$。均值走两条路对照：走导出密度 $\int_0^8 y \cdot \frac{1}{6} y^{-2/3}\, dy = \frac{1}{8} \cdot 8^{4/3} = 2$；走期望值规则 $\int_0^2 x^3 \cdot \frac{1}{2}\, dx = 2$，完全一致——这是"不求出分布也能算期望"的第一次实证。
>
> 定义域是这条链上最容易被省掉的一环，而它有可检测的症状：把 $F_Y(y) = y^{1/3}/2$ 不加截断地用到 $y = 27$，会得到 $1.5$，一个超过 1 的"概率"，立刻暴露矛盾；正确写法必须在 $y > 8$ 时把 $F_Y$ 钉在 $1$、密度归零。密度在 $y \to 0$ 时爆表也不算违规，判据是可积性：$\int_0^{0.001} \frac{1}{6} y^{-2/3}\, dy = 0.05$ 是有限数，而若换成 $y^{-1}$ 就会对数发散——"无界"和"不可积"是两件事，$Y = X^3$ 属于前者。
>
> 非单调会怎样，必须亲手拆一次：取 $Y = X^2$，$X \sim U[-1, 1]$。此时"$X^2 \le y$"等价于"$-\sqrt{y} \le X \le \sqrt{y}$"，是两段拼起来的区间，于是 $F_Y(y) = \sqrt{y}$，$f_Y(y) = \frac{1}{2\sqrt{y}}$，在 $y = 0.01$ 处密度等于 $5$，在 $y = 0.25$ 处等于 $1$——零点附近密度无界。如果硬套单调公式、只用正分支，算出的总质量只有一半，这正是"必须按分支拆开"的实证；负分支与正分支在这里不仅贡献相同，而且重合成一条 $\sqrt{y}$，所以结果比两个分支各算一遍再相加更简单，但那属于巧合，不能当方法。
>
> 跨课程连接：CSAPP 第 2 章的 floating point（浮点）表示给了一个平行的读法。取对数看伸缩率，$\ln y = 3\ln x$ 意味着 $dy/y = 3\,dx/x$：立方把相对误差放大三倍，用 ulp（unit in the last place，末位单位）的语言说，输入每差一个末位单位，输出在相对量上差三个末位单位，等价于损失 $\log_2 3 \approx 1.58$ 个有效 bit。这也解释了为什么 $|g'|$ 在 $x = 0.1$ 处只有 $0.03$，密度就在那一带爆起来：映射把长度压扁了 $33$ 倍，同样的 $x$ 长度能装下 $33$ 倍的质量。区别在于浮点分析把映射看成确定性截断，导出分布处理的是随机质量的搬运，但"看局部伸缩率"这个动作是同一个。收束一句：单调时一行等价改写，不单调时按分支拆开再相加，两条路都由 $|g'|$ 记账；写完务必回头检查 $F_Y$ 在两个端点是否分别贴着 $0$ 和 $1$，以及密度积分是否回到 $1$，这两项检查能拦下绝大多数漏定义域的错误。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Example（例：波士顿到纽约的车程）</span>

- Joan 从 Boston 开车去 New York，车速在 30–60 mph 之间均匀分布。行程时间（duration of the trip）的分布是什么？
- 令 $T(V) = \dfrac{200}{V}$，求 $f_T(t)$。

> <span style="color:#7f8c8d;">图：$V$ 的 PDF——在 $[30, 60]$ 上高度恒为 $1/30$ 的均匀密度，横轴标注 $30$ 与 $60$。</span>

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.211–213</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 卡点诊断）:**</span> 这道题只有一个真卡点：$T = 200/V$ 是递减映射，事件的像要翻方向，支撑集要跟着映射走，其余全是积分。
>
> 机制先捋清：$F_T(t) = P(T \le t) = P(200/V \le t)$，两边都是正数，取倒数会翻不等号，所以它等于 $P(V \ge 200/t)$。翻错的后果不是"结果略有偏差"，而是结构性崩塌：若写成 $P(V \le 200/t) = \frac{200/t - 30}{30}$，那么在 $t = 10/3$（对应最快的 $V = 60$）处给出 $1$，在 $t = 20/3$（对应 $V = 30$）处给出 $0$——一个随 $t$ 递减的"累积分布"，违反 $F$ 必须单调不减，一眼就能判死。这条自检（写完先看单调性）比任何记忆都可靠。
>
> 支撑集也从映射来，不是照抄：$30 \le V \le 60$ 经 $t = 200/v$ 变成 $10/3 \le t \le 20/3$，即约 $3.33$ 到 $6.67$ 小时。区间内 $F_T(t) = \int_{200/t}^{60} \frac{1}{30}\, dv = 2 - \frac{20}{3t}$，求导得 $f_T(t) = \frac{20}{3t^2}$；区间长度 $10/3$ 小时、密度从 $t = 3.33$ 处的 $0.6$ 单调降到 $t = 6.67$ 处的 $0.15$，积分 $\frac{20}{3}\left(\frac{3}{10} - \frac{3}{20}\right) = 1$ 自检通过。顺便算一个概率：$P(T \le 4) = 2 - 20/12 \approx 0.333$，只有三分之一的机会四小时内到；中位数由 $2 - \frac{20}{3t} = 0.5$ 解得 $t = 40/9 \approx 4.44$ 小时。
>
> 真正值得停下来看的是期望的两条路为什么不一样。走期望值规则：$\mathrm{E}[T] = \int_{30}^{60} \frac{200}{v} \cdot \frac{1}{30}\, dv = \frac{20}{3} \ln 2 \approx 4.621$ 小时；走导出密度：$\int t\, f_T(t)\, dt = \frac{20}{3}\ln\frac{20/3}{10/3} = \frac{20}{3}\ln 2$，两条路一致（说明分布算对了）。但若偷懒用"距离除以平均速度"，得到 $200/45 = 4.444$ 小时，比真值少了 $0.177$ 小时，约 10.6 分钟。差额不是舍入，是 Jensen 不等式：$v \mapsto 1/v$ 在正半轴上是凸的，所以 $\mathrm{E}[1/V] \ge 1/\mathrm{E}[V]$，等号只在 $V$ 为常数时成立。把车速区间放宽到 $[10, 60]$ 会看得更狠：平均速度 $35$、$200/35 = 5.714$，而真值 $\mathrm{E}[T] = 4\ln 6 \approx 7.167$，差 $1.45$ 小时——分布越散，平均速度这个"点估计"越不可信。
>
> 密度形状能给出额外的判读：两端密度之比是 $0.6/0.15 = 4$，恰好等于 $(20/3)^2 / (10/3)^2$，也就是 $1/t^2$ 的直接后果——慢车那一段虽然只占速度范围的另一半，却在时间轴上被拉长了同样的倍数，所以"落在后半程"的概率远大于一半。数一数就知道：$P(T > 5) = 1 - F_T(5) = 20/15 - 1 \approx 0.333$，只有三分之一的车程慢于五小时，三分之二在五小时内抵达。
>
> 中位数 $40/9$ 恰好等于 $200/\mathrm{E}[V]$ 这件事要当巧合处理：因为 $V$ 是均匀的，$1/v$ 的积分恰好给出对数，而中线正好落在对数中点上。换成三角分布或截断正态，两个数立刻分家，所以别把它当恒等式记。
>
> 顺带看一眼下界为什么必须有：若把 $V$ 换成允许趋近于零的分布（例如指数分布），$\mathrm{E}[T] = \mathrm{E}[200/V]$ 在 $v \to 0$ 处对数发散，期望当场不存在——与上一页 $Y/X$ 的重尾是同一个病灶，只是从二维退化成一维。
>
> 跨课程连接：CSAPP 第 11 章的 socket 编程与 TCP 栈里，把文件大小固定为 $200$ MB、带宽记作 $V$ 时，传输时间同样是 $T = 200/V$，"拿平均吞吐算平均下载时间"犯的正是上面这个错，而且方向永远偏乐观。区别有两处：其一，TCP 里的带宽估计是滑动平均给出的点估计，本身就在随时间漂移，没有"固定的 $V$ 分布"可言，所以严格地说连这个反比映射的前提都不满足；其二，网络里的 $V$ 会自适应（拥塞窗口一变，$V$ 就变），而本课程这道题把 $V$ 的分布当成外生给定，两者是"开环"与"闭环"的差别。收束一句：反比映射只多一条规矩——不等号翻转、端点重映射，剩下的交给积分；而"平均的反比不等于反比的平均"这条，工程上要单独记一笔。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The pdf of Y = aX + b（线性函数 Y = aX + b 的 PDF）</span>

$Y = 2X + 5$：

> <span style="color:#7f8c8d;">图：三张 PDF 的对比——$f_X$、经缩放得到的 $f_{aX}$（横轴拉伸、高度压低）、再平移得到的 $f_{aX+b}$（整体右移）；横轴标注 $-2$、$3$ 等端点随"拉伸 $\times 2$、右移 $5$"而移动。</span>

```math
f_Y(y) = \frac{1}{|a|}\, f_X\!\left(\frac{y - b}{a}\right).
```
- 用它检验：若 $X$ 是 normal（正态）随机变量，则 $Y = aX + b$ 也是正态。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.202；§3.3, p.154</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 跨课程连接）:**</span> 那条公式里唯一需要解释的不是 $f_X$，而是前面的系数：$1/|a|$ 是面积守恒的记账，不是约定俗成的装饰。
>
> 先把推导走完，两分支分开写才看得见绝对值从哪来。$a > 0$ 时 $F_Y(y) = P(aX + b \le y) = P(X \le (y-b)/a) = F_X((y-b)/a)$，求导得 $f_Y(y) = \frac{1}{a} f_X\left(\frac{y-b}{a}\right)$，系数是正的。$a < 0$ 时不等号翻转，$F_Y(y) = P(X \ge (y-b)/a) = 1 - F_X((y-b)/a)$，求导得 $-\frac{1}{a} f_X\left(\frac{y-b}{a}\right)$；因为此时 $a$ 为负，$-\frac{1}{a}$ 本身就是正数，并且等于 $\frac{1}{|a|}$。两支合流，绝对值就是这么来的——它不是为了避免符号错误而硬加的，是"递减分支贡献了一个负号"这件事的代数痕迹。
>
> 漏掉绝对值会怎样，有立刻可见的症状：取 $X \sim N(0,1)$、$Y = -2X + 5$，若写成 $\frac{1}{a} f_X(\cdots)$，系数是 $-0.5$，密度在整条轴上取负值，而密度的积分变成 $-1$，一张"负概率"的表。这就是为什么公式里必须带绝对值，且 $a = 0$ 要单独排除：此时 $Y$ 退化成常数，没有密度，只有一个点质量。
>
> 量纲与几何各给一句：$f_X$ 的单位是每单位 $x$ 的倒数，$x$ 轴被拉长 $|a|$ 倍之后，同一份质量摊在 $|a|$ 倍长的区间上，密度必须相应变稀 $|a|$ 倍；平移不改变长度，所以 $b$ 不进系数，只进 $f_X$ 的自变量。看图和看式子给同一结论：先横向拉伸 $|a|$ 倍、再整体右移 $b$，拉伸把峰压矮 $|a|$ 倍，平移只挪位置不改高度。
>
> 数值核对三次。第一，$X \sim N(0,1)$、$Y = 2X + 5$：代入并配方，$f_Y(y) = \frac{1}{2\sqrt{2\pi}} \exp\left(-\frac{(y-5)^2}{8}\right)$，正是 $N(5, 4)$ 的密度，标准差为 $2$。取概率：$P(Y \le 3) = \Phi(-1) \approx 0.1587$，另一条路 $P(X \le -1)$ 给同一个数，两条路必须一致，这是最省事的自检。第二，换成 $Y = -2X + 5$，方差仍是 $4$，$P(Y \le 3) = P(X \ge 1) \approx 0.1587$，对称性把符号问题遮住了，所以光靠这个算例发现不了绝对值缺失，必须另设检查。第三，均匀分布：$X \sim U[0,1]$、$Y = 2X + 5$ 得 $U[5,7]$，密度 $1/2$、均值 $6$、方差 $4 \times \frac{1}{12} = \frac{1}{3}$，区间长度从 $1$ 变 $2$、密度从 $1$ 变 $1/2$，面积仍是 $1$。
>
> 正态为什么能"穿越"线性变换而不变形：把 $x = (y-b)/a$ 代进 $-\frac{(x-\mu)^2}{2\sigma^2}$，指数变成 $-\frac{(y - b - a\mu)^2}{2a^2\sigma^2}$，前面的归一化常数 $1/(\sqrt{2\pi}\sigma)$ 再乘 $1/|a|$，恰好合成 $1/(\sqrt{2\pi}|a|\sigma)$，与 $N(a\mu + b,\ a^2\sigma^2)$ 的标准形式一字不差。这是"族封闭"的一个例子：两次线性变换的复合仍是线性变换，参数按 $a\mu + b$ 与 $a^2\sigma^2$ 更新，所以可以反复套。
>
> 跨课程连接：Strang 的线性代数语言里，$x \mapsto ax + b$ 是一个 affine（仿射）映射（线性部分加平移），而 $1/|a|$ 就是 Jacobian（雅可比行列式）的一维特例——一维的"行列式"就是那个数本身，取绝对值是因为密度不能为负。历史的账可以顺一下：函数行列式最早出现在 Cauchy 1815 年的工作里，Jacobi 在 1841 年于 Crelle 杂志上系统处理并证明"行列式恒为零当且仅当函数相关"，名字是更晚才固定下来的。区别在于：一维只需一个伸缩因子，$n$ 维需要整个 $|\det J|$，因为不同方向可以被拉伸不同的倍数，只有行列式能把它们折成一个数；而若映射不单调（雅可比在某处为零或变号），一维的"翻转"就升级为"折叠"，必须像 $Y = X^2$ 那样按分支拆开。收束一句：$Y = aX + b$ 这一页是全讲最短的一页，却已经把导出分布的全部零件——伸缩因子、绝对值、边界排除——摆齐了。
