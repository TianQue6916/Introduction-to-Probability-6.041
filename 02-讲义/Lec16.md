> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 教材第 7 章开篇（p.340）先给了一句话定位：Bernoulli 过程与 Poisson 过程是 memoryless（无记忆）的——未来与过去无关；而本章考虑的是**有记忆**的过程，只不过把"记忆"压缩到一个 state（状态）里：给定当前状态，未来与更早的历史无关。这是本讲一切内容的总纲。
>
> 大纲四块恰好是四个台阶：先用具象的收银台队列示范"怎么把一个系统装进状态里"；再给 Markov chain（马尔可夫链）的正式定义（p.340–341 的转移概率与马尔可夫性质）；然后用 n-step transition probabilities（$n$ 步转移概率）回答"从 $i$ 出发 $n$ 步后在 $j$ 的概率"（p.345 的 Chapman-Kolmogorov 递归）；最后用 classification of states（状态分类）建立 recurrent（常返）与 transient（暂态）的语言（§7.2 从 p.346 起）。
>
> 先把"压缩"这个词拆开，因为它是全章的赌注。问题是这样：一个系统的未来通常依赖它的全部过去，若照实建模，状态空间会随历史长度指数膨胀。能不能用一个有限集合上的当前取值，替代整条历史？答案的边界由分布决定：geometric（几何分布）与 exponential（指数分布）是仅有的两个满足 memoryless（无记忆）性的分布，所以到达间隔服从 geometric（几何分布）的过程里，"已经等了多久"不携带任何关于"还要等多久"的信息，历史可以被直接丢掉。算一下：设到达概率 $p = 0.2$，间隔 $T$ 服从 geometric（几何分布），则 $P(T > 5) = 0.8^5 \approx 0.328$，而给定 $T > 5$ 之后 $P(T > 10 \mid T > 5) = 0.8^5 \approx 0.328$——两个数一字不差。队列就不同：$X_n = 3$ 与 $X_n = 0$ 给出的下一步分布完全不同，历史必须留痕。
>
> 但留痕不必留全部。这正是 state（状态）承担的角色：它是历史的一个函数，功能上等价于一个 sufficient statistic（充分统计量）——把长历史映射成短对象，而在"预测下一步"这件事上零损失。写成式子就是 $P(X_{n+1} = j \mid X_n, X_{n-1}, \ldots, X_0) = P(X_{n+1} = j \mid X_n)$，左边条件里有整条历史，右边只剩一个符号。压缩之所以可能，是因为系统内部的机制本身把冗余吃掉了，不是因为数学上凑巧。
>
> 这笔压缩是可以用数字定价的。设状态数 $m$，若未来依赖最近 $k$ 步（$k$ 阶链），自由参数有 $m^k (m-1)$ 个（每行和为 1 吃掉一个自由度）；一阶链只要 $m(m-1)$ 个。取 $m = 3$、$k = 10$：一阶是 $3 \times 2 = 6$ 个，十阶是 $3^{10} \times 2 = 118098$ 个，差两万倍。这不是审美问题，是样本量问题：要把每个参数估到 $\pm 0.05$ 的精度，每个参数大约需要 400 次观测，一阶链要 2400 次转移，十阶链要 $4.7 \times 10^7$ 次；按每秒一次转移算，后者要 545 天。所谓马尔可夫假设，就是把"赌未来只经由现在依赖过去"这句话折算成能省下的观测次数。
>
> 跨课程连接：6.042J（离散数学）里的 finite state machine（有限状态自动机），转移函数 $\delta(\text{state}, \text{symbol})$ 只看当前状态与当前输入、不看历史，那正是确定版的马尔可夫性质；区别有两条——自动机的输入来自外部环境而转移是确定的，马尔可夫链没有外部输入、随机性内生，$p_{ij}$ 顶替了 $\delta$；而且自动机要求状态数有限是为了可判定性，链要求有限是为了让转移矩阵可写。CSAPP 第 8 章的 context（上下文）是同一思想的硬件实现：内核切换进程时只保存程序计数器、寄存器与栈指针，因为此后程序的行为由这份快照决定，而不是由它此前执行过的每一条指令决定。
>
> 与前几讲的关系也顺带对齐：到达过程研究的是"到达流"，这里研究的是"带记忆的系统状态轨线"，样本空间从单个时刻上的随机变量换成整条时间轴上的样本路径，但条件化、全概率、独立性这些工具一件都没换。讲义标题写 Markov Processes（马尔可夫过程），教材与后续两讲限定在 discrete time（离散时间）、finite state（有限状态）的 Markov chain（马尔可夫链）上——先在最干净的情形里把语言建好，再去一般化。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Checkout counter model（收银台模型）</span>

- 离散时间 $n = 0, 1, \ldots$
- 顾客到达：Bernoulli($p$)（伯努利过程）——到达间隔为 geometric（几何分布）。
- 顾客服务时长：geometric($q$)（参数 $q$ 的几何分布）。
- "State"（状态）$X_n$：时刻 $n$ 的顾客数（number of customers at time $n$）。

> <span style="color:#7f8c8d;">图：收银台前的队列示意——格子 $0, 1, 2, 3, \ldots, 9, 10$ 标出队列中可能出现的顾客数（容量上限 10）。</span>

转移结构的直觉：每一步有两个独立的伯努利事件——"新顾客到达"（概率 $p$）与"队首顾客服务完成"（队列非空时概率 $q$）。于是队列非空、未满时：到达且未完成则 $X_{n+1} = X_n + 1$，无到达且完成则 $X_{n+1} = X_n - 1$，其余情形 $X_{n+1} = X_n$。

> <span style="color:#7f8c8d;">Bertsekas §7.1, p.341–345（Examples 7.1–7.3 的建模范式）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 跨课程连接）:**</span> 这个模型示范了马尔可夫建模的**三步配方**：先挑 state（状态，这里取 queue length（队列长度）——它恰好是对未来有影响的全部历史信息的压缩：顾客几点来、服务了多久都无所谓）；再定可能的 transition（转移，长度至多 $\pm 1$）；最后填转移概率（由 $p$、$q$ 两个 Bernoulli（伯努利）参数复合而成）。
>
> 第一步才是真功夫，值得单独追问一句：凭什么队列长度就够？答案不在队列本身，而在服务时间的分布。模型规定每个 slot（时隙）里，只要队列非空，队首顾客就以概率 $q$ 完成服务——这是 geometric（几何分布）的服务时间，同样 memoryless（无记忆）。正因为无记忆，"这位顾客已经服务了几个 slot"不携带任何额外信息，长度才成为足够的摘要。反例用来钉死这一点：若服务时间固定为 3 个 slot，则知道队列长度是 4 也无法决定下一步，你必须另外记住队首还剩几个 slot 没服务完，state（状态）被迫膨胀成二元组（长度，剩余时间）。所以马尔可夫建模的第一课不是"挑一个看起来像状态的量"，而是"验证这个量是否把该留的信息全留了、该扔的全扔了"。
>
> 到达侧与上一讲的字典对接：每 slot 以概率 $p$ 到达的 Bernoulli arrivals（伯努利到达），其到达间隔正是 geometric（几何分布，教材 §6.1, p.299–300），所以"离散时间到达流"在两章之间无缝换轨，不需要重新定义任何东西。
>
> 现在把它算成具体的数。取 $p = 0.3$、$q = 0.5$、容量上限 10。队列既非空又未满时，两个独立事件组合出三种结局：只到达不完成则涨一格，概率 $p(1-q) = 0.15$；只完成不到达则掉一格，概率 $(1-p)q = 0.35$；两个都发生或都不发生都停在原地，合计 $1 - 0.15 - 0.35 = 0.5$。边界要单独写：$0$ 号状态下没人可服务，只有 $0 \to 1$ 的 $0.3$ 与 $0 \to 0$ 的 $0.7$；$10$ 号状态下新来的顾客被拒，只有 $10 \to 9$ 的 $0.35$ 与停留的 $0.65$。整个 transition probability matrix（转移概率矩阵）是 $11 \times 11 = 121$ 个格，但非零元只有 31 个（9 个内部行各 3 个，两个边界行各 2 个），占四分之一——这就是把系统读成稀疏图时该看到的形状。
>
> 从 $0$ 出发手推两步做一次核验：$n=1$ 时分布是 $(0.7, 0.3, 0, \ldots)$，到 $n=2$ 用 Chapman-Kolmogorov 求和得 $P(X_2 = 0) = 0.7 \times 0.7 + 0.3 \times 0.35 = 0.595$、$P(X_2 = 1) = 0.7 \times 0.3 + 0.3 \times 0.5 = 0.36$、$P(X_2 = 2) = 0.3 \times 0.15 = 0.045$，三项相加正好 1，说明没有漏掉任何一条路径。期望长度因此是 $0 \times 0.595 + 1 \times 0.36 + 2 \times 0.045 = 0.45$。
>
> 顺带得到一个漂亮的小恒等式：内部净漂移等于 $p(1-q) - (1-p)q = p - q$，交叉项 $pq$ 恰好抵消，与 $q$ 的大小无关，只由两个参数之差决定。本例 $p - q = -0.2$，队列被往回拉；然而两步后的期望是 $+0.45$ 而不是 $-0.4$——因为 $0$ 号状态是 reflecting（反射）边界，向下的一步被物理地掐掉了。低负载队列之所以不会变负、不会发散，靠的就是这根地板。
>
> 跨课程连接：CSAPP（第 11 章）里 `listen` 的 backlog 就是一个容量有限的等待队列，满了以后新到的 SYN 被丢弃，与本模型 $10$ 号状态的"拒客"逐字对应——区别在于内核丢弃的是连接请求，代价由对端重传承担，而这里只把它从概率里删掉、不追究后果。再挂一条 6.006（算法导论）的线：把这张 $11 \times 11$ 的表读成带权 adjacency list（邻接表），每次转移就是沿一条出边随机游走一步，于是"求 $n$ 步分布"变成"跑 $n$ 步随机游走"，一次转移只碰 3 条边，$n$ 步的代价是 $O(n)$ 次乘法而不是 $O(n m)$。建模的艺术就在这两处：状态空间尽量小，图尽量稀疏。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Finite state Markov chains（有限状态马尔可夫链）</span>

- $X_n$：$n$ 次 transition（转移）之后的状态。
  - 属于一个 finite set（有限集），如 $\{1, \ldots, m\}$。
  - $X_0$ 既可以是给定的，也可以是随机的。
- **Markov property/assumption（马尔可夫性质/假设）**：给定当前状态，过去无关紧要（given current state, the past does not matter）：
```math
p_{ij} = P(X_{n+1} = j \mid X_n = i) = P(X_{n+1} = j \mid X_n = i,\, X_{n-1}, \ldots, X_0) .
```
- **模型规定（model specification）**：
  - 识别可能的 states（状态）。
  - 识别可能的 transitions（转移）。
  - 识别转移概率（transition probabilities）。

> <span style="color:#7f8c8d;">Bertsekas §7.1, p.340–341（转移概率矩阵与转移概率图）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 本页最值得诊断的是马尔可夫性质到底"弱化"了什么。公式 $P(X_{n+1} = j \mid X_n = i, X_{n-1}, \ldots, X_0) = p_{ij}$ 说的是**条件独立**：在给定 $X_n$ 的条件下，$X_{n+1}$ 与更早的历史条件独立。它**不**等于"$X_{n+1}$ 与 $X_0, \ldots, X_{n-1}$ 独立"——事实上 $X_{n+1}$ 与 $X_{n-1}$ 通常就是相依的（比如队列长度两步后大概率更长），只是这层相依必须经过 $X_n$ 中转。
>
> 把这两个"独立"分开看，才知道为什么不能更弱也不能更强。若要求"$X_{n+1}$ 与过去无条件独立"，那么未来连现在都不依赖，模型退化成独立同分布的噪声，链这个概念直接消失；若允许"$X_{n+1}$ 与过去直接相依"而不经过现在，那么任何有限的状态集合都不够用，因为相依的路径可以无限长。条件独立正好卡在中间：它承认"过去有影响"，但规定影响力必须在 $X_n$ 这个关口重新登记一次。
>
> 用数字把它钉死。取二状态链 $p_{11} = 0.6$、$p_{12} = 0.4$、$p_{21} = 0.3$、$p_{22} = 0.7$，从状态 1 出发。先算无条件的一步之后两步落点：$P(X_2 = 2) = 0.6 \times 0.4 + 0.4 \times 0.7 = 0.24 + 0.28 = 0.52$。现在加上条件 $X_1 = 1$：$P(X_2 = 2 \mid X_1 = 1) = 0.4$，从 $0.52$ 掉到 $0.4$，说明 $X_2$ 与 $X_1$ 确实相依。再在 $X_1 = 1$ 之上补一条 $X_0 = 1$：结果仍是 $0.4$，一个数字都没动。这就是马尔可夫性质的全部内容——多加一层历史不改变任何预测。反过来，若这条链不满足马尔可夫性质（例如 $X_2$ 的真实分布依赖 $X_0$ 与 $X_1$ 是否相等），第二个数就会从 $0.4$ 变成别的值，一测就露。
>
> 另一处卡点是 time-homogeneous（时齐）假设：$p_{ij}$ 不随 $n$ 变化，无论状态 $i$ 是第几次被访问、以何种路径被到达，Bertsekas（教材）p.341 的原话是 no matter how state $i$ was reached。这条假设不是装饰：后面 $R(n) = R(n-1)P$ 能被写成矩阵乘法、进而 $R(n) = P^n$，全靠 $P$ 这个矩阵不随时刻变形。一旦允许 $P$ 随 $n$ 变，$n$ 步转移就是 $\prod_{k=0}^{n-1} P_k$，乘积次序不能交换，幂这个记号立刻失效，平稳态理论全部要重写。
>
> 模型规定的三步（状态／转移／概率）在教材 p.341 有标准封装：transition probability matrix（转移概率矩阵，每行和为 1，行对应出发状态、列对应到达状态）与 transition probability graph（转移概率图，节点加带权弧）。同一个模型的两种视图，前者供代数使用（下一页的递归就是矩阵乘法），后者供结构判断使用（本讲末尾的状态分类只看图的可达性，不看数值）。
>
> 跨课程连接：6.042J（离散数学）里的条件独立与 Bayesian network（贝叶斯网络），把 $X_0, X_1, \ldots, X_n$ 按时间顺序画成一张有向无环图，边只连相邻两层，得到的就是一条链状网络；马尔可夫性质恰好是这张图上的 d-separation（有向分离）结论——给定中间节点 $X_n$，两侧被"挡住"，条件独立成立。区别有两处需要记住：链的 state graph（状态图）可以有环（状态 1 可以回到状态 1），但时间展开后的图永远无环，两者不是同一张图，混为一谈就会得出"马尔可夫链不可能是无环的"这种错话；另外贝叶斯网络的节点是随机变量、边表示直接的因果或统计依赖，而状态图的节点是状态取值、边表示一步之内可以到达。
>
> 再挂一条 CSAPP（第 4 章）的线：流水线里的两位饱和计数器寄存器（2-bit saturating counter）只有四个取值，下一次预测只看当前这个两位状态，不看更早的跳转历史——这就是一条四状态马尔可夫链被做进了硬件；区别在于它的转移由真实的分支结果驱动，是外生的，而这里 $p_{ij}$ 是模型内在的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">n-step transition probabilities（n 步转移概率）</span>

- 给定初始状态 $i$ 的状态占据概率（state occupancy probabilities）：
```math
r_{ij}(n) = P(X_n = j \mid X_0 = i) .
```

> <span style="color:#7f8c8d;">图：三段时刻轴 Time 0 → Time $n-1$ → Time $n$——从 $i$ 出发经 $n-1$ 步以概率 $r_{i1}(n-1), \ldots, r_{ik}(n-1), \ldots, r_{im}(n-1)$ 落到各个中间状态 $k$，再各以 $p_{1j}, \ldots, p_{kj}, \ldots, p_{mj}$ 走到 $j$（对应教材 Fig. 7.5）。</span>

- **关键递归（key recursion，Chapman-Kolmogorov 方程）**：
```math
r_{ij}(n) = \sum_{k=1}^{m} r_{ik}(n-1)\, p_{kj} .
```
- 初始状态随机时：
```math
P(X_n = j) = \sum_{i=1}^{m} P(X_0 = i)\, r_{ij}(n) .
```

> <span style="color:#7f8c8d;">Bertsekas §7.1, p.345（Fig. 7.5）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 跨课程连接）:**</span> 递归的推导只有两行，却是全讲的引擎：先用全概率定理按第 $n-1$ 步的位置拆分 $P(X_n = j \mid X_0 = i) = \sum_k P(X_{n-1} = k \mid X_0 = i)\, P(X_n = j \mid X_{n-1} = k, X_0 = i)$，再用马尔可夫性质把最后一个因子削成 $p_{kj}$（教材 p.345 的验证正是这两步）。
>
> 第一行成立的唯一理由是事件 $\{X_{n-1} = k\}$ 对 $k$ 求和构成一个**划分**：链在第 $n-1$ 步必定恰好站在某一个状态上，既不重叠也不遗漏，所以把各自的贡献加起来等于总数。这一步与状态数、与时间都无关，是纯粹的计数事实。第二行才是马尔可夫的用处——若没有它，最后那个条件概率还带着 $X_0 = i$，$n$ 步转移就无法用一步的数据表达，只能老老实实枚举全部历史路径。
>
> 迭代下去就是矩阵乘法。把 $r_{ij}(n)$ 排成 $R(n)$，递归左边是第 $i$ 行第 $j$ 列，右边是对 $k$ 求和 $r_{ik}(n-1) p_{kj}$——这正是"前一个矩阵的第 $i$ 行乘以后一个矩阵第 $j$ 列"的定义式，所以 $R(n) = R(n-1)\,P$，层层剥到 $R(0) = I$，得 $R(n) = P^n$。矩阵乘法在这里不是记号上的方便，它和"对中间状态求和"是同一个运算的两种写法。第二式 $P(X_n = j) = \sum_i P(X_0 = i)\, r_{ij}(n)$ 则是把初始的不确定性再作一次全概率展开，读成矩阵就是行向量 $\pi_0 P^n$。
>
> 顺带一个不变量：$R(n)$ 的每一行仍然是一个概率分布，和恒为 1。原因是行随机矩阵对乘法封闭——乘积的第 $i$ 行是 $P$ 若干行按 $r_{ik}(n-1)$ 的正权重叠加，而每一行自带和 1，加权后仍是 1。这条不变量给了一道免费的错误检测：任何一步算出的行和不为 1，就说明递推里抄错了某一项，不必等到最后才发现（注 5 正是用它逐格验算）。
>
> 算一个能落地的例子。取 $P = \begin{pmatrix} 0.8 & 0.2 \ 0.5 & 0.5 \end{pmatrix}$，它有两个特征值：$1$（因为每行和为 1，全 1 向量是右特征向量）与 $0.8 + 0.5 - 1 = 0.3$（二阶方阵的迹等于特征值之和，$1.3 - 1 = 0.3$）。按左右特征向量展开得 $P^n = \begin{pmatrix} 5/7 & 2/7 \ 5/7 & 2/7 \end{pmatrix} + 0.3^n \begin{pmatrix} 2/7 & -2/7 \ -5/7 & 5/7 \end{pmatrix}$。代 $n = 10$ 验证量级：$0.3^{10} \approx 5.90 \times 10^{-6}$，修正项乘上 $2/7$ 只有 $1.7 \times 10^{-6}$，因此 $r_{11}(10) = 0.714286 \pm 0.000002$，与极限 $5/7$ 在六位小数上已经分不开。再看衰减速度：$0.3^n$ 的半衰期是 $\ln 0.5 / \ln 0.3 \approx 0.58$ 步，每过半大步误差就打对折。这两个数合起来回答了一个实用问题——"要迭代多少步才够"，答案是"由第二大特征值的模决定，模越小越快"。
>
> 跨课程连接：Strang（线性代数）把 $P$ 看成分布空间上的线性算子，行和为 1 保证它把概率单纯形映到自身（不会把总质量变大或变小），特征值 $1$ 对应不变的方向，其余特征值的模都不超过 1；链的长期行为就是"$1$ 那一项留下、其余项按 $|\lambda|^n$ 衰减"。区别必须点明：$P$ 一般**不是对称矩阵**，所以 Strang 里那套正交对角化不直接可用，必须左右两套特征向量配对（左边求平稳分布、右边求全 1），本例中 $0.3^n$ 那一项的系数矩阵就是由这一对拼出来的。再挂一条 CLRS（算法导论）的线：既然 $R(n) = P^n$，算 $n$ 步分布就退化成矩阵快速幂，代价 $O(m^3 \log n)$；取 $m = 1000$、$n = 10^6$，逐步递推要 $10^{15}$ 次乘法，快速幂只要 $20 \times 10^9$，差五万倍。两条公式请分开记：固定起点用递归逐行推，随机起点左乘初始分布一次性推整行。

> <span style="color:#7f8c8d;">Bertsekas §7.1, p.345（Fig. 7.6 同型链的 $n$ 步迭代行为）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证）:**</span> 逐格验算。$n = 0$：从 $i$ 出发仍在 $i$，得 $(r_{11}, r_{12}, r_{21}, r_{22}) = (1, 0, 0, 1)$；$n = 1$：直接读一步转移概率 $(0.8, 0.2, 0.5, 0.5)$。$n = 2$ 用关键递归：$r_{11}(2) = 0.8 \times 0.8 + 0.2 \times 0.5 = 0.74$，$r_{12}(2) = 0.8 \times 0.2 + 0.2 \times 0.5 = 0.26$，$r_{21}(2) = 0.5 \times 0.8 + 0.5 \times 0.5 = 0.65$，$r_{22}(2) = 0.5 \times 0.2 + 0.5 \times 0.5 = 0.35$。
>
> 每格都要过一次归一检查：$0.74 + 0.26 = 1$、$0.65 + 0.35 = 1$。这不是形式主义——转移矩阵的幂每一行仍然必须是概率分布（行随机矩阵对乘法封闭），所以只要某一步两元素之和不是 1，就一定是递归抄错了行：要么乘错了列，要么漏掉了某条中间路径。手算时这一步比复核公式便宜得多。
>
> 递归的拆分方向也值得看一眼：为什么不按首步 $X_1$ 拆、而要按末步 $X_{n-1}$ 拆。因为马尔可夫性质只承诺"再走一步"的分布，多步概率唯一的剥离方式是"剩下 $n-1$ 步"配上"最后一格的一步"，反复剥到零，这就是对 $n$ 的归纳。按首步拆同样能算，但得到的是从左边乘 $P$ 的版本，与条件"从 $i$ 出发"的书写顺序相反，稍不留神就会在转置上翻车，而末步版本与"行向量右乘"的读数天然对齐。
>
> $n = 100$ 与 $n = 101$ 的格子都填 $(5/7, 2/7, 5/7, 2/7)$，理由分两层。第一层是代数的：设 $r_i(n) \to \pi$，在递归 $r_i(n) = r_i(n-1)P$ 两边取极限，左右两端收敛到同一处，于是 $\pi = \pi P$——极限必须是不动点。写成方程：$\pi_1 = 0.8\pi_1 + 0.5\pi_2$ 给出 $0.2\pi_1 = 0.5\pi_2$，即 $\pi_1 = 2.5\,\pi_2$，连同 $\pi_1 + \pi_2 = 1$ 解得 $\pi_1 = 5/7 \approx 0.7143$、$\pi_2 = 2/7 \approx 0.2857$。这一步不是"猜出极限再验证"，而是"假设极限存在，它就只能是这个"。
>
> 第二层是数值的，也是本题最值得记住的地方：为什么 $n = 100$ 与 $n = 101$ 一模一样，而不只是"很接近"。$0.3^{n}$ 衰减得快：$0.3^{10} \approx 5.9 \times 10^{-6}$，$0.3^{20} \approx 3.5 \times 10^{-11}$，到 $0.3^{33}$ 已经是 $10^{-17}$ 量级，比双精度浮点的相对分辨率 $2.2 \times 10^{-16}$ 还小。也就是说从 $n \approx 33$ 起，$5/7$ 与真实值在 64 位浮点里就是同一个比特串，再迭代 70 次也不会改动任何一个字。这张表的最后两格其实在说：收敛不是形容词，可以换算成"多少次迭代之后计算机看不出来"。
>
> 还有一条能直接手算的观察，把"两行同极限"从口号变成数字：两行之差 $\Delta(n) = r_{11}(n) - r_{21}(n)$ 每步被同一个因子乘一次。$\Delta(0) = 1$，$\Delta(1) = 0.8 - 0.5 = 0.3$，$\Delta(2) = 0.74 - 0.65 = 0.09 = 0.3^2$，正好按 $0.3^n$ 收缩，而 $0.3$ 就是上一注算出的第二大特征值。差值趋于零，两行才被迫收敛到同一个极限；收缩因子小于 1，收敛才必然发生。反向的极端情形可以直接看穿：若取 $p_{11} = p_{22} = 1$（两个吸收态），差值恒为 1 永不缩小，链就停在原地，谈不上收敛到公共分布。
>
> 顺手做一个敏感性检查，看答案有多依赖参数：只把 $p_{22}$ 从 $0.5$ 改成 $0.4$（$p_{21}$ 相应变成 $0.6$），方程变成 $0.2\pi_1 = 0.6\pi_2$，解出 $\pi = (0.75, 0.25)$；同时第二大特征值从 $0.3$ 掉到 $0.2$，收敛更快。参数动 $0.1$，极限动 $0.036$，收敛速度却提升一半——"链的形状"和"链的速度"是两件可以分开读的事。
>
> 跨课程连接：CSAPP 第 2 章讲过 $0.3$ 在二进制里存不下精确值，机器里存的是 $0.299999999999999988897769753748$，每次乘法都带一点误差；本例照样收敛得干净，是因为每轮都把上一轮的误差乘上 $0.3$ 再叠加，误差本身就是一条收缩的几何级数，总误差不超过单次舍入误差的 $1/(1-0.3) \approx 1.43$ 倍——这是一个用浮点分析的视角就能读出来的稳定性结论。再挂一条 CLRS 的线：把递归写成程序，每步是一次矩阵向量乘，$m$ 个状态要 $m^2$ 次乘法，迭代 $n$ 步是 $O(n m^2)$；本例 $m = 2$ 手算两行就够，而真实系统 $m$ 上万时，这就是能不能在几秒内跑完的问题。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Generic convergence questions（一般性的收敛问题）</span>

- $r_{ij}(n)$ 会收敛到什么吗？
> <span style="color:#7f8c8d;">图（周期反例）：周期 2 的链——从状态 2 出发各以 $0.5$ 进入状态 1 或 3，而 1、3 下一步以概率 $1$ 返回 2；从 2 出发每逢偶数步回到 2、奇数步离开 2。填空：$n$ 奇时 $r_{22}(n) = \underline{\qquad}$；$n$ 偶时 $r_{22}(n) = \underline{\qquad}$。</span>
- 极限依赖于初始状态吗？
> <span style="color:#7f8c8d;">图（初态依赖反例）：苍蝇与蜘蛛链（教材 Example 7.2 取 $m = 4$）——状态 1、4 为蜘蛛（吸收态，自环概率 $1$）；苍蝇在 2、3 处各以 $0.3$ 左移/右移、$0.4$ 原地不动。填空：$r_{11}(n) = \underline{\qquad}$，$r_{31}(n) = \underline{\qquad}$，$r_{21}(n) = \underline{\qquad}$。</span>

> <span style="color:#7f8c8d;">Bertsekas §7.3, p.352（周期类不收敛的论述）；§7.1, p.345（Fig. 7.7：极限依赖初态）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 卡点诊断）:**</span> 上图验算：从状态 2 出发，奇数步必在 1 或 3（$r_{22}(n) = 0$，$n$ 奇），偶数步必回到 2（$r_{22}(n) = 1$，$n$ 偶）——序列 $1, 0, 1, 0, \ldots$ 永不收敛。教材 p.352 用两状态版（$p_{12} = p_{21} = 1$）给出同样的诊断：recurrent class（常返类）是 periodic（周期的），$r_{ij}(n)$ 一般会振荡。
>
> 机制在于这个链的每一条回路都是偶数长度，所以 $n$ 的奇偶决定了你在哪一半里；把转移矩阵自乘两次恰好得回单位阵，$P^2 = I$，于是 $P^{2k} = I$、$P^{2k+1} = P$，两条子序列各自稳定，合起来永远在两点之间跳。这不是数值算不准，是结构上不可能收敛：极限要求整条序列最终落进任意给定的 $\epsilon$ 邻域，而每隔一步它就跳出去一个固定距离。若要修复，只需让状态 2 有一个正概率的自环（停留），奇偶分界立刻被打散，序列就会收敛。
>
> 下图验算：$r_{11}(n) = 1$ 对一切 $n \ge 1$（蜘蛛 1 是吸收态，进去出不来），$r_{41}(n) \to 0$（从 4 出发永远到不了 1）。真正要算的是 $r_{21}(n)$ 与 $r_{31}(n)$ 的极限，即"被蜘蛛 1 抓住"的概率，用 first-step analysis（首步分析）解方程：$h_2 = 0.3 \cdot 1 + 0.4 h_2 + 0.3 h_3$，$h_3 = 0.3 h_2 + 0.4 h_3$。由第二式 $0.6 h_3 = 0.3 h_2$，得 $h_3 = h_2 / 2$；代回第一式 $h_2 = 0.3 + 0.4 h_2 + 0.15 h_2$，即 $0.45 h_2 = 0.3$，得 $h_2 = 2/3$、$h_3 = 1/3$。故 $r_{21}(n) \to 2/3$、$r_{31}(n) \to 1/3$。
>
> 首步分析为什么合法，值得拆开：对第一步的落点作全概率分解，$h_i = \sum_j p_{ij} h_j$，其中 $h_j$ 是"从 $j$ 出发最终被 1 抓住"的概率；再用马尔可夫性质，把"从 $i$ 走一步到 $j$ 之后的历史"与"从 $j$ 重新开始"视为同一个随机过程，这一步才让方程闭合。边界条件由吸收态直接给出，$h_1 = 1$、$h_4 = 0$，方程组的个数等于未知数的个数，解唯一。这套"把概率写成自洽的线性方程组再解"的手法，比直接算 $n$ 步极限省事得多——它连极限存在与否都不需要预先知道。
>
> 同一套方程换个右端项就能回答另一个问题：期望被抓住的时间。设 $t_2$、$t_3$ 为从各状态出发到吸收的期望步数，则 $t_2 = 1 + 0.4 t_2 + 0.3 t_3$、$t_3 = 1 + 0.4 t_3 + 0.3 t_2$，解得 $t_2 = t_3 = 10/3 \approx 3.33$ 步。一个概率、一个期望，出自同一张系数矩阵，只是常数项不同——这是马尔可夫链里最省力的一类复用。
>
> 结论：这条链确实收敛，但极限**依赖初始状态**（从 4 出发永远到不了 1）。两幅反例分别击破两个想当然：周期性击破"一定会收敛"，多常返类击破"收敛就与初态无关"。下一讲将证明只要"单一常返类 + 非周期"同时成立，两条同时修复。
>
> 跨课程连接：6.042J（离散数学）里的 bipartite graph（二分图）——周期为 2 的状态图恰好就是二分图，因为二分图等价于"不存在奇数长度的环"，而周期 2 正是"所有回路长度都被 2 整除"。区别在于：一般状态图的 period（周期）是所有回路长度的最大公约数，可以是 $3$、$4$ 等任意值，二分只是 $d = 2$ 的特例，所以二分图直觉只在二状态互跳这种最简情形里好用。再挂一条 CLRS（算法导论）的线：首步分析给出的是一组 $m$ 元线性方程，高斯消元要 $O(m^3)$，$m$ 上万时不可行，实际做法是 value iteration（值迭代）——从任意初值出发反复套首步方程，收敛速度由同一批特征值控制，与上一注算的 $0.3^n$ 是同一件事。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Recurrent and transient states（常返态与暂态）</span>

- 状态 $i$ 是 recurrent（常返）的，如果：从 $i$ 出发，且从你能到达的任何地方出发，都存在一条回到 $i$ 的路。
- 若非常返，则称为 transient（暂态）。
  - $i$ 暂态：$P(X_n = i) \to 0$，且 $i$ 只被访问有限次。
- **Recurrent class（常返类）**：彼此 "communicate"（互通）、且不与任何其他状态互通的常返状态之集合。

> <span style="color:#7f8c8d;">图：多状态分类示例链（本讲与下一讲反复使用的同一张图，图中可见状态 $5, 1, 2$ 一行与上方的 $3, 4, 6, 7$、右侧的 $8$）——用于辨认哪些状态互通、哪些常返；各弧上的转移概率数值未随文本保留。</span>

> <span style="color:#7f8c8d;">Bertsekas §7.2, p.346（accessible/recurrent/transient 的定义；Example 7.2 与 Fig. 7.8）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 跨课程连接）:**</span> 定义的关键词是 accessible（可达）：$j$ 从 $i$ 可达，若存在某个 $n$ 使 $r_{ij}(n) > 0$——即图上存在一条从 $i$ 到 $j$ 的有向路径（教材 p.346）。
>
> "常返"的直觉版本是"进了我的势力范围就跑不出去"：从 $i$ 出发能到的所有状态里，每一个都必须能回到 $i$；只要有一个 $j$ 回不来，$i$ 就是暂态。为什么？因为链的随机性保证了只要 $j$ 还能被走到，就迟早会被走到（有限状态上每一步都有正下界），而一旦走进去就再也回不来，于是 $P(X_n = i) \to 0$，$i$ 只被访问有限次。
>
> 把这句"有限次"变成可证明的，用的是**独立重复试验 + 几何分布**这个模板，值得单列：每回一次 $i$，把此后的过程重新起一次头，由于马尔可夫性质它和刚出发时同分布；于是每次回访之后"从此再也不会回来"的概率至少是某个固定的 $\epsilon > 0$。要连续 $k$ 次都成功往返，概率不超过 $(1-\epsilon)^k$，求和有限，所以总回访次数服从参数为 $\epsilon$ 的几何分布，期望次数 $1/\epsilon$ 有限，因而以概率 1 只有有限次。这条论证只用了两件东西：正下界保证 $\epsilon > 0$，强马尔可夫性质保证每趟独立——缺任何一条都不成立。
>
> 算一个具体的数。设状态 3 每步以 $0.8$ 停留、以 $0.2$ 转入一个由状态 1、2 组成的闭环，闭环进不去第三格。则从 3 出发访问 3 的总次数服从几何分布，期望 $1/(1-0.8) = 5$ 次；同时 $P(X_n = 3) = 0.8^n$，$n = 10$ 时只剩 $0.107$，$n = 30$ 时是 $0.0012$——这正是教材 p.346 说的"暂态占据概率趋于零"，也是 $i$ 暂态的标志性现象。状态 1、2 反过来：进去就出不来，回访无限多次，$P(X_n = 1)$ 趋于某个正数而不是零。
>
> 第一性原理推论：常返性把状态切成"封闭势力范围"——若 $i$ 常返，则从 $i$ 可达的状态全部与 $i$ 互通，它们构成一个 recurrent class（常返类），从类内任何状态都到不了类外。顺着这个思路可以证明一条只说一句就成立的定理：**任何有限马尔可夫链至少有一个常返类**。因为它不是空的，取一个状态出发一直走，状态只有有限个，所以必然有某个状态被访问无限多次，而那就是常返的。
>
> 跨课程连接：这套结构在 6.006（算法导论）与 CLRS 第 22 章的有向图里就是 SCC（强连通分量）。把状态图缩点得到 condensation DAG（缩点有向无环图），常返类恰好是其中**没有出边**的那些分量，即 sink component（汇点分量），其余全是暂态；Tarjan 或 Kosaraju 一遍 $O(V + E)$ 就能全部找出来。上面的存在性定理也可以换成图论说法：有限 DAG 必有汇点，所以缩点图必有 sink，常返类不可能缺席。区别有两处要记牢：一是 SCC 只要求"互相可达"，而常返要求"从 $i$ 可达的每个 $j$ 都能回到 $i$"，两者在有限链上等价（若有出边的分量，走出去就回不来，分量内每个点都成了暂态），但在无限状态空间上不等价——一维对称随机游走从 $0$ 出发可以到达任何整数，却仍以概率 1 返回，此时可达与常返必须分开叙述；二是"常返"本身是个概率命题，用回访概率为 1 定义，而 SCC 是纯图论命题，不涉及数值，所以图上先分块、概率上再谈停留时间，顺序不能反。
>
> 最后挂一条 CSAPP 的线：把状态图读成程序的控制流图，sink 分量就是那些"进去了就出不来"的循环体，暂态就是只会执行有限次的前导代码——把"哪些代码必然被执行无穷多次"这个问题翻译成"哪些状态是常返的"，两者是同一个问题换了词汇表。
