> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 本讲的分界线不在"又换了一个应用"，而在问题里的自变量换了：Lec 16–17 的答案是 $\pi_j$ 这类长期比例，它是一个不随步数变化的向量；本讲的答案是首次到达某集合的时刻 $T$ 的分布，它是随起点 $i$ 变化的函数。前者的自由变量是时刻 $n$（再取极限），后者的自由变量是起点 $i$。这个差别不是叙述习惯的问题，混用会算错具体数字。
>
> 先说为什么长期结果不能顶替首次到达结果。$\pi_j$ 的语义是"长期中处在 $j$ 的时间占比"，它把时间顺序完全抹平；而 first passage（首达）关心的是次序，即第一次碰到某集合发生在第几步。一个把顺序抹平的量，当然回答不了关于顺序的问题。拿课堂上的 two-state chain（两状态链）验一遍：$p_{11}=0.5$、$p_{12}=0.5$、$p_{21}=0.2$、$p_{22}=0.8$，平衡方程给出 $\pi_1 = 2/7$、$\pi_2 = 5/7$。如果按"一除以稳态概率"的直觉，从状态 1 到状态 2 的期望步数应该是 $1/\pi_2 = 1.4$ 步。真去解一遍：设 $t_1$ 为从 1 首次到达 2 的期望步数，first-step analysis（首步分解）写成 $t_1 = 1 + 0.5\,t_1$，解得 $t_1 = 2$。两个数差 43%。原因很清楚：$1/\pi_s$ 度量的是"从 $s$ 出发、下一次回到 $s$ 要多久"，它把起点钉死在被考察的那个状态上；一旦起点换成别的状态，那个倒数就不再是首达时间。第 7 条会把这条恒等式的成立范围说清楚。
>
> 这个区别在工程上可以直接换成钱。电话公司问题的数字：呼叫按 Poisson process（泊松过程）到达，速率 $\lambda = 2$ 通每分钟，平均通话时长 $1/\mu = 2$ 分钟，于是 offered load（提供负载）$a = \lambda/\mu = 4$ erlang（爱尔兰，无量纲，等于长期平均占用线路数）。设线路数 $B = 6$，稳态分布正比于 $a^i/i!$，逐项为 $1$、$4$、$8$、$10.667$、$10.667$、$8.533$、$5.689$，七项合计 $48.556$，故 $\pi_6 = 5.689/48.556 = 0.1172$。这个 11.7% 读作"长期中 11.7% 的时刻六条线全忙"。而工程师真正上报的指标是"一通新呼叫被拒的比例"，它也等于 11.7%，靠的是 Poisson arrival（泊松到达）的一条特殊性质：到达者在随机时刻看到的系统状态分布，恰好等于时间平均分布。这条等式是模型送给你的，不是定义里写着的——换一个到达过程就未必成立。本讲先补稳态、再转吸收，正是为了把长期量与事件量分开放，需要相等时再单独证明。
>
> 跨课程连接放在 CSAPP 第 6 章。cache 的 AMAT 等于 hit time 加 miss rate 乘 miss penalty，那是 steady state（稳态）口径的长期平均；可 cold start 之后最先几次 miss 是 compulsory miss，AMAT 一点都预测不出来。连接路径这样走：把 working set（工作集）的驻留情况看成链的状态、把一次 miss 看成离开当前驻留区间，AMAT 立刻变成 $\pi$ 的语言；而"第一个 miss 落在哪个地址、第几个周期到来"变成 first passage（首达）的语言。区别必须说清：cache 没有 absorbing state（吸收态），它永远在 hit 与 miss 之间往复，所以只有长期比例可用；只有当结构里存在"进得去、出不来"的块时，才有本讲 $a_i$、$\mu_i$ 这套方程可解。
>
> 收束一句：本讲四块其实是一个算子的两次特化。把"最后停在哪个吸收态"问成概率，得到 $a_i$；把"停之前走多少步"问成时间，得到 $\mu_i$；把"多久第一次碰到目标态"问成时间，得到 $t_i$。三者共用同一套设备——全概率定理加 Markov property（马氏性）加线性方程组，只是 boundary condition（边界条件）钉的位置不同。带着这个模板意识往下读，后面三条注都是在同一个模板上换零件。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Review（复习：稳态行为）</span>

- 假设链只有**单一常返类**（single recurrent class）且非周期（aperiodic），外加若干暂态（transient）状态，则
```math
\lim_{n \to \infty} r_{ij}(n) = \pi_j ,
```
  其中 $r_{ij}(n) = P(X_n = j \mid X_0 = i)$ 为 **n 步转移概率**（n-step transition probability，即从 $i$ 出发、$n$ 步后落在 $j$ 的概率），$\pi_j$ 不依赖初始条件：
```math
\lim_{n \to \infty} P(X_n = j \mid X_0 = i) = \pi_j .
```
- $\pi_1, \ldots, \pi_m$ 可作为下述平衡方程（balance equations）的**唯一解**求出：
```math
\pi_j = \sum_{k} \pi_k\, p_{kj}, \qquad j = 1, \ldots, m,
```
  再加上归一化条件
```math
\sum_{j} \pi_j = 1 .
```

> <span style="color:#7f8c8d;">Bertsekas §7.3, p.352–353</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断 + 跨课程连接）:**</span> 这四行不是结论摘要，而是一份带前提的合同。前提有两个——单一 recurrent class（常返类）与 aperiodic（非周期）——它们各自失效时，坏的不是同一个地方：前者让解不唯一，后者让极限不存在。把这两种坏法分别造出来看一眼，才知道那两句话为什么必须写。
>
> 先毁掉"单一常返类"。造一个链：状态 1 与 2 互相跳，状态 3 与 4 互相跳，两组之间没有任何一条边。四个状态各成一个常返类。平衡方程变成 $\pi_1=\pi_2$、$\pi_3=\pi_4$，配上归一化 $2\alpha+2\beta=1$，通解是 $(\alpha,\alpha,\beta,\beta)$，任何 $\alpha\in[0,1/2]$ 都满足。方程挑不出唯一的点，而信息其实真的不在方程里：从 1 出发，n-step transition probability（n 步转移概率）的极限是 $(1/2,1/2,0,0)$；从 3 出发是 $(0,0,1/2,1/2)$。初值决定了最后困在哪个类，而平衡方程是一组只看全局结构的静态式子，它看不见初值。所以"单一常返类"这个前提的真正功能，是保证初值携带的信息会随时间被彻底冲刷掉，而不是被永久保存。
>
> 再毁掉"非周期"。二点链 1 与 2 各以概率 1 互相跳，走的是奇偶交替的节拍。$r_{11}(n)$ 在 $n$ 为偶数时等于 1、奇数时等于 0，逐点极限根本不存在。但它的 Cesaro 平均（切萨罗平均，即前 $N$ 项求和再除以 $N$）收敛到 $1/2$。这个对比给出准确的补救办法：要么把"极限"放宽成"平均极限"，要么给每个状态加一点自环把节拍打散。后者在工程上有名字，叫 lazy chain（懒惰链）：以一半概率原地不动，代价是有效样本变少、收敛变慢，换来的是极限存在。
>
> 第二个卡点是 transient（暂态）状态的 $\pi_j=0$。教材只留一句话，机制得自己补。反设某个暂态集合 $T$ 上有正概率永不离开，即 $\Pr(X_n\in T \text{ 对所有 } n)>0$。在这个事件上，过程无穷多次落在有限集 $T$ 内，由鸽巢原理必有某个状态 $k\in T$ 被访问无穷多次；而"在有限状态链里被访问无穷多次"恰好就是 recurrent（常返）的定义，于是 $k$ 常返，与 $T$ 全由暂态组成矛盾。结论是暂态必以概率 1 被离开，离开之后不再回来，质量一次性流走，长期占比只能是 0。
>
> 这个 0 容易和"访问次数为 0"混成一件事，需要用一个可算的例子把两者分开。取链：1 以概率 $1/2$ 留在 1、以概率 $1/2$ 跳到吸收态 3。则 $r_{11}(n)=(1/2)^n$，从 1 出发在状态 1 停留的期望次数是 $\sum_{n\ge 0}(1/2)^n=2$ 次——有限的、正的两步。可 $\pi_1=0$。两个数不矛盾：2 是访问次数，$\pi_1$ 是时间占比，而分母是无穷大，有限的 2 除以无穷大就是 0。这就是为什么读 $\pi_j$ 时只能说"长期中处在 $j$ 的时间比例"，不能说"长期中访问 $j$ 的频率"。
>
> 跨课程连接分两层。第一层用 Strang 线性代数的语言：把 $P$ 写成行随机矩阵（每行和为 1），平衡方程就是 $\pi P=\pi$，$\pi$ 是特征值 1 对应的左特征向量；"行和为 1"保证 $P\mathbf{1}=\mathbf{1}$，所以 1 必然是特征值，全 1 向量是右特征向量。这里有一个必须点明的区别：Strang 讲 Markov matrix（马尔可夫矩阵）时用的是列和为 1 的矩阵 $A$，稳态满足 $A\mathbf{x}=\mathbf{x}$，那个 $\mathbf{x}$ 就是这里的 $\pi$ 的转置。行列方向搞反，稳态照样能解出来但会解成另一个东西，考场上是常见失分点。
>
> 第二层往上走半步，到拓展前沿。把"单一常返类"翻译成矩阵语言就是 $P$ 不可约，把"存在唯一的正稳态"翻译过来就是 Perron–Frobenius theorem（佩龙–弗罗贝尼乌斯定理）在非负矩阵上的结论：非负不可约矩阵必有一个正特征向量对应它的最大特征值，且该特征值的代数重数为 1，特征方向唯一。它同时解释了为什么"不可约"不能省：一旦可约，最大特征值出现重根，特征空间从一条线升成一个多面体，解就从唯一的一点退化成上面那个解族。这条定理你还没在课上见过，但它的内容这页已经全用上了，只是换了个名字。
>
> 收束：这四行的正确读法是"在有限状态、单一常返类、非周期三个前提同时成立时，极限存在、与初值无关、且等于平衡方程的唯一概率解"。三个前提各自失效对应三种不同的补救——放宽成平均极限、把解族配上初值、或者重新划分状态。记住三种坏法，比记住那句极限公式有用。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Example（两状态链示例）</span>

> <span style="color:#7f8c8d;">图：两状态转移图——状态 1 自环 0.5、$1 \to 2$ 为 0.5；状态 2 自环 0.8、$2 \to 1$ 为 0.2。解平衡方程得稳态 $\pi_1 = 2/7$，$\pi_2 = 5/7$。</span>

- 假设过程从状态 1 出发（$X_0 = 1$）。
- **课堂填空**：
  - $P(X_1 = 1,\ \text{且}\ X_{100} = 1) = \underline{\qquad}$
  - $P(X_{100} = 1\ \text{且}\ X_{101} = 2) = \underline{\qquad}$

> <span style="color:#7f8c8d;">Bertsekas §7.3, p.353</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证）:**</span> 这两个空表面上考乘法法则，实际考的是一个判断力：什么时候可以把 $\pi_j$ 当成真实分布来用。判据有两半——被问的那一步离初值够远，以及这条链的谱间隙够大。两半都能量化，不必凭手感。
>
> 先不解近似，直接解出精确公式。转移矩阵的迹是 $0.5+0.8=1.3$，行列式是 $0.4-0.1=0.3$，故两个特征值是 $1$ 与 $0.3$。于是 $r_{11}(n)$ 形如 $A+B\cdot 0.3^n$：$n=0$ 时它等于 1，给 $A+B=1$；$n=1$ 时它等于 $0.5$，给 $A+0.3B=0.5$。相减得 $0.7B=0.5$，即 $B=5/7$、$A=2/7$。所以逐位精确的式子是 $r_{11}(n)=2/7+(5/7)\cdot 0.3^n$。验两个点：$n=1$ 给 $0.2857+0.2143=0.5$，对；$n=2$ 时直接算两步路径得 $0.25+0.10=0.35$，公式给 $0.2857+0.0643=0.350$，也对。有了这个式子，"99 步忘了初值"就不再是一句形容词。顺带记住一个可以口算的事实：二状态链的第二特征值恒等于 $p_{11}+p_{22}-1$，因为两条对角线之和就是矩阵的迹，而其中一个特征值已经确定是 1；所以只要知道两个自环概率，收敛速度立刻到手，不必解特征方程。这条小恒等式在考试里比求根公式快得多。
>
> 把数字代进误差项。$\ln 0.3=-1.20397$，乘 99 得 $-119.2$；再除以 $\ln 10=2.302585$，得 $-51.8$，即 $0.3^{99}\approx 10^{-51.8}$。误差项是 $(5/7)\cdot 10^{-51.8}$。而 double（双精度浮点）只有约 $10^{-16}$ 的相对分辨率，所以这个误差在浮点里根本不存在：$r_{11}(99)$ 与 $2/7$ 在 double 下逐位相同。这就是"99 步足够"的真实含义——不是"大致忘了"，是在可表示的数字范围内完全忘了。
>
> 但"忘得快"不是链的普遍性质，而是谱间隙的性质。把自环改成 $p_{11}=p_{22}=0.99$，非 1 特征值变成 $0.99+0.99-1=0.98$。算一下：$\ln 0.98=-0.020203$，乘 99 得 $-2.0001$，故 $0.98^{99}=0.135$。误差还有 13.5% 的量级，这时候拿 $\pi$ 顶替真实分布会错得离谱。同样的 99 步，一个精确到机器精度，一个错一成三。所以"跑得够久"这句话没有信息量，有信息量的是 $|\lambda_2|^n$ 什么时候小到可以忽略，其中 $\lambda_2$ 是模第二大的特征值。
>
> 回到两个空。第一空按乘法法则拆成 $P(X_1=1)\cdot r_{11}(99)$，等于 $\tfrac12\cdot\left[\tfrac27+\tfrac57\cdot 0.3^{99}\right]$，数值上就是 $1/7$。第二空是 $P(X_{100}=1)\cdot p_{12}$，等于 $\tfrac12\cdot\left[\tfrac27+\tfrac57\cdot 0.3^{100}\right]$，数值上也是 $1/7$。严格说来两空并不完全相等，差的是 $0.3^{99}$ 与 $0.3^{100}$ 之间那一档，量级 $10^{-52}$；在 double 里两空给出同一个数，所以看着相同是浮点的功劳，不是代数的巧合。这一点值得记住，因为如果把 99 换成 3，两空就明显不同了：$r_{11}(3)=2/7+(5/7)\cdot 0.027=0.305$，与 $1/7$ 差一倍多。
>
> 跨课程连接有两条。第一条接 CSAPP 第 6 章：AMAT 用的是稳态 miss rate，可程序刚启动那几十个周期里 miss rate 由 compulsory miss（强制性缺失）主导，用稳态数字会把启动代价算漏。判断"该用稳态还是该用逐次"的判据和这里是同一个——看那段"预热期"相对于谱间隙够不够长。第二条接 6.006 与 CLRS 的 amortized analysis（摊还分析）：摊还成本是长期平均，正对应 $\pi$；单次操作的最坏代价是逐步量，正对应 $p_{ij}$。区别在于摊还分析对一条确定的执行序列取平均，给出的是确定性上界；而这里的 $\pi$ 是对随机路径取期望，给的是概率意义下的极限，两者不能互相替代。
>
> 收束：这道小题真正的训练点不是算出 $1/7$，而是建立一条分诊规则——问远处某个时刻的边缘分布用 $\pi_j$，问下一跳的条件概率用 $p_{ij}$，而"远处"到底多远要由谱间隙算出来。凭感觉说"99 步肯定够了"，在 $p_{11}=0.99$ 那条链上就是错的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The phone company problem（电话公司问题）</span>

- 电话呼叫按泊松过程（Poisson process）到达，速率为 $\lambda$。
  - 每次通话时长服从指数分布（exponential distribution），参数为 $\mu$。
  - 共有 $B$ 条线路可用（$B$ lines available）。
- 把时间切成长度很小的**离散区间** $\delta$：状态 $0, 1, \ldots, i-1, i, \ldots, B-1, B$（忙线路数）。
- **平衡方程**：
```math
\lambda\, \pi_{i-1} = i \mu\, \pi_i
```
- 解出
```math
\pi_i = \pi_0\, \frac{(\lambda / \mu)^i}{i!}, \qquad \pi_0 = \frac{1}{\sum_{i=0}^{B} \dfrac{(\lambda / \mu)^i}{i!}} .
```

> <span style="color:#7f8c8d;">Bertsekas §7.3, p.353–357</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 跨课程连接）:**</span> 这条平衡方程写的不是"流入等于流出"，而是"每一对相邻状态之间的净流量为零"。后者是一个更强的陈述，但在 birth-death process（生灭过程）里恰好更容易解——强度换来了降阶。
>
> 先看为什么笼统写法会吃亏。状态 $i$ 的流入有两条通道：从 $i-1$ 新接通一通电话、从 $i+1$ 挂断降下一条；流出也有两条：向 $i+1$ 上升、向 $i-1$ 挂断。把它们写成总量相等，得 $\lambda\pi_{i-1}+(i+1)\mu\pi_{i+1}=(\lambda+i\mu)\pi_i$，这是二阶差分方程，要先解特征方程再套两个边界条件，手算基本走不下去。而教材那条式子 $\lambda\pi_{i-1}=i\mu\pi_i$ 是一阶递推，从 $\pi_0$ 一路乘上去就行：$\pi_i=\frac{\lambda}{i\mu}\pi_{i-1}$，连乘 $i$ 次收获 $(\lambda/\mu)^i/i!$。
>
> 为什么允许逐对相等，机制在"割"上。取集合 $S=\{0,1,\ldots,i-1\}$，看它的补集。稳态的定义是 $S$ 内的概率质量不随时间净增减，否则分布就在漂移，谈不上稳态。跨过这条割的转移只有两条：从 $i-1$ 进 $S^c$，以及从 $i$ 回 $S$。两条必须相等，这叫 detailed balance（细致平衡）。这里有个适用范围要说清：割之所以只切到两条边，是因为状态编号是一条直线，只能走到相邻格。若某个状态还能直接跳到 $i+2$，割上就多出第三条边，逐对相等立刻失效，只能退回全局平衡。
>
> 再抠一个最容易错的因子：为什么是 $i\mu$ 而不是 $\mu$。每条忙线各自挂一个独立的 exponential clock（指数时钟），参数都是 $\mu$。$i$ 个独立指数随机变量取最小值，结果仍然服从指数分布，参数相加，得 $i\mu$。所以线上的人越多，下一通挂断来得越快，而且是线性地快。这一点是整个系统的非线性来源：到达速率恒为 $\lambda$ 不随状态变，离开速率却随占用线性增长，一横一斜两条线的交点就把系统钉在某个占用水平附近。
>
> 把数字代进去看量级。$\lambda=2$ 通每分钟、平均通话 $1/\mu=2$ 分钟，故提供负载 $a=\lambda/\mu=4$ erlang（爱尔兰）。线路 $B=6$ 时 $\pi_i$ 正比于 $4^i/i!$，逐项 $1$、$4$、$8$、$10.667$、$10.667$、$8.533$、$5.689$，合计 $48.556$，故 $\pi_6=0.1172$。再算两个对照：$B=4$ 时只加到 $10.667$，合计 $34.333$，$\pi_4=0.3107$，阻塞 31%；$B=8$ 时再补 $4^7/7!=3.251$ 与 $4^8/8!=1.625$，合计 $53.432$，$\pi_8=0.0304$，阻塞 3.0%。于是同一条 4 erlang 的负载，4 条线（利用率 100%）丢 31%，6 条线（利用率 67%）丢 11.7%，8 条线（利用率 50%）丢 3.0%。从 31% 降到 3% 只用了一倍线路——这条曲线的陡峭程度就是"容量必须留余量"的定量依据，也是运维口径里从不敢报 100% 利用率的原因。
>
> 跨课程连接落在 CSAPP 第 11 章。`listen(sockfd, backlog)` 里的 backlog 就是这个 $B$：accept queue（接受队列）装满时新连接被拒。连接路径是逐项对应的——SYN 到达对呼叫到达，队列里的已完成连接数对忙线数，应用调用 `accept` 的速率对挂断速率。区别必须点明：电话系统是 loss system（损失制），阻塞即丢弃，被拒的呼叫再也不回来；TCP 是 retry（重试），客户端会重传 SYN，所以 backlog 满的后果不是"拒绝率"而是"延迟上升"，模型要换成带等待队列的那一类，Erlang B 的公式直接搬会算错。
>
> 再补一条与本课程第 6 章的连接。$\pi_i$ 的形状正比于 $(\lambda/\mu)^i/i!$，这就是参数为 $a$ 的 Poisson PMF（泊松概率质量函数），只是被截断到 $B$ 后重新归一化。两者数值不同，方向值得记住：无容量限制时 $P(N=6)=e^{-4}\cdot 4^6/720=0.1042$，有 6 条线时 $\pi_6=0.1172$——截断把溢出到 $7,8,\ldots$ 的质量挤回来，所以阻塞概率比"不受限时的占用概率"更大。这个偏差随 $B$ 减小而放大，$B$ 远大于 $a$ 时才趋于消失。
>
> 收束：这个公式由丹麦工程师 A. K. Erlang 于 1917 年发表在 Post Office Electrical Engineers' Journal 上，一百多年后仍在做线路容量规划。它能活这么久，靠的正是上面三步：细致平衡把二阶降成一阶、$i\mu$ 的线性离开率给出可积的形状、截断再归一化给出真正要上报的那个数。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Calculating absorption probabilities（吸收概率的计算）</span>

> <span style="color:#7f8c8d;">图：五状态转移链——状态 4 与 5 为吸收态（自环概率为 1），状态 1、2、3 为暂态，各弧线标注相应的转移概率；本图与下一页"期望时间"图共用同一链结构。</span>

- **问题**：$a_i$ = 从初始状态 $i$ 出发，过程最终停在状态 4 的概率是多少？
- **课堂填空**：
  - 对 $i = 4$：$a_i = \underline{\qquad}$
  - 对 $i = 5$：$a_i = \underline{\qquad}$
- 对其余所有状态 $i$：
```math
a_i = \sum_{j} p_{ij}\, a_j
```
  —— 该方程组有唯一解。

> <span style="color:#7f8c8d;">Bertsekas §7.4, p.362–363</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 证明策略模板）:**</span> 这一步要解决的问题是：怎样把一个"最终会怎样"的问题，换成有限维的线性方程组。路径有无穷多条、长度没有上界，直接求和是发散的思路；首步分解把它折叠成"花掉一步，然后面对一个同型的子问题"。
>
> 先补两个空。4 本身是吸收态，落到它就停在那里，故 $a_4=1$；5 也是吸收态，且与 4 是两个不同的状态，进去就再也出不来、更到不了 4，故 $a_5=0$。这两个值不是方程解出来的，是题目结构白送的。要留一个心眼：如果目标是一整个常返类而不是单个吸收态，得先把类里所有状态合并成一个超级吸收态，边界才存在——教材 §7.4 的 Example 7.10 就是这么把两个常返态并成一个的。
>
> 机制分两步，缺一不可。第一步是全概率定理：按"第一步落在哪"把事件切开，$a_i=\sum_j P(X_1=j\mid X_0=i)\,a_j$。第二步是马氏性：一方面 $P(X_1=j\mid X_0=i)$ 就是 $p_{ij}$，另一方面"从 $j$ 出发最终落到 4 的概率"与"从 $i$ 出发、已经走到 $j$ 之后最终落到 4 的概率"必须相等，这样左边的 $a_j$ 才能原样搬进方程。若无马氏性，第二个条件概率要写成 $P(\text{最终到 }4\mid X_1=j,\ \text{到 }j\text{ 为止的全部历史})$，它可能随历史变化，$a_j$ 就不再是一个只由 $j$ 决定的数，整个方程的合法性当场崩塌。
>
> 唯一性是这套方法真正的支柱，值得单独立成一个模板，可以叫最大模收缩法。设 $h$ 是暂态集合 $T$ 上的齐次解，即在 $T$ 内部满足 $h_i=\sum_{j\in T}p_{ij}h_j$、边界上取 0。取 $|h|$ 达到最大值的点 $k$，则 $|h_k|\le\sum_{j\in T}p_{kj}|h_j|\le|h_k|\sum_{j\in T}p_{kj}$。因为 $k$ 是暂态，必存在某个不在 $T$ 里的 $j$ 使 $p_{kj}>0$，所以 $\sum_{j\in T}p_{kj}<1$，右端严格小于 $|h_k|$，矛盾——除非 $|h_k|=0$。于是齐次方程只有零解，非齐次方程解唯一。这个套路在数值上还有一个副产品：只要谱半径小于 1，简单迭代就会收敛，不必真去求逆。
>
> 造一组数字走一遍。三个暂态：1 以 $0.5$ 留原处、$0.3$ 去 2、$0.2$ 直接去 4；2 以 $0.4$ 留原处、$0.4$ 去 3、$0.2$ 去 5；3 以 $0.6$ 留原处、$0.4$ 去 4。从只有单出口的 3 开始：$a_3=0.6a_3+0.4$，得 $a_3=1$；代进 2：$a_2=0.4a_2+0.4\cdot 1$，得 $a_2=2/3$；再代进 1：$a_1=0.5a_1+0.3\cdot\tfrac23+0.2=0.5a_1+0.4$，得 $a_1=0.8$。三个数都在 $[0,1]$ 内，且随"离 4 更近"而变大，符合直觉：3 只有通向 4 和留原处两个出口，必胜；2 有 $0.2$ 的份额被 5 抓住，掉到 $2/3$；1 有 $0.2$ 直通 4，升到 $0.8$。这个"单调性加取值范围"的自检几乎免费，解出负数或大于 1 就说明某项系数抄错了。
>
> 跨课程连接有两条。第一条接 6.042J 的图论：可达性是这套东西的影子版——只问"存不存在一条路径到 $s$"，一趟宽度优先搜索就够，代价 $O(V+E)$。概率版问的是"所有路径的概率之和"，路径有无穷多条而每条权重不同，必须解方程组，代价升到 $O(m^3)$。区别的本质是一句话：可达性把 $0.5$ 和 $0.9$ 都记成 1，概率版把权重留着，代价就从图遍历涨到线性代数。
>
> 第二条接 Strang 18.065 的诺伊曼级数。把暂态部分的转移子矩阵记作 $Q$、把"一步直接跳进 4"的概率向量记作 $r$，方程就是 $(I-Q)a=r$，形式解是 $a=(I+Q+Q^2+\cdots)r$。第 $n$ 项的语义很干净：$Q^n r$ 的第 $i$ 个分量，等于"从 $i$ 出发恰好走 $n$ 步仍困在暂态、第 $n+1$ 步才离开并落进 4"的概率。所以"方程组有唯一解"与"这个级数收敛"是同一件事的两种说法，收敛的充要条件是 $Q$ 的谱半径小于 1，而"全是暂态"正好保证了这一点。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Expected time to absorption（吸收的期望时间）</span>

- **问题**：$\mu_i$ = 从初始状态 $i$ 出发、到进入吸收态为止的期望转移次数是多少？
- **课堂填空**：
  - 对 $i = \underline{\qquad}$：$\mu_i = 0$
- 对其余所有暂态 $i$：
```math
\mu_i = 1 + \sum_{j} p_{ij}\, \mu_j
```
  —— 该方程组有唯一解。

> <span style="color:#7f8c8d;">Bertsekas §7.4, p.366–367</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 卡点诊断）:**</span> 这一页和上一页是同一台机器，只换了 boundary condition（边界条件）：$a$ 方程把边界钉在 $\{0,1\}$，$\mu$ 方程把边界钉在 $0$，另外多出一个常数项 $1$。判断一个"时间"型的量该不该带这个 $1$，判据只有一句——那一刻是不是真的花掉了一次转移。
>
> 先补空。$\mu_4=0$：已经站在吸收态上，一步都不用走；同理 $\mu_5=0$。这不是解出来的，是定义给的，教材 p.366 明写起点若是常返态则取 $0$。把这条约定记住，后面所有方程才自洽。
>
> 机制的骨头在于那个 $1$，得逐句拆。令 $N$ 为从 $i$ 出发到进入吸收态为止走过的转移次数。当 $i$ 是暂态时必有 $N\ge 1$，因为至少要迈一步才可能落进吸收态。现在在 $X_1=j$ 上取条件：由时齐的马氏性，从 $(X_1=j)$ 往后数还剩 $N-1$ 步，其条件分布与"从 $j$ 出发数 $N$"完全一样，故 $E[N\mid X_0=i,X_1=j]=1+\mu_j$。再用全期望定理按 $j$ 加权：$\mu_i=\sum_j p_{ij}(1+\mu_j)=1+\sum_j p_{ij}\mu_j$。最后这一步值得停一下看：$\sum_j p_{ij}\cdot 1=1$ 恰好是 1，这不是"漏算了什么"，而是"每一支都先记一次转移，加权之后总量仍是 1"。
>
> 如果把 $1$ 丢掉会怎样，代价很直观。写成 $\mu_i=\sum_j p_{ij}\mu_j$ 之后，这就是暂态上的齐次方程，而上一页已经证过它只有零解，于是所有 $\mu_i$ 一律为 $0$，等于宣称"吸收不需要时间"。拿一条最傻的链试：1 必到 2、2 必到吸收态，真答案 $\mu_1=2$，误式给出 $0$。所以那个 $1$ 不是格式上的修饰，它承担了"每迈一步都要计时"的全部重量。
>
> 还有一个常被跳过的技术点：吸收几乎必然发生，不等于期望吸收时间有限。重尾分布可以做到"几乎必然停，但期望无穷"。有限状态链里这不成问题，证明两行：令 $p_{\min}=\min_{i\in T}\sum_{j\notin T}p_{ij}$，它是"任意一步就跳出去"的最小概率，因每个暂态都有出边故 $p_{\min}>0$；于是 $\Pr(N>k)\le(1-p_{\min})^k$，尾巴是几何的，故 $\mu_i\le 1/p_{\min}$。这个界不紧，但足以说明"里面在打转"不可能无限拖。
>
> 把数字代进上一页那条链。$\mu_3=1+0.6\mu_3$，得 $\mu_3=2.5$；$\mu_2=1+0.4\mu_2+0.4\cdot 2.5=1+0.4\mu_2+1$，得 $0.6\mu_2=2$，即 $\mu_2=10/3\approx 3.333$；$\mu_1=1+0.5\mu_1+0.3\cdot\tfrac{10}{3}=1+0.5\mu_1+1$，得 $0.5\mu_1=2$，即 $\mu_1=4$。用上面的界校一下：$p_{\min}=\min(0.2,0.2,0.4)=0.2$，界给 $5$，实测 $4$，落在界内且只差一步，说明这条链几乎没有内部打转的空间——所有暂态都有不小的概率直接跳向吸收态。若某个状态自环概率高达 $0.99$，界还是 $5$ 附近而真值会接近 $100$，那时差的就不是一点。
>
> 跨课程连接接 CLRS 第 4 章和 6.006 的随机化快排。它的期望复杂度满足 $E[T(n)]=(n-1)+\frac{2}{n}\sum_k E[T(k)]$，结构与本页完全同型：固定的一步代价（一次划分）加上各分支子问题的期望，按分支概率加权。但区别必须说死：快排的子问题规模严格小于 $n$，递归是良基的、无环的，所以可以画递归树、用代入法或主定理展开成闭式；而 $\mu$ 方程里允许出现 $i\to j\to i$ 这样的环，展开会原地打转，递归树长不成树，只能退回去解线性方程组。这也正是 CLRS 主定理管不到的情形——它假设子问题规模严格下降。
>
> 再补一条短连接，落在 CSAPP 第 6 章：一次 miss 的平均服务时间等于"总线事务的固定开销"加上"后续层次的访存延迟"，那个固定开销就是这里的 $1$——不管数据在不在下一层，这笔开场费都要先付。区别在于 cache 的"吸收"是伪吸收：miss 处理完就回到正常执行，不存在永久停住的吸收态，所以那套式子算的是单次服务时间，不是到吸收的期望步数。
>
> 收束：$\mu$ 方程真正要练的是一个反射动作——写任何"期望步数/期望时间"的式子时，先问一句"这一步本身算不算一次"。算，就加 $1$；不算（比如已经停在终点），就把那一支的系数直接抹掉。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Mean first passage and recurrence times（平均首达时间与平均回访时间）</span>

- 设链只有单一常返类；固定常返态 $s$。
- **平均首达时间**（mean first passage time）——从 $i$ 到 $s$：
```math
t_i = \mathrm{E}\big[\min\{n \ge 0\ \text{such that}\ X_n = s\} \,\big|\, X_0 = i\big]
```
- $t_1, t_2, \ldots, t_m$ 是如下方程组的唯一解：
```math
t_s = 0, \qquad t_i = 1 + \sum_{j} p_{ij}\, t_j \quad \text{for all } i \ne s .
```
- **平均回访时间**（mean recurrence time）——$s$ 回到自身：
```math
t^*_s = \mathrm{E}\big[\min\{n \ge 1\ \text{such that}\ X_n = s\} \,\big|\, X_0 = s\big]
```
```math
t^*_s = 1 + \sum_{j} p_{sj}\, t_j .
```

> <span style="color:#7f8c8d;">Bertsekas §7.4, p.368–369；p.402</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 跨课程连接）:**</span> 用教材 Example 7.13（p.368–369）做完整验算：链的转移概率为 $p_{11} = 0.8$、$p_{12} = 0.2$、$p_{21} = 0.6$、$p_{22} = 0.4$，取 $s = 1$。由 $t_1 = 0$ 与 $t_2 = 1 + 0.4\,t_2$ 解得 $t_2 = 1/0.6 = 5/3$ ✓；再算回访时间 $t^*_1 = 1 + p_{11}t_1 + p_{12}t_2 = 1 + 0.2 \times \tfrac{5}{3} = \tfrac{4}{3}$ ✓。另一路独立验证：该链的稳态解为 $\pi_1 = 0.75$、$\pi_2 = 0.25$，而教材 p.402 证明了一般公式 $t^*_s = 1/\pi_s$——$1/\pi_1 = 4/3$，两路完全吻合 ✓。这个恒等式值得单独记住：**回访越"勤"的状态稳态概率越大**，长期频率 $\pi_s$ 就是"每隔 $1/\pi_s$ 步回访一次"的倒数措辞。跨课程连接：$t_i$、$\mu_i$、$a_i$ 三套方程在结构上就是 CLRS 算法分析里的 recurrence（递归式）——"一步代价 + 各分支子问题的期望"——边界条件扮演 base case，解线性方程组扮演"展开递归求闭式"；随机化算法的期望复杂度分析与这里的期望吸收时间，是同一枚硬币的两面。
