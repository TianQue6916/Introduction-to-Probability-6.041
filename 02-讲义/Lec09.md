**PDF 复习**：

> <span style="color:#7f8c8d;">图：样本空间上的事件 $\{a < X < b\}$ 对应 $f_X(x)$ 曲线下 $a$ 到 $b$ 的阴影面积。</span>

```math
P(a \le X \le b) = \int_a^b f_X(x)\, dx, \qquad P(x \le X \le x + \delta) \approx f_X(x) \cdot \delta, \qquad \mathrm{E}[g(X)] = \int_{-\infty}^{\infty} g(x) f_X(x)\, dx .
```

**Summary of concepts（概念对照表）**：

| 离散世界 | 连续世界 |
|:---:|:---:|
| $p_X(x)$ | $f_X(x)$ |
| $\sum_x x\, p_X(x) = \mathrm{E}[X]$ | $\int x f_X(x)\, dx = \mathrm{E}[X]$ |
| $F_X(x)$ | $F_X(x)$ |
| $\mathrm{var}(X)$ | $\mathrm{var}(X)$ |
| $p_{X,Y}(x, y)$ | $f_{X,Y}(x, y)$ |
| $p_{X|A}(x)$ | $f_{X|A}(x)$ |
| $p_{X|Y}(x \mid y)$ | $f_{X|Y}(x \mid y)$ |

> <span style="color:#7f8c8d;">Bertsekas §3.1, p.140, p.144–145（PDF 与期望的连续版复习）；§3.4, p.158 起（本讲 Readings 起点：联合 PDF）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 这张概念对照表的真正功能不是让人背诵，而是给出一个可以逐格执行的翻译方式：任何离散世界的陈述，只要按三条规则搬过去，就能得到连续世界的对应物——求和换成积分、PMF（概率质量函数）换成 PDF（概率密度）、条件表格换成比值。真正需要动脑的地方只有一处：哪条规则在搬运途中会失效。本讲的技术内容基本上就是这一处的补丁。
>
> 先说为什么"求和换积分"几乎不会出错。离散的 PMF（概率质量函数）是质量在可数多个点上的分配，连续的 PDF（概率密度）是质量在直线上按长度铺开的浓度，两者的共同约束都是"总质量等于一"，唯一区别是取值集合从可数变成不可数。因为约束同形，凡是只用到"总质量为一"和"期望是加权平均"的陈述，机械替换都不会错。会失效的必然是那些暗中用到"某个点有正概率"的陈述——条件化正好属于这一类。
>
> 逐行看第四行往后。联合这一行最安全：$p_{X,Y}$ 是一张二维表格，$f_{X,Y}$ 是一张曲面，一维的求和变成二维的二重积分，"按列求和"对应"沿一条轴把另一条轴积掉"，没有新概念。条件于事件这一行也安全，因为事件可以有正概率：把密度在事件上截断再除以 $P(A)$，分母是一个正数，除法合法。危险的是最后一行，条件于变量：事件 $\{Y = y\}$ 的概率是零，除法失去意义，必须改用极限定义（本讲第四节）。所以这张表真正的分界线不在第三行与第四行之间，而在"事件"与"变量"之间——同一个符号，左边是可以除的，右边不能除。
>
> 拿一个能全程手算的例子把四种对象摆在一起。设联合密度在三角域 $0 < y < x < 1$ 上取常数 $2$，区域外取零——区域面积是二分之一，密度取倒数正好归一化。沿 $x$ 积分得 $f_X(x) = 2x$，沿 $y$ 积分得 $f_Y(y) = 2(1-y)$，两个条件密度分别是 $f_{Y|X}(y \mid x) = 1/x$ 与 $f_{X|Y}(x \mid y) = 1/(1-y)$。代数字：$f_X(0.5) = 1$，$f_Y(0.25) = 1.5$，于是 $f_{Y|X}(y \mid 0.5) = 2$（在 $0 \le y \le 0.5$ 上），$f_{X|Y}(x \mid 0.25) = 4/3$（在 $0.25 \le x \le 1$ 上）。四个数互不相同，却描述同一个随机对，这就是字典要防的那类混淆。
>
> 跨课程连接有三条值得钉住。其一是 6.042J 的 partition（划分）：条件化在离散世界就是按 $Y$ 的取值把样本空间切成若干等价类，类内重新归一化；连续世界的区别在于每个类都是零厚度的线，无法数元素只能积密度，所以"类内归一化"必须写成除以 $f_Y(y)$ 而不是除以类的大小。其二是 CSAPP 第 6 章的 cache（高速缓存）层次：同一份数据在 L1 与在主存里"看得见的粒度"不同，正像联合密度、边缘密度、条件密度是同一个对象在三种分辨率下的呈现；区别是 cache line（缓存行）的宽度由硬件钉死在 64 字节，而这里的切片宽度可以取到任意小，这正是连续世界能取极限、而 cache 只能用固定块的根本原因。其三是 Strang 的矩阵分解：把矩阵按行求和得到行边缘、按列求和得到列边缘，"边缘"这个词在两边同名同义，离散的求和与连续的积分只是同一动作的两种实现。
>
> 所以这张表该这样读：前三行是可直接搬的语法，后三行里只有"条件于事件"能直译，"条件于变量"必须重写定义。带着这张地图读后面每一节，遇到新公式先问"它在表里属于哪一行、要不要重写"，就不会把零概率事件上的除法当成理所当然。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Joint PDF $f_{X,Y}$（联合概率密度函数）</span>

```math
P\left((X, Y) \in S\right) = \iint_S f_{X,Y}(x, y)\, dx\, dy .
```
- **解释**：
```math
P(x \le X \le x + \delta,\ y \le Y \le y + \delta) \approx f_{X,Y}(x, y) \cdot \delta^2 .
```
- **期望**：
```math
\mathrm{E}[g(X, Y)] = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} g(x, y)\, f_{X,Y}(x, y)\, dx\, dy .
```
- **从联合到边缘**：
```math
f_X(x) \cdot \delta \approx P(x \le X \le x + \delta) = \delta \int_{-\infty}^{\infty} f_{X,Y}(x, y)\, dy .
```
两边同除以 $\delta$，即得边缘化公式 $f_X(x) = \int_{-\infty}^{\infty} f_{X,Y}(x, y)\, dy$。
- **独立性**：称 $X$ 与 $Y$ independent（独立），若
```math
f_{X,Y}(x, y) = f_X(x) f_Y(y), \qquad \text{对所有 } x, y .
```

> <span style="color:#7f8c8d;">Bertsekas §3.4, p.158–164（定义与 $\delta^2$ 解释 p.159；边缘 PDF 与二维均匀例 p.160；联合 CDF p.162；期望值规则与线性特例 p.163；汇总框 p.164）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 验证）:**</span> 联合 PDF（概率密度）要解决的问题只有一个：两维的"概率浓度"该怎么定义，才能让"体积"恰好表示概率。答案藏在量纲里——概率是纯数，面积带单位，所以密度必须是"每单位面积的概率"。这一句定了后面所有公式的形状，包括 $\delta^2$ 解释、边缘化的积分、以及独立判据为什么是两个函数相乘。
>
> 把 $\delta^2$ 解释拆开看。一维里 $P(x \le X \le x + \delta) \approx f_X(x)\delta$，理由是"落在长为 $\delta$ 的小区间"的可能位置数与 $\delta$ 成正比，密度就是那个比例系数。二维里"落在边长 $\delta$ 的小方块"的可能位置数与 $\delta^2$ 成正比，所以右端必须带 $\delta^2$。反过来想会更清楚：若硬把密度定义成概率本身，那么 $\delta \to 0$ 时概率趋于零，密度只能是零，什么也描述不了。允许密度大于一是这套定义的代价，也是它的红利——密度不是概率，只是概率对面积的斜率，所以它没有上界，也不该有。
>
> 边缘化是这套语言里最常用的一步，几何读法是投影。$f_X(x)\delta$ 是竖直薄条带的概率，薄条带的面积是 $\delta$ 乘以沿 $y$ 方向的长度，而密度在条带内近似为常数，于是条带概率等于密度乘以条带面积。把沿 $y$ 的所有条带累加，就是沿 $x$ 处整条切片的面积。这个"把另一个方向的信息全部积掉"的动作，与离散表格里按列求和是同一次操作，区别只在"列"变成了连续切片，求和变成了积分。
>
> 手算两个数，两个都要能独立复核。第一个：单位正方形上均匀，密度恒为一，求两人到达时间相差不超过四分之一小时的概率。补集是左上与右下两个等腰直角三角形，直角边长 $3/4$，每个面积是 $(1/2)(3/4)^2 = 9/32$，合计 $9/16$，所以答案是 $7/16 = 0.4375$。第二个：还是三角域上的常密度二，算 $\mathrm{E}[XY] = \int_0^1 \int_0^x 2xy\,dy\,dx = \int_0^1 x^3 dx = 1/4$，而 $\mathrm{E}[X]\mathrm{E}[Y] = (2/3)(1/3) = 2/9 \approx 0.2222$，两者不等，协方差约 $0.0278$，说明二者不独立。判据可以直接肉眼验：联合密度是常数二，而边缘乘积是 $4x(1-y)$，两者显然不是同一个函数。注意"对所有 $x,y$ 都相等"这个条件不能省，只要有一个点不相等，独立性就破了。
>
> 跨课程连接两条。其一是 Strang 的线性代数：二重积分换元时面积元要乘 $|\det J|$，而行列式度量线性变换把单位面积放大多少倍，这两句话说的是同一条事实；区别在于 Strang 处理的是常矩阵，缩放因子在整个区域上是同一个数，而概率里的雅可比随点变化，因子必须留在积分号内，这正是"密度随位置变"的数学来源。其二是 CSAPP 第 6 章的 cache（高速缓存）：要在代码里算 $\int f\,dy$，最省 cache line（缓存行）的写法是固定 $x$、沿 $y$ 连续走，也就是行优先；反过来固定 $y$ 沿 $x$ 走，每一步跨八个 double 即 64 字节，正好一整条 cache line（缓存行），取一个元素浪费七个，有效带宽掉到八分之一。这里的教训在概率上是中性的（积分值一样），在工程上却是八倍差距。
>
> 所以联合密度的全部内容可以压缩成两句话：密度是概率对面积的导数，概率是密度在区域上的二重积分。边缘、期望、独立判据都是这两句的推论，不要当成三条彼此无关的公式去背。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Buffon&rsquo;s needle（蒲丰投针）</span>

- 平行线间距为 $d$，针长为 $\ell$（设 $\ell < d$）。求 $P(\text{针与某条线相交})$。

> <span style="color:#7f8c8d;">图：一组间距 $d$ 的平行线，一根长 $\ell$ 的针斜搭其间——$x$ 为针中点到最近直线的距离，$\theta$ 为针与平行线的夹角。</span>

- 建模：$X \in [0, d/2]$ 为针中点到最近直线的距离；模型取 $X, \Theta$ uniform（均匀）且 independent（独立）：
```math
f_{X,\Theta}(x, \theta) = \frac{4}{\pi d}, \qquad 0 \le x \le \frac{d}{2},\ 0 \le \theta \le \frac{\pi}{2} .
```
其中 $f_X(x) = \frac{2}{d}$（在 $[0, d/2]$ 上均匀）与 $f_\Theta(\theta) = \frac{2}{\pi}$（在 $[0, \pi/2]$ 上均匀），独立相乘即得联合密度 $\frac{4}{\pi d}$。
- 相交条件：$X \le \dfrac{\ell}{2} \sin \Theta$。
```math
P\left(X \le \frac{\ell}{2} \sin \Theta\right) = \iint_{x \le \frac{\ell}{2} \sin \theta} f_X(x) f_\Theta(\theta)\, dx\, d\theta = \frac{4}{\pi d} \int_0^{\pi/2} \frac{\ell}{2} \sin \theta\, d\theta = \frac{2\ell}{\pi d} .
```

> <span style="color:#7f8c8d;">Bertsekas §3.4, p.161–162（Example 3.11: Buffon&rsquo;s needle，含史料与"实验估计 $\pi$"）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，历史与人物 + 验证）:**</span> 投针问题的地位不在那个积分，而在它是 geometric probability（几何概率）的第一个完整算例：样本空间不再有限个格子，而是连续的位置参数，概率由面积比给出。它之所以值得单独拆一遍，是因为它把"先声明模型、再算面积"这条流水线的每个零件都露在外面，任何一环含糊都会立刻算错。
>
> 模型里有三个必须交代的决定，少一个概率就没有定义。第一，针的位置要用两个数描述：中点到最近直线的距离 $X$，以及针与直线的夹角 $\Theta$。第二，$X$ 只取 $[0,\,d/2]$，因为更远的位置等价于"离另一条线更近"，用对称性把样本空间压成一个基本域；同理 $\Theta$ 只取 $[0,\,\pi/2]$，因为针没有方向性。这两处"折半"不是省事，而是把等价的位置合并成一个代表，保证每种物理位置恰好被数一次——这正是 6.042J 里"用代表元处理等价类"的老做法搬到了连续情形。第三，必须显式声明 $X$ 与 $\Theta$ 都 uniform（均匀）且互相 independent（独立）。这一步是模型假设而非定理：不声明，"随机投针"这四个字根本不构成概率问题，因为"随机"这个词在没有测度时是空的。
>
> 相交条件可以这样读。中点离最近直线的距离是 $x$，针的两端相对中点各偏 $\frac{\ell}{2}\sin\theta$，那么靠线那一端到最近直线的距离是 $x - \frac{\ell}{2}\sin\theta$；这个量为负就意味着针跨过了线。于是相交恰好等价于 $X \le \frac{\ell}{2}\sin\Theta$。$\ell < d$ 的假设保证针不可能同时跨过两条线，所以边界情形不用分段，整个计算是一个干净的积分：$\frac{4}{\pi d} \int_0^{\pi/2} \frac{\ell}{2}\sin\theta\, d\theta = \frac{2\ell}{\pi d}$，因为正弦在半周期上的积分等于一。
>
> 代数字更有说服力。取 $\ell = d/2$，概率是 $2\ell/(\pi d) = 1/\pi \approx 0.3183$。投 $n = 10000$ 次，观察频率 $\hat p$ 的标准误是 $\sqrt{p(1-p)/n} = \sqrt{0.3183 \times 0.6817 / 10000} \approx 0.00466$，相对误差约 $1.46\%$；把这个频率代回 $\hat\pi = 1/\hat p$，一个标准差的范围大约是 $[3.10,\, 3.19]$。想把 $\pi$ 定到小数点后三位（相对误差 $0.05\%$），需要 $n \approx (1.46/0.05)^2 \times 10^4 \approx 8.6 \times 10^6$ 次。这组数字说明投针是个漂亮的思想实验，不是实用的 $\pi$ 算法：标准误随 $\sqrt{n}$ 缩小，想多一位小数要一百倍样本。
>
> 历史只取三点，不铺年表。Buffon 1733 年向巴黎皇家科学院宣读这份工作，当年的科学院史册留有记录；完整成文收在 1777 年出版的 Essai d'arithmétique morale 中。二手文献对"1733 年即已成文"与"1777 年才刊行"两种说法并存，稳妥的写法是动笔取 1733、出版取 1777。真正的转折晚了两百年：1946 年 Ulam 病中玩纸牌时想到用抽样估计组合量，随后与 von Neumann 讨论，1949 年 Metropolis 与 Ulam 发表文章，把这类做法命名为 Monte Carlo（蒙特卡洛）方法。Buffon 给的是"面积比算概率"，Monte Carlo（蒙特卡洛）给的是"用随机数代替解析积分"，后者才是工程方法，前者只是它的思想祖先。
>
> 跨课程连接。CLRS 第 5 章讲概率分析与随机化算法，核心工具是 indicator random variable（指示器随机变量）：把"发生了多少次"拆成一串零一之和，再用期望的线性逐项计算。投针里每根针的指示器就是"交或不交"，总计数是它们之和，期望立刻是 $n$ 乘单次概率，这正是 CLRS 第 5 章分析 hiring problem 时用的同一招。区别在误差的性质：CLRS 里的 randomized（随机化）quicksort（快速排序）是 Las Vegas 型，结果一定正确、只有运行时间随机；投针是 Monte Carlo（蒙特卡洛）型，运行次数固定、答案带误差。同一条"以随机换确定性"的思路，落在两种不同的保证上，混用这两种保证是读随机算法时最常见的误解。
>
> 最后记一个警告，它解释了本讲为什么非要把分布写出来。1889 年 Bertrand 指出：若只说"在圆内随机取一条弦"，三种都算自然的取法会分别给出 $1/3$、$1/4$、$1/2$ 三个不同答案，而每一种取法都能自圆其说。可见几何概率的数值依赖于测度的选择，面的"随机"必须先翻译成参数的分布才可计算。所以教材把 $X$、$\Theta$ 的分布逐条写出不是啰嗦，而是让问题成立的前提。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Conditioning（条件化）</span>

- 回顾：$P(x \le X \le x + \delta) \approx f_X(x) \cdot \delta$。
- 依此类比，希望有：
```math
P(x \le X \le x + \delta \mid Y \approx y) \approx f_{X|Y}(x \mid y) \cdot \delta .
```
- 由此引出定义：
```math
f_{X|Y}(x \mid y) = \frac{f_{X,Y}(x, y)}{f_Y(y)}, \qquad \text{若 } f_Y(y) > 0 .
```
- 对固定的 $y$，conditional PDF（条件概率密度函数）是联合 PDF 的一个（归一化的）"section"（切片）。
- 若独立（$f_{X,Y} = f_X f_Y$），则得
```math
f_{X|Y}(x \mid y) = f_X(x) .
```

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.169–171（条件 PDF 的定义、解释与归一化）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 卡点诊断）:**</span> 连续条件化只卡在一句话上：conditional probability（条件概率）的定义要做除法，而条件事件的概率正好是零。本讲第四节的全部力气都在绕开这一次除零，绕法是把"除以零"改写成"先除以一个正数，再取 limit（极限）"。
>
> 先把离散版摊开对照。$p_{X|Y}(x \mid y) = p_{X,Y}(x,y)/p_Y(y)$，分母是"$Y = y$ 这一行"的总概率，是一个正数，归一化一行就完事。连续版想照抄，分母就变成 $f_Y(y)\,dy$ 那个量级的东西，而事件 $\{Y = y\}$ 本身的概率是零，直接除得到的是零比零，没有意义。教材的出路是用一条宽度可调的窄带代替那条线：先条件化于正概率事件 $\{y \le Y \le y + \delta_2\}$，再问 $X$ 落在长度为 $\delta_1$ 的小区间里的条件概率。分子约等于 $f_{X,Y}(x,y)\,\delta_1\delta_2$，分母约等于 $f_Y(y)\,\delta_2$，相除之后 $\delta_2$ 被完全约掉，剩下的正是 $f_{X,Y}(x,y)\,\delta_1/f_Y(y)$。
>
> 这里最值得停一下的是"$\delta_2$ 被约掉"这个事实本身。它说明答案与"窄带取多窄"无关，于是让 $\delta_2 \to 0$ 的极限存在而且唯一，可以直接把极限结果拿去当定义。反过来想：若分子分母不是同阶小量，约不掉，那就说明这条路线本身有问题——例如拿一个面积趋于零的斜带做条件，得到的比值会发散的，什么也定义不了。同阶相消是这套论证能成立的唯一理由，不是巧合。
>
> 严格化这条路需要测度论（$\sigma$-代数、Radon–Nikodym 导数那一套），这**不是必须懂的**：本课只需要两条可操作的事实。第一，条件密度等于联合密度沿另一方向切片再除以该切片的总面积。第二，这个比值在一切 $f_Y(y) > 0$ 的点上都存在，且对 $x$ 积分等于一。凡是要用条件密度的地方，把比值写出来代进去就够用，不必追问极限过程。
>
> 用三角域上常密度二那个例子做数值对照，两个方向都要算。$f_{Y|X}(y \mid x) = 1/x$，于是 $P(Y \le 0.25 \mid X = 0.5) = 0.25/0.5 = 0.5$，条件期望 $\mathrm{E}[Y \mid X = 0.5] = 0.25$。反方向 $f_{X|Y}(x \mid y) = 1/(1-y)$，于是 $P(X \le 0.5 \mid Y = 0.25) = (0.5 - 0.25)/0.75 = 1/3 \approx 0.333$。两个数零点五与零点三三三不等，这不是算错，而是 $f_{Y|X}$ 与 $f_{X|Y}$ 本来就是两个不同的对象：前者是"已知 $X$ 推 $Y$ 的规律"，后者方向相反。把这两个数并排记住，能挡掉大部分把两个条件密度混用的错误。
>
> 卡点清单三条。一是角色：$f_{X|Y}(x \mid y)$ 是以 $x$ 为自变量的函数，$y$ 只是参数；它对 $x$ 积分等于一，对 $y$ 积分则毫无意义。二是定义域：只在 $f_Y(y) > 0$ 处有定义，个别零概率点上怎么取值都不影响任何概率，习惯上随便填。三是自检：把定义代回去，$\int f_{X|Y}(x \mid y)\,dx = \int f_{X,Y}(x,y)\,dx / f_Y(y) = f_Y(y)/f_Y(y) = 1$，归一化自动成立；再把独立判据 $f_{X,Y} = f_X f_Y$ 代入，立刻得到 $f_{X|Y} = f_X$，也就是"知道 $Y$ 的值不改变 $X$ 的规律"。这与 Lec 03 的事件独立、Lec 07 的变量独立是同一条原则在第三种对象上的落位。
>
> 跨课程连接。6.042J 里的三条基本公式在连续世界逐条换成积分形式：$f_X(x) = \int f_{X,Y}(x,y)\,dy$ 是全概率公式，"把所有可能的原因积掉"；$f_{Y|X}(x \mid y) = f_{X|Y}(y \mid x) f_X(x)/f_Y(y)$ 是 Bayes rule（贝叶斯公式）的连续版，"用观测修正先验"。区别有两条：离散版分母是有限和，连续版是积分，后者可能算不出闭式解；连续版多一个风险，分母可能为零，而离散版只在"该行总概率为零"时才有这个问题，通常一眼能看出。CSAPP 第 6 章那条更接近工程经验：同一个循环，若把"上一次访问的是相邻地址"作为已知条件，hit rate（命中率）会从一成跳到九成以上。这也是"给定条件后分布改变"，区别在于那里统计的是经验频率，这里算的是密度之比：前者靠测量，后者靠求导与积分，而且后者的条件可以是零概率事件，前者必须是真实发生过的事件。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Joint, Marginal and Conditional Densities（联合、边缘与条件密度）</span>

- 读图要点：
  - **Area of slice = Height of marginal density at $x$**：固定 $x$ 的切片面积 = 边缘密度在该处的高度。
  - **Slice through density surface for fixed $x$**：沿固定 $x$ 用竖直平面切开密度曲面所得的截面。
  - **Renormalizing slices for fixed $x$ gives conditional densities for $Y$ given $X = x$**：把各切片除以自身面积重新归一化，即得给定 $X = x$ 时 $Y$ 的条件密度。

> <span style="color:#7f8c8d;">图：三维密度曲面示意——曲面下总体积为 $1$；沿固定 $x$ 的一刀切出截面曲线，其面积即 $f_X(x)$；把截面缩放到面积为 $1$ 便得到 $f_{Y|X}(\cdot \mid x)$。图源：Image by MIT OpenCourseWare, adapted from *Probability*, by J. Pittman, 1999.</span>

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.169–171（同主题可视化与"切片归一化"论证）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这一页没有一条公式，却把条件化里最难的一层直觉画透了：同一个联合密度曲面，换一个方向切、取不同的信息，就分别得到 edge（边缘）与条件分布，而这两样东西来自同一批切片。读它的关键不是记住三句话，而是意识到"面积"与"形状"是同一刀口的两种读数。
>
> 第一步，联合密度是一张总体积为一的曲面，任何区域的概率等于曲面下该区域的体积。第二步，固定 $x$ 切一刀，截面曲线下的面积恰为 $f_X(x)$，理由很朴素：这条薄片的全部概率正好是"$X$ 落在 $x$ 附近"的概率，而薄片上的密度沿方向逐点累加（积起来）就是它的总量。把每个 $x$ 处的面积记下来，就得到一个一维的 marginal density（边缘密度），这个把曲面"压扁成曲线"的动作就是 $f_X(x) = \int f_{X,Y}(x,y)\,dy$。第三步，同一个切片的形状正比于联合密度沿 $y$ 的轮廓，但它的总面积是 $f_X(x)$ 而不是一；做 conditional density（条件密度）必须归一化，所以整条轮廓要除以切片面积，得到 $f_{Y|X}(\cdot \mid x)$。三步用同一批刀口，区别只在"记面积"还是"保形状再缩放"。
>
> 用三角域上常密度二那个例子把三步走成数字，两个方向都走一遍。固定 $x = 0.5$：$y$ 从零到 $0.5$，高度恒为二，面积 $2 \times 0.5 = 1$，与 $f_X(0.5) = 2 \times 0.5 = 1$ 一致；把这条切片除以一，得到 $[0,\,0.5]$ 上高度为二的密度，而公式给出 $1/0.5 = 2$，一致。换方向，固定 $y = 0.25$：$x$ 从 $0.25$ 到一，长度 $0.75$，面积 $2 \times 0.75 = 1.5$，与 $f_Y(0.25) = 2 \times 0.75 = 1.5$ 一致；截面缩放后高度是 $2/1.5 = 4/3$，它在长度 $0.75$ 上的积分是 $1$，与 $1/(1-0.25) = 4/3$ 一致。两个方向都自洽，说明"面积给边缘、形状给条件"这句口诀可以当数值自检用，算完随手验一次就能抓住大半的错。
>
> 把同一个点 $(0.5,\,0.25)$ 上的四个数摆在一起，两个陷阱立刻显形。四个数是：联合密度二，$f_X(0.5) = 1$，$f_Y(0.25) = 1.5$，两个条件密度分别是二与 $4/3$。陷阱一是联合密度可以同时大于两个边缘密度，因为它不是概率，不能与一比较；判断"密度大小"只在同一个密度内部、同一个自变量下才有意义，跨密度比较数值是失去量纲意义的行为。陷阱二是两个条件密度不相等，因为两个方向的分母与切片长度都不同：沿 $y$ 方向的切片长度是 $x$，沿 $x$ 方向的切片长度是 $1-y$。这两个长度在点 $(0.5,\,0.25)$ 上分别是 $0.5$ 与 $0.75$，分母差一半，答案自然不同。
>
> 跨课程连接。Strang 的线性代数里有一个现成的对应物：把矩阵按列归一化，每列除以列和，得到 column-stochastic（列随机）矩阵，它的第 $(i,j)$ 个元素读作"已知列指标为 $j$ 时行指标为 $i$ 的比例"，这正是 $p_{X|Y}$ 的含义，而列和序列就是边缘 $p_Y$。连续版把"列"换成切片、"列和"换成切片面积、求和换成积分，其余结构一模一样。区别有两条值得记：离散版里"列和为零"对应一个空列，连续版里"$f_Y(y) = 0$"对应一个零概率点，两者都必须排除，否则除法无定义；离散版的归一化因子是有限和、能精确算，连续版是积分，常常只能数值求。CSAPP 第 6 章那条更直白：固定 $x$ 扫 $y$ 是 stride（跨步）为一的访问，一条 $64$ 字节的 cache line（缓存行）装八个 double，全部用上；固定 $y$ 扫 $x$ 的 stride（跨步）是八，每走一步就换一条 line，命中率优势彻底反转。几何上说的"换个方向切"，在代码里就是"换遍历顺序"，代价可以差八倍。
>
> 收束一句：这一页之所以不写公式，是因为它要给的是一个可以反复使用的图像——曲面、刀口、面积、缩放。以后每见到 $f_{X|Y}$ 或 $f_{Y|X}$，先在脑子里切一刀，确认分母是哪个面积、切片沿哪个方向，剩下的就是代入。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Stick-breaking example（折棍例子）</span>

- 把长为 $\ell$ 的棍子折断两次：第一次在 $X$ 处折断，$X$ 在 $[0, \ell]$ 上均匀；再在 $Y$ 处折断，$Y$ 在 $[0, X]$ 上均匀。
```math
f_X(x) = \frac{1}{\ell}, \qquad f_{Y|X}(y \mid x) = \frac{1}{x} \ \ (0 \le y \le x),
```
```math
f_{X,Y}(x, y) = f_X(x)\, f_{Y|X}(y \mid x) = \frac{1}{\ell x}, \qquad 0 \le y \le x \le \ell .
```

> <span style="color:#7f8c8d;">图：左为 $f_X$（$[0, \ell]$ 上的平顶密度）与棍子在 $x$ 处折断的示意；右为 $f_{Y|X}$（$[0, x]$ 上的平顶密度，高度随 $x$ 变化）与第二段折断的示意。</span>

- 边缘与期望：
```math
f_Y(y) = \int f_{X,Y}(x, y)\, dx = \int_y^{\ell} \frac{1}{\ell x}\, dx = \frac{1}{\ell}\left[\log x\right]_{y}^{\ell} = \frac{1}{\ell}\log \frac{\ell}{y}, \qquad 0 \le y \le \ell,
```
```math
\mathrm{E}[Y] = \int_0^{\ell} y f_Y(y)\, dy = \int_0^{\ell} \frac{y}{\ell} \log \frac{\ell}{y}\, dy = \frac{\ell}{4}, \qquad \mathrm{E}[Y \mid X = x] = \int_0^{x} y f_{Y|X}(y \mid X = x)\, dy = \frac{x}{2} .
```

> <span style="color:#7f8c8d;">Bertsekas §3.5, p.169–173（条件 PDF 乘法规则与条件期望机制）；同型折棍问题另见 §3.5 习题区 p.191（Problems 21–22）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 证明策略模板）:**</span> 折棍这一页真正要记的不是那个对数密度，而是一个可迁移的命名模板：sequential modeling（分层建模）。它的做法是把"两维同时建模"降成"两次一维建模"，每一次都是能一眼写出的 uniform（均匀）分布，再由 multiplication rule（乘法规则）$f_{X,Y} = f_X \cdot f_{Y|X}$ 自动合成联合密度。
>
> 为什么必须分层，可以从"直接猜会怎样"看起。联合密度要同时满足两个约束：总体积为一、形状正确。在三角域 $0 \le y \le x \le \ell$ 上，体积约束只能定出一个常数，但真实密度的形状在这里根本不是常数——它是 $1/(\ell x)$，在 $x$ 趋于零时发散，没有任何"看起来自然"的常数能猜对。分层把这件事换成两次可以口算的决定：先让 $X$ 在 $[0,\ell]$ 上均匀，再说"给定 $X = x$ 后 $Y$ 在 $[0,x]$ 上均匀"。每一步都只是一维均匀，密度直接写出来。合法性由乘法规则保证：$\int\int f_X(x) f_{Y|X}(y \mid x)\,dy\,dx = \int f_X(x)\left(\int f_{Y|X}(y \mid x)\,dy\right)dx = \int f_X(x)\,dx = 1$，归一化自动成立，不需要事后补常数。这就是分层的证明：内层对 $y$ 积分得一，外层对 $x$ 积分得一，两级各管一半。
>
> 取 $\ell = 1$ 代数字，三个量都要能自己复算。边缘 $f_Y(y) = \ln(1/y)$，在 $y = 0.5$ 处等于 $\ln 2 \approx 0.6931$，比一大得多，但它照样是合法密度，因为它的积分才是一。条件期望 $\mathrm{E}[Y \mid X = x] = x/2$，无条件期望 $\mathrm{E}[Y] = 1/4$。再算一个必须动手的量：$P(Y \le 0.1)$。走边缘路线，$\int_0^{0.1}\ln(1/y)\,dy = [y\ln(1/y) + y]_0^{0.1} = 0.1 \times (2.3026 + 1) \approx 0.3303$。走二维路线验算，必须分两块：$x \in [0,\,0.1]$ 时整段 $y \le x$ 都在区域内，贡献 $\int_0^{0.1} 1\,dx = 0.1$；$x \in [0.1,\,1]$ 时只取 $y \in [0,\,0.1]$，贡献 $0.1\ln 10 \approx 0.2303$；两块相加 $0.3303$，与边缘路线吻合。若只算第二块，会得到 $0.2303$，恰好差 $0.1$——这是分段积分最常掉的那一步，值得单独记。
>
> 机制再补一层：$\mathrm{E}[Y] = 1/4$ 这个数不是背出来的，因为 $x/2$ 对 $X$ 取期望得 $\mathrm{E}[X]/2 = \ell/4$。这不是巧合，而是全期望定理在连续世界的形态，本讲先拿它做自检，严格版本在后面的 iterated expectations（迭代期望）一节。换个模型做对照最能说明"建模决定答案"：若第二个断点在整根棍上独立均匀，而不是在 $[0,x]$ 内，则 $\mathrm{E}[Y] = \ell/2$，正好是现在的两倍，联合密度也从 $1/(\ell x)$ 变成 $1/\ell^2$。两句话的差别，答案差一倍。顺带记一个反例：若把"第二次折断"读成"在较长的那一段里再折"，模型立刻就变了，分母里会出现 $\max(x,\,\ell-x)$，边缘密度也不再是单一的对数形——读题时"在剩余段内均匀"这几个字必须逐字确认，它是这个模板唯一的入口。
>
> 跨课程连接。CLRS 第 7 章的 quicksort（快速排序）随机化用的是同一个模板：随机 pivot（枢轴）把长度 $n$ 的数组切成两段，pivot 的名次在 $1$ 到 $n$ 上均匀，这正是"给定长度后切点均匀"的条件分布，与 $f_{Y|X}(y \mid x) = 1/x$ 是同一件事的离散版。它的递归期望 $\mathrm{E}[T(n)] = n - 1 + \frac{1}{n}\sum_{k=1}^{n}\left(\mathrm{E}[T(k-1)] + \mathrm{E}[T(n-k)]\right)$ 的构造方式就是"先固定 pivot 位置算条件期望，再对所有位置取平均"，与 $\mathrm{E}[Y] = \mathrm{E}[\mathrm{E}[Y \mid X]]$ 完全同型，连符号习惯都一致。区别有两条：quicksort 的条件变量是离散名次，求和即可，折棍的条件变量是连续的，必须积分；quicksort 切出的两段还要各自继续递归，折棍的第二段不再折，所以前者是递推方程，后者只是一次性的两步抽样。看清这两条区别，就不会把折棍误当成"递归随机分割"的模型。
>
> 收束：折棍的正确读法是"物理顺序 → 条件顺序 → 乘法规则"三步翻译，积分只是收尾。以后遇到任何"先随机决定一个量、再在这个量的范围内随机"的建模题，先写下 $f_X$ 与 $f_{Y|X}$，联合密度不必猜，也猜不出来。

> <span style="color:#1e8449;">**[note] Note（译者注，跨课程连接）:**</span> 折棍的机制可以概括成"除法式取样"：第二个断点的采样范围由第一个断点决定，于是密度里出现 $1/x$，边缘里出现对数。这一句话解释了本页两个反直觉现象——无界的密度与不对称的期望——也是它能与其它课程接上的原因：凡是"先决定规模、再在规模内均匀撒点"的结构，都会长出同一种形状。
>
> 先回答"为什么 $f_Y$ 在零点发散"。从物理上看，想得到很小的 $y$，需要两件事同时成立：$x$ 不能小于 $y$；并且 $y$ 落在 $[0,x]$ 里的相对位置要够靠前。$x$ 越接近零，密度 $1/(\ell x)$ 越大，而能使 $y$ 出现的 $x$ 有无穷多个（从 $y$ 一直排到 $\ell$），这些微小贡献累加起来就成了对数。$x$ 恰好等于零是一个零概率事件，但它对密度有贡献，因为密度只看"每单位长度的概率"这个斜率，不看单点的值。概率本身完全正常：$P(Y \le \varepsilon) = \int_0^{\varepsilon} \frac{1}{\ell}\ln\frac{\ell}{y}\,dy = \frac{\varepsilon}{\ell}\left(1 + \ln\frac{\ell}{\varepsilon}\right)$，取 $\ell = 1$、$\varepsilon = 0.001$ 得 $0.0079$，是一个规规矩矩的小数。
>
> 把"三段能拼成三角形"在这套模型下算出来，是检验"模型决定答案"最有力的例子。三段长度是 $Y$、$X-Y$、$\ell-X$，取 $\ell = 1$，条件"每段都小于一半"即 $y < 1/2$、$x - y < 1/2$、$x > 1/2$。在区域 $0 < y < x < 1$ 上以 $1/x$ 为密度积分：内层 $y$ 从 $x - 1/2$ 到 $1/2$，长度是 $1-x$；外层 $x$ 从 $1/2$ 到 $1$，于是 $\int_{1/2}^{1}\frac{1-x}{x}\,dx = \ln 2 - \frac{1}{2} \approx 0.1931$。用两百万次抽样独立验证，得 $0.1931$，与解析值吻合。作为对照，若两个断点都在 $[0,1]$ 上独立均匀，同一问的答案是四分之一，两者相差约 $0.057$，差别完全来自"第二个断点的条件范围"。这道题在 6.042J 里以计数题的面貌出现过，那里的答案是四分之一，因为默认了两个断点独立；换成折棍模型，答案就必须重算。
>
> 跨课程连接两条。其一是 CLRS 第 7 章的 quicksort（快速排序）：随机 pivot（枢轴）下期望比较次数是 $2(n+1)H_n - 4n$，取 $n = 1000$、$H_{1000} \approx 7.4855$ 得约 $10986$ 次，而粗糙估计 $2n\ln n$ 给出 $13816$，高了两成，差额被 $-4n$ 那一项吃掉。这个计算与折棍用的是同一套语言：先固定切点算条件量，再对所有切点取平均；区别在于 quicksort 的切点是离散名次、两段还要各自递归，折棍的切点是连续的、只折一次。其二是 6.042J 的 partition（划分）：把"$X$ 的取值"当成划分的标签，给定标签后就退化成一个一维子问题；连续版的划分块是零厚度的切片，块内没有"元素个数"可数，只能用密度之比代替计数之比，这正是本讲反复强调的那道分水岭。
>
> 顺便清掉两个容易误用的词。折棍的结构常被说成"分形"或"自相似"，又说与 quicksort"同构"——这里都不需要那些概念：所谓"结构相同"只是"两步抽样加条件期望"的步骤一一对应，不需要任何代数背景，也不是在说两个对象之间存在保持结构的双射。本条实际用到的工具只有三个：conditional density（条件密度）、边缘积分、全期望。另外不要以为密度发散就是错误：$f_Y(y) = \frac{1}{\ell}\ln\frac{\ell}{y}$ 在 $y$ 趋于零时趋于无穷，但它的积分有限且等于一，所以它是合法的 PDF（概率密度）；离散的 PMF（概率质量函数）必须不超过一，连续密度没有这个上界，两套直觉不能互相搬运——把密度值当概率大小来比较，是连续化之后最常见的错。
>
> 带着"模型决定答案"这一条回看本页：分母 $\ell x$、对数边缘、期望 $\ell/4$、三角形成立概率约 $0.193$，四个数字都是同一个两步抽样机制的输出，换任何一个建模假设，四个数字会一起变。
