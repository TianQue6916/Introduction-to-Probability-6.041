### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Readings &amp; topics（阅读材料与本讲主题）</span>

**阅读（Readings）**：教材 pp. 225–226（§4.3，条件期望与条件方差重温）与 Sections 8.3–8.4（§8.3 贝叶斯 LMS 估计、§8.4 贝叶斯线性 LMS 估计）。

> <span style="color:#7f8c8d;">图：一个 object（目标物）位于未知位置，若干 sensors（传感器）分别对它做带噪声的观测（如 $X = \Theta + W$，噪声 $W \sim f_W$），全部数据汇入一个 Estimator（估计器），输出估计值 $\hat\Theta$——贝叶斯推断的标准场景图。</span>

**本讲主题（Topics）**：
- (Bayesian) Least Mean Squares (LMS) estimation（贝叶斯最小均方估计）。
- (Bayesian) Linear LMS estimation（贝叶斯线性 LMS 估计）。
- **MAP estimate（最大后验估计）**：$\hat\theta_{\mathrm{MAP}}$ 最大化 $f_{\Theta|X}(\theta \mid x)$。
- **LMS estimation（LMS 估计）**：$\hat\Theta = \mathrm{E}[\Theta \mid X]$ 在**所有**估计器 $g(\cdot)$ 中最小化 $\mathrm{E}[(\Theta - g(X))^2]$：
  - 对任意 $x$，$\hat\theta = \mathrm{E}[\Theta \mid X = x]$ 在所有估计值 $\hat\theta$ 中最小化 $\mathrm{E}[(\Theta - \hat\theta)^2 \mid X = x]$。

> <span style="color:#7f8c8d;">Bertsekas §8.3, p.430–436；§8.4, p.437–443；§4.3, p.225–226</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 本讲要解决的问题只有一个：所谓"估计得准"，到底是哪一把尺子量出来的。上一讲，即 Lec 21，已经把未知参数 $\Theta$ 升格为随机变量，用先验与似然算出后验，再用 MAP 法则拍出后验峰顶那个单值；那一套回答的是"哪个取值最可能"。可估计器一旦拍出单值，代价就落在"差多远"上，而 MAP 从不度量这件事——它只报告峰在哪，不报告峰有多宽、尾部有多重。
>
> 先把两把尺子的差别在机制上说透。MAP 隐含的损失是 0-1 loss（全对或全错）：猜对记零分，猜错记一分，于是逐点最优解就是让后验概率最大的那个点——离散情形是众数，连续情形是密度的峰。LMS estimation（LMS 估计）隐含的损失是 squared error（平方误差）：逐点看 $\mathrm{E}[(\Theta - c)^2 \mid X = x]$，它是 $c$ 的一条抛物线，开口朝上，最小值落在顶点 $c = \mathrm{E}[\Theta \mid X = x]$。两条最优化路径只在后验对称单峰时才交汇于同一点；后验一旦偏斜，两个答案就分开，分开多少完全由偏斜程度决定。
>
> 拿一个能心算的例子把差距钉住。设 $\Theta$ 只取 $0$ 或 $1$，某次观测之后算出 $\mathrm{P}(\Theta = 1 \mid X = x) = 0.4$。MAP 报 $0$，LMS 报 $0.6$。用平方误差评账：报 $0$ 的期望平方误差是 $0.4 \times 1 = 0.4$；报 $0.6$ 的是 $0.6 \times 0.36 + 0.4 \times 0.16 = 0.28$，低了整整三成。反过来用"猜对率"评账：报 $0$ 命中率 $0.6$，把 $0.6$ 四舍五入成 $1$ 之后命中率掉到 $0.4$。同一组数据、两把尺子、两个"最优"，谁都不算错——这一点必须先立住，后面的推导才有意义。
>
> 再给一个连续的例子，因为它能同时给出两个答案的具体数值。设 $X \mid \Theta = \theta$ 服从 $[0, \theta]$ 上的均匀分布，$\Theta$ 服从 $[0, 1]$ 上的均匀分布，观测到 $X = 0.7$。后验密度在 $[0.7, 1]$ 上正比于 $1/\theta$，在这个区间单调递减，所以 MAP 取左端点 $0.7$；归一化常数是 $\ln(1/0.7) \approx 0.3567$，后验均值是 $0.3 / 0.3567 \approx 0.841$。两个答案差 $0.14$，占真值两成——在"估计一个上界"这类任务里（比如估算最大并发连接数、最大突发长度），两成偏差直接改变容量规划结论。
>
> 还该追问一句：为什么偏偏用平方，不用绝对值？换成绝对误差，逐点最优是条件中位数，数值上要先排序、理论上不满足任何线性结构，多个观测联合时无法化归成方程组。而平方误差的最优解是条件均值，条件均值对"先逐点求最优、再把各点的代价按 $X$ 的分布加权合并"这条流水线封闭——这才是它能一路推到后文误差正交性、再推到 linear LMS（线性 LMS）降级版的根本原因。换成别的损失，这条流水线当场断掉。
>
> 跨课程连接放在 CLRS 算法导论里最清楚：比较排序的 $\Omega(n \log n)$ 下界只在"只许比较"的代价模型里成立，一旦允许字长 RAM 上的计数排序，同一问题的下界立刻掉到 $\Omega(n)$。同一个任务，"最优"随代价模型改口。区别在于谁有权定代价模型——算法分析里代价模型是题目给定的，你无权挑；统计里 loss 是你自己声明的，声明错了就会得到一个在该 loss 下最优、在你真正关心的事情上很差的估计器。所以这一讲把"选 loss"从纯数学问题提升成了一次建模决策。
>
> 收束回正文一句：MAP 与 LMS 不是新旧替代关系，而是两条不相交的坐标轴；后面全部内容——条件均方误差、误差的正交性质、以及"只许线性"的降级版——都只在 LMS 这一条轴上重复展开。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Conditional mean squared error（条件均方误差）</span>

- $\mathrm{E}[(\Theta - \mathrm{E}[\Theta \mid X])^2 \mid X = x]$：
  - 与 $\mathrm{Var}(\Theta \mid X = x)$ 相同：$\Theta$ 的 conditional distribution（条件分布）的 variance（方差）。

> <span style="color:#7f8c8d;">Bertsekas §8.3, p.430–431</span>

---

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Predicting X based on Y（用 $Y$ 预测 $X$）</span>

- 两个随机变量 $X, Y$；观测到 $Y = y$。
  - 新宇宙：condition on（条件化于）$Y = y$。
- $\mathrm{E}[(X - c)^2 \mid Y = y]$ 在 $c = \underline{\qquad}$ 处取最小。

> <span style="color:#7f8c8d;">Bertsekas §8.3, p.430–431；§4.3, p.225–226</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 证明策略模板）:**</span> 这一页要干三件事：验一个恒等式、填一个空、立一个能反复用的证明骨架。恒等式是"条件均方误差等于条件方差"，空是那个让二次代价最小的常数，骨架则是把"逐点最优"升级成"全局最优"的那条通路——后面 LMS 的全部结论，包括线性降级版，都挂在这条通路上。
>
> 先验第一件。条件化到 $X = x$ 之后，$x$ 就是一个常数，$\mathrm{E}[\Theta \mid X = x]$ 也是一个常数；于是这就是"围绕某个常数的二阶矩"这条老恒等式的直接套用：把 $(\Theta - a)^2$ 展成 $\Theta^2 - 2a\Theta + a^2$，逐项取条件期望，得到 $\mathrm{E}[\Theta^2 \mid X = x] - 2a\,\mathrm{E}[\Theta \mid X = x] + a^2$，再令 $a = \mathrm{E}[\Theta \mid X = x]$，后两项恰好合并成 $-\bigl(\mathrm{E}[\Theta \mid X = x]\bigr)^2$。剩下的就是"二阶矩减一阶矩平方"，即条件方差。这一步之所以能无条件成立，是因为方差定义本身没有用到 $\Theta$ 与 $X$ 的任何关系，只用到"在一个给定的宇宙里算二阶中心矩"。
>
> 再验第二件，也就是幻灯片上的那个空。把 $\mathrm{E}[(X - c)^2 \mid Y = y]$ 展开成 $\mathrm{E}[X^2 \mid Y = y] - 2c\,\mathrm{E}[X \mid Y = y] + c^2$，对 $c$ 求导得 $-2\,\mathrm{E}[X \mid Y = y] + 2c$，置零读出 $c = \mathrm{E}[X \mid Y = y]$；二阶导数恒等于 $2$，所以这不是驻点而是全局最小值，抛物线开口朝上、顶点唯一。这个空看似平凡，却把"用什么常数去猜最能减少平方误差"这件事彻底封死了：不需要任何分布假设，只需要条件均值存在。
>
> 拿一组能心算的数字把收益量出来。设 $\Theta$ 取 $0$ 或 $1$，先验 $\mathrm{P}(\Theta = 1) = 0.4$；给定 $\Theta = 0$ 时 $X$ 取 $0, 1$ 的概率是 $0.8, 0.2$，给定 $\Theta = 1$ 时是 $0.3, 0.7$。于是 $\mathrm{P}(X = 0) = 0.6$、$\mathrm{P}(X = 1) = 0.4$，贝叶斯公式给出 $\mathrm{P}(\Theta = 1 \mid X = 0) = 0.2$、$\mathrm{P}(\Theta = 1 \mid X = 1) = 0.7$。条件方差分别是 $0.16$ 与 $0.21$，加权平均得 LMS 的均方误差 $0.18$。若干脆不看观测、一律报先验均值 $0.4$，均方误差就是 $\mathrm{var}(\Theta) = 0.24$。省下的 $0.06$ 恰好等于 $\mathrm{var}\bigl(\mathrm{E}[\Theta \mid X]\bigr)$：$0.22$ 减 $0.16$——观测能买到多少精度，可以被精确记账，而不是一句"信息更多所以更好"。
>
> 现在立模板，名字叫"逐点打包、再合并"。要证 $\mathrm{E}[(\Theta - \mathrm{E}[\Theta \mid X])^2] \le \mathrm{E}[(\Theta - g(X))^2]$ 对一切函数 $g$ 成立，第一步固定 $x$，把 $g(x)$ 当成一个候选常数，用上一段的抛物线结论得到逐点不等式；第二步注意到这一步对每个 $x$ 都成立，等价于"以 $X$ 为条件的两个随机变量满足 $\le$ 几乎必然成立"；第三步取期望，靠期望算子的保序性（若 $A \le B$ 几乎必然则 $\mathrm{E}[A] \le \mathrm{E}[B]$）把它抬成全局不等式。这三步里最容易被忽略的是第二步到第三步的"几乎必然"：如果只在"绝大多数 $x$"上逐点最优，那么极少数 $x$ 上的巨额超额损失可以把全局算账整个翻过来，所以必须逐点全胜，不能允许例外。
>
> 补一段历史坐标，说明这条准则为什么在两百年里反复被重新发现。最小二乘最早由 Legendre 在 1805 年公开发表，用于彗星轨道拟合；Gauss 在 1809 年的著作里主张自己 1795 年就已使用，并给出了误差服从正态分布时最小二乘恰为最大似然估计的推导，两人的优先权之争于是成了统计史上一桩公案。这段历史给出的教训不是谁先谁后，而是：平方误差并不是从抽象公理推出来的，它长在"测量误差左右对称、小误差远比大误差常见"这类经验事实上面；一旦误差分布重尾，平方误差就会被个别离群点绑架，改用绝对值或 Huber 型损失才合理。
>
> 跨课程连接落在 CLRS 的最优子结构上：分治算法要得到全局最优，必须每一层子问题都取到它自己的最优解，而"子问题最优"与"全局目标一致"这件事在贪心里会失效（带负权时就翻车）。这里的保序性就是那个一致性条件的概率版本——期望算子把"每个分支都不差"忠实地翻译成"整体不差"。区别在于，算法里的一致性靠交换论证或递推单调性手工验证，概率里的一致性由期望的线性与单调性一次性供给。
>
> 最后收束回"用 $Y$ 预测 $X$"那一页：它和"用 $X$ 估计 $\Theta$"是同一个定理换了座位，只是被条件化的变量换了名字。这也解释了为什么 LMS 同时是参数估计与预测理论的地基——两者的数学内容完全相同，只差你把哪个变量叫作"未知量"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Some properties of LMS estimation（LMS 估计的若干性质）</span>

- Estimator（估计器）：$\hat\Theta = \mathrm{E}[\Theta \mid X]$。
- Estimation error（估计误差）：$\tilde\Theta = \hat\Theta - \Theta$。
- $\mathrm{E}[\tilde\Theta] = 0$，且 $\mathrm{E}[\tilde\Theta \mid X = x] = 0$。
- $\mathrm{E}[\tilde\Theta\, h(X)] = 0$，对任意函数 $h$。
- $\mathrm{cov}(\tilde\Theta, \hat\Theta) = 0$。
- 由 $\Theta = \hat\Theta - \tilde\Theta$：
```math
\mathrm{var}(\Theta) = \mathrm{var}(\hat\Theta) + \mathrm{var}(\tilde\Theta) .
```

> <span style="color:#7f8c8d;">Bertsekas §8.3, p.434–436</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断 + 跨课程连接）:**</span> 这五条性质不是五个独立的小结论，而是同一句话的五种说法：估计误差与"一切能由 $X$ 算出来的量"都不相关。抓住这一句，其余四条都是它的推论；抓不住，就得逐条背，背完还是不知道为什么方差能拆成两块。
>
> 先把机制的正中心说清：为什么"正交"恰好等价于"最优"。取任意函数 $h$，考虑一族估计器 $\hat\Theta + \varepsilon h(X)$，它把当前估计沿 $h$ 这个方向挪一点点。把代价 $\mathrm{E}[(\Theta - \hat\Theta - \varepsilon h(X))^2]$ 看作 $\varepsilon$ 的函数，求导得 $-2\,\mathrm{E}\bigl[(\Theta - \hat\Theta)h(X)\bigr]$，再改写成本条记号就是 $2\,\mathrm{E}[\tilde\Theta\, h(X)]$。若这个量不为零，就存在一个符号合适的 $\varepsilon$ 让代价下降——也就是说，误差与某个特征相关，这个相关本身就是一条"还能改进"的下坡路。反过来，若对每个 $h$ 都有 $\mathrm{E}[\tilde\Theta h(X)] = 0$，一阶导数为零，而代价关于 $\varepsilon$ 是开口朝上的二次函数，一阶条件在这里既必要又充分，于是没有任何方向能改进。正交性因此不是几何装饰，而是可操作的最优性判据。
>
> 第三条性质的验证只要一步：$\mathrm{E}[\tilde\Theta h(X)] = \mathrm{E}\bigl[\mathrm{E}[\tilde\Theta \mid X]\, h(X)\bigr] = \mathrm{E}[0 \cdot h(X)] = 0$，中间那一步是把 $h(X)$ 当常数提到内层条件期望外面，用的仍是重期望法则。取 $h$ 为指示函数就得到"条件误差逐点为零"，取 $h = \hat\Theta$ 就得到协方差为零，取 $h \equiv 1$ 就得到误差均值为零——五条性质一次性归位。
>
> 拿上一段那组数字做一次完整的勾股验算。$\Theta$ 取 $0$ 或 $1$、$\mathrm{P}(\Theta = 1) = 0.4$，$\mathrm{P}(\Theta = 1 \mid X = 0) = 0.2$、$\mathrm{P}(\Theta = 1 \mid X = 1) = 0.7$。逐点误差是 $0.2 - 0.2 = 0$ 与 $0.7 - 0.7 = 0$，正交性直接肉眼可见。$\mathrm{E}[\hat\Theta^2] = 0.6 \times 0.04 + 0.4 \times 0.49 = 0.22$，$\mathrm{E}[\hat\Theta] = 0.4$，故 $\mathrm{var}(\hat\Theta) = 0.06$；$\mathrm{var}(\Theta) = 0.24$；于是 $\mathrm{var}(\tilde\Theta) = 0.18$，而 $0.06 + 0.18 = 0.24$ 分毫不差。这个 $0.18$ 正是上一节算出的均方误差——勾股关系把"总不确定性"劈成"被观测解释掉的部分"与"解释不掉的部分"。
>
> 顺带把一个易混的诊断说透：什么时候观测毫无信息？当且仅当 $\mathrm{var}(\tilde\Theta) = 0$，也就是剩余不确定性消失、$\hat\Theta$ 恒等于 $\Theta$、$\Theta$ 是 $X$ 的函数。这个方向容易记。难的是逆命题不成立：条件均值恒等于常数并不推出独立。构造一个反例——让 $X$ 等概率取 $0$ 或 $1$；$X = 0$ 时 $\Theta$ 等概率取 $-1$ 与 $1$，$X = 1$ 时 $\Theta$ 等概率取 $-2, 0, 2$。两种情形下条件均值都是 $0$，可 $\Theta$ 的条件分布明显不同，$\Theta$ 与 $X$ 当然不独立。教训是：条件均值只保存一阶信息，方差的差异它一概看不见——这正是下一节相关系数为零时线性 LMS 失效的同一种盲区。
>
> 跨课程连接用 Strang 线性代数的语言最省力：$\hat\Theta = \mathrm{E}[\Theta \mid X]$ 是把 $\Theta$ 正交投影到"$X$ 的一切函数"所张成的空间上，$\mathrm{E}[\tilde\Theta h(X)] = 0$ 就是投影的正交方程，和最小二乘里的 $A^{\mathrm T} e = 0$ 形状一模一样；方差分解则对应勾股定理 $\|b\|^2 = \|p\|^2 + \|e\|^2$。区别有两处：内积在这里是 $\mathrm{E}[uv]$ 而不是逐坐标求和，于是"维数"可能是无穷的；另外线性代数里投影矩阵是给定的，这里投影算子 $\mathrm{E}[\cdot \mid X]$ 随 $X$ 的分布一起变动，你得先有概率模型才能写出它。
>
> 最后一句卡点预警：$\tilde\Theta$ 的符号约定（这里取估计减真值）不影响任何结论，换一本教材读到相反定义时不必慌，只要在所有公式里统一即可——正交性与方差分解对符号都不敏感。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Linear LMS（线性 LMS）</span>

- 考虑形如 $\hat\Theta = aX + b$ 的估计器。
- 最小化 $\mathrm{E}[(\Theta - aX - b)^2]$。
- $a, b$ 的最优选择；最优线性估计器（best linear estimator）：
```math
\hat\Theta_L = \mathrm{E}[\Theta] + \frac{\mathrm{Cov}(X, \Theta)}{\mathrm{var}(X)}\,\bigl(X - \mathrm{E}[X]\bigr) .
```

> <span style="color:#7f8c8d;">Bertsekas §8.4, p.437–438</span>

---

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Linear LMS properties（线性 LMS 的性质）</span>

```math
\mathrm{E}\bigl[(\hat\Theta_L - \Theta)^2\bigr] = (1 - \rho^2)\,\sigma_\Theta^2 .
```

> <span style="color:#7f8c8d;">Bertsekas §8.4, p.438–439</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证）:**</span> 这一页的推导值得完整走一遍，因为它同时暴露了一个方法论：当被优化的对象被限制在一个"参数化的小家族"里时，最优性条件会退化成有限条正交方程，解方程就等于求最优。线性 LMS 就是这么被解出来的，而且整个解只用到二阶矩。
>
> 第一步先消掉 $b$。固定 $a$ 之后，$\mathrm{E}[(\Theta - aX - b)^2]$ 其实是"用常数 $b$ 去估计随机变量 $\Theta - aX$"的平方误差，而上一页已经证明常数估计的均方最优解就是均值，于是 $b = \mathrm{E}[\Theta - aX] = \mathrm{E}[\Theta] - a\,\mathrm{E}[X]$。这一步之所以能单独做，是因为 $b$ 只平移估计器的位置、不改变它以什么比例跟随 $X$；把平移量先按均值对齐，剩下的问题就纯粹关于"斜率取多少"。
>
> 第二步解 $a$。把 $b$ 代回，目标变成 $\mathrm{E}\bigl[(\Theta - \mathrm{E}[\Theta] - a(X - \mathrm{E}[X]))^2\bigr]$，也就是 $\mathrm{var}(\Theta - aX)$，展开成 $\sigma_\Theta^2 + a^2\sigma_X^2 - 2a\,\mathrm{cov}(\Theta, X)$。对 $a$ 求导置零得 $a = \mathrm{cov}(\Theta, X)/\sigma_X^2$，写成相关系数的形式就是 $a = \rho\,\sigma_\Theta/\sigma_X$；二阶导是 $2\sigma_X^2 > 0$，所以这是唯一的全局最小点——只要 $\sigma_X^2$ 不为零，问题就没有第二个山谷。
>
> 换个角度重推一次，能看出更本质的结构：两个未知数 $a, b$，对应的最优性条件是两条正交方程 $\mathrm{E}[\tilde\Theta] = 0$ 与 $\mathrm{E}[\tilde\Theta X] = 0$，展开成矩阵就是 $\begin{bmatrix} 1 & \mathrm{E}[X] \ \mathrm{E}[X] & \mathrm{E}[X^2] \end{bmatrix}\begin{bmatrix} b \ a \end{bmatrix} = \begin{bmatrix} \mathrm{E}[\Theta] \ \mathrm{E}[\Theta X] \end{bmatrix}$。两个方程定两个未知数，解唯一。这就是"第一性原理"层面的答案：线性家族只有两个自由度，而最优性恰好压上两个约束，不多不少，于是解被完全确定；自由度多于约束就有无穷多解，少于约束就无解。
>
> 代入具体数字体检一遍。取 $\sigma_\Theta = 2$、$\sigma_X = 1$、$\rho = 0.5$、$\mathrm{E}[\Theta] = 10$、$\mathrm{E}[X] = 8$，则 $a = 0.5 \times 2 / 1 = 1$、$b = 10 - 8 = 2$，估计器是 $\hat\Theta_L = X + 2$。代回代价公式，均方误差是 $(1 - 0.25) \times 4 = 3$，相对先验方差 $4$ 削减了四分之一，而这个比例恰好是 $\rho^2$。再做两组对照：把 $\rho$ 提到 $0.9$，$a$ 变成 $1.8$，均方误差掉到 $0.19 \times 4 = 0.76$，削减八成以上；把 $\rho$ 压到 $0$，$a = 0$，估计器退化成常数 $10$，均方误差回到 $4$，一个比特的线性信息都没榨到。
>
> 顺手核一下正交性，确认这套解真的站在最优位置上：$\mathrm{E}[X^2] = 1 + 64 = 65$，$\mathrm{E}[\Theta X] = 0.5 \times 2 \times 1 + 80 = 81$；而 $\mathrm{E}[\hat\Theta_L X] = \mathrm{E}[X^2 + 2X] = 65 + 16 = 81$，两者相等，误差与 $X$ 的内积为零。这不是巧合，而是上一条注里"正交即最优"的直接兑现。
>
> 两个极端对应的直觉要分开记：$|\rho| = 1$ 时 $\Theta$ 与 $X$ 严格落在一条直线上，$a, b$ 把它一网打尽，误差为零；$\rho = 0$ 时线性 LMS 报常数，但**这只宣判线性估计器无能，不宣判条件期望等于常数**。反例前面已经给过：条件均值恒为零、条件方差却随 $X$ 变化的情形，线性 LMS 完全看不见，通用 LMS 却看得见。这条分界线就是后面"选择观测量"那一页的伏笔。
>
> 跨课程连接放在 Strang 的最小二乘拟合上：那里的正规方程 $A^{\mathrm T}A\hat x = A^{\mathrm T}y$ 与这里的 $2 \times 2$ 方程组是同一个东西，只是把"样本求和"换成了"期望"。区别在于待估对象不同——回归里 $a, b$ 是未知常数、$y$ 是数据；这里 $\Theta$ 是随机变量、$a, b$ 是用来预测它的工具，我们优化的不是"拟合残差"而是"预测误差的期望"。也正因为要取期望，答案才只依赖协方差这一层，而不依赖联合分布的细节。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Linear LMS with multiple data（多观测数据的线性 LMS）</span>

- 考虑形如下式的估计器：
```math
\hat\Theta = a_1 X_1 + \cdots + a_n X_n + b .
```
- 找出 $a_1, \ldots, a_n, b$ 的最优选择；最小化：
```math
\mathrm{E}\bigl[(a_1 X_1 + \cdots + a_n X_n + b - \Theta)^2\bigr] .
```
- 令各导数为零——得到关于 $b$ 与各 $a_i$ 的 linear system（线性方程组）。
- 只有 means（均值）、variances（方差）、covariances（协方差）起作用。

> <span style="color:#7f8c8d;">Bertsekas §8.4, p.439–441</span>

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板 + 跨课程连接）:**</span> 这一页把单观测的结论原样推广到 $n$ 个观测，但真正要带走的是一个模板：**当目标函数是参数的二次型时，最优性条件必然是一组线性方程，解方程就是求最优**。名字可以叫"导数置零得正规方程"，后面凡是"平方误差 + 线性家族"的场合都能直接套。
>
> 先说为什么一定会线性。目标 $\mathrm{E}\bigl[(a_1X_1 + \cdots + a_nX_n + b - \Theta)^2\bigr]$ 展开之后，关于每个 $a_i$ 与 $b$ 最高只出现二次项，交叉项是 $a_ia_j\mathrm{E}[X_iX_j]$、$a_ib\,\mathrm{E}[X_i]$ 这类形状，一次项是 $a_i\mathrm{E}[\Theta X_i]$、$b\,\mathrm{E}[\Theta]$ 这类形状，没有三次及以上的项。于是梯度关于参数是线性的，置零得到的必然是一个线性方程组；又因为二次型的二次项矩阵是协方差矩阵（半正定），问题没有局部极小之外的陷阱，驻点即全局最优点。若目标里出现 $a^3$ 或 $\log a$，这个模板当场失效——非二次的目标求导后仍是非线性方程，只能迭代。
>
> 这套方程只吃均值、方差、协方差三类数字，原因也在这里：系数矩阵的每个元素都是 $\mathrm{E}[X_iX_j]$、$\mathrm{E}[X_i\Theta]$ 这样的二阶量，加上一个常数项 $\mathrm{E}[\Theta]$。凡是能匹配这些二阶量的模型，无论它背后的联合分布是正态、均匀还是双峰，线性 LMS 给出的估计器一模一样。这就是"只有前二阶矩起作用"的确切含义——它不是一句修辞，而是展开式里除了二阶项再没有别的原料可用。
>
> 拿两个传感器做一次可代入的演算。设 $X_i = \Theta + W_i$，先验 $\Theta \sim (\mu, \sigma_0^2) = (0, 2)$，噪声 $\sigma_1^2 = 1$、$\sigma_2^2 = 3$，观测到 $X_1 = 1$、$X_2 = 2$。按精度加权，权重分别是 $1/2$、$1/1$、$1/3$，分母是 $1.8333$，分子是 $0 + 1 + 0.6667 = 1.6667$，于是 $\hat\Theta_L \approx 0.909$。注意这个数离 $X_1$ 更近、离 $X_2$ 更远，虽然 $X_2$ 数值更大：决定权重的不是观测值大小，而是它的可靠性。若两个观测的噪声方差相差十倍，最优线性估计会几乎完全倒向更准的那一个，另一个的存在感接近于零。
>
> 更深一层：为什么贝叶斯线性 LMS 与经典的普通最小二乘长得很像、又不等同？这就牵到 Gauss-Markov 这条线索。Gauss-Markov 定理说的是：当误差均值为零、互不相关且方差相同，普通最小二乘在所有"线性且无偏"的估计量里方差最小，并且这个结论不需要误差服从正态分布——Gauss 的工作可追到 1821 年前后，Markov 在 1900 年补上严格表述。经典回归里 $\Theta$ 被当作固定常数，你被迫要求估计量无偏，于是没有"往先验中心收缩"的余地；贝叶斯版本把 $\Theta$ 当随机变量，先验提供了一个天然的中心，允许估计有偏，代价换来方差更小——两者之差正是先验信息的价格。所以贝叶斯线性 LMS 可以读作"带先验收缩的最小二乘"。
>
> 跨课程连接落在 Strang 线性代数的正规方程上。那里的 $A^{\mathrm T}A\hat x = A^{\mathrm T}y$ 说的是"残差正交于列空间的每一列"，这里的方程说的是"估计误差正交于 $1, X_1, \ldots, X_n$ 这 $n+1$ 个方向"，形状完全同构：$A$ 的列在这里是"常数函数与各个观测函数"，$y$ 在这里是 $\Theta$。区别在于，回归里 $A$ 由样本数据填成、方程一次性解完；概率里每一项都是期望、需要模型才能填，但一旦填好，求解过程与最小二乘逐字相同。
>
> 最后点一下这条路的双重性格：因为它只要二阶矩，所以便宜——不必知道联合分布，采样式地把均值方差协方差估出来就能算；也因为只要二阶矩，所以上限被锁死——真实的条件均值若靠高阶结构（比如 $X$ 与 $\Theta$ 通过 $X^2$ 相关），它一点也看不到。便宜与上限低是同一枚硬币的两面，下一页"最干净的例子"会展示它在什么条件下能追平通用 LMS。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The cleanest linear LMS example（最干净的线性 LMS 例子）</span>

- $X_i = \Theta + W_i$，其中 $\Theta, W_1, \ldots, W_n$ 相互 independent（独立）；
- $\Theta \sim (\mu, \sigma_0^2)$，$W_i \sim (0, \sigma_i^2)$：
```math
\hat\Theta_L = \frac{\mu/\sigma_0^2 + \sum_{i=1}^{n} X_i/\sigma_i^2}{\sum_{i=0}^{n} 1/\sigma_i^2}
```
  （$\mu, X_1, \ldots, X_n$ 的 weighted average（加权平均））。
- 若全部分布都是 normal（正态）的，则 $\hat\Theta_L = \mathrm{E}[\Theta \mid X_1, \ldots, X_n]$。

> <span style="color:#7f8c8d;">Bertsekas §8.4, p.442</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 跨课程连接）:**</span> 这一页的公式长得像个加权平均，实际上说的是一个更强的道理：**独立观测的精度可以相加**。理解这一点，就不必记公式，遇到新的融合问题能自己推。
>
> 先把机制从第一性原理起。设两个估计量 $Z_1, Z_2$ 都是 $\Theta$ 的无偏估计、彼此独立，方差分别是 $v_1, v_2$。考虑组合 $wZ_1 + (1-w)Z_2$，它的方差是 $w^2v_1 + (1-w)^2v_2$，对 $w$ 求导置零得 $w \propto 1/v_1$，最小值是 $1/(1/v_1 + 1/v_2)$。把 $1/v$ 称为精度，结论就是一句：**精度可加，方差取倒数后再相加**。幻灯片上的公式只不过是把这个结论推广到 $n$ 个独立观测，外加把先验当作第零个观测——先验本身也是一个关于 $\Theta$ 的无偏信息来源，方差 $\sigma_0^2$、均值 $\mu$。
>
> 用 $n = 1$ 验算一遍，确认它和单观测的线性 LMS 是同一件事。$\mathrm{cov}(\Theta, X_1) = \mathrm{cov}(\Theta, \Theta + W_1) = \sigma_0^2$，$\mathrm{var}(X_1) = \sigma_0^2 + \sigma_1^2$，代入 $a = \mathrm{cov}/\mathrm{var}$ 得 $a = \sigma_0^2/(\sigma_0^2 + \sigma_1^2)$，于是 $\hat\Theta_L = \mu + a(X_1 - \mu)$。把它通分重排，恰好等于 $\dfrac{\mu/\sigma_1^2 + X_1/\sigma_0^2}{1/\sigma_1^2 + 1/\sigma_0^2}$——形式与精度加权完全一致。注意这里权重的分母是"另一个"的方差：先验的权重由观测噪声决定，观测的权重由先验方差决定，两者互为对方的可信度标尺。
>
> 代入一组数字看量级。取先验 $\mu = 5$、$\sigma_0^2 = 4$，两个传感器噪声 $\sigma_1^2 = 1$、$\sigma_2^2 = 0.5$，读数 $X_1 = 5.4$、$X_2 = 5.2$。精度分别是 $0.25, 1, 2$，总精度 $3.25$，估计方差 $1/3.25 \approx 0.308$；估计值为 $(5 \times 0.25 + 5.4 \times 1 + 5.2 \times 2)/3.25 = 17.05/3.25 \approx 5.246$。关键对比：单个最好的传感器精度是 $2$、方差 $0.5$，把三个信息源合并后方差掉到 $0.308$，比最强的单个还低四成。换句话说，与其换一个贵十倍的传感器，不如再买两个平庸的传感器——只要它们彼此独立，精度是可以攒起来的。
>
> 正态分布那一行是这页的高潮：当先验与噪声都是正态分布时，线性 LMS 恰好等于真正的后验均值，线性家族的上限被顶到了天花板。机制在于正态分布族对"取条件"封闭——正态先验配正态似然，后验仍是正态，而正态分布的均值就是它的峰，于是 MAP、LMS、线性 LMS 三者重合。这也是教材里那个经典例子的原型：多个传感器测同一个常数，噪声独立正态，后验均值的精度就是各精度之和。
>
> 跨课程连接有两处。第一处是 CSAPP 的存储层次：cache 按延迟分层、按局部性决定谁服务谁，多个层次之间是互斥替换关系；这里的多个信息源不是替换而是并存加权，各自保留一点话语权，权重由可靠性决定。差别在于 cache 的目标是命中率与延迟，融合的目标是最小化均方误差，一个是策略问题一个是统计问题。第二处是信号处理里的 Kalman filter（卡尔曼滤波器）：把上面这套"先验提供旧估计、新观测提供似然、按精度分配权重"的更新过程递归化，每一步只用上一时刻的后验与当前观测，不必保存全部历史——这正是 Kalman 在 1960 年那篇论文里给出的形式，论文题为 A New Approach to Linear Filtering and Prediction Problems，刊于 Journal of Basic Engineering 第 82 卷。
>
> 收束回正文：这一页把"最干净的线性 LMS 例子"变成了一句可复用的工程口诀——**按精度加权，精度可加，方差取倒数**。后面遇到任何"多源信息融合"的场景，先问三件事：各源是否无偏、是否独立、方差多大；三个答案齐了，公式自己就长出来了。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Choosing Xi in linear LMS（线性 LMS 中观测量的选择）</span>

- $\mathrm{E}[\Theta \mid X]$ 与 $\mathrm{E}[\Theta \mid X^3]$ 相同。
- Linear LMS 则不同：
  - $\hat\Theta = aX + b$ 与 $\hat\Theta = aX^3 + b$ 不一样；
  - 也可考虑 $\hat\Theta = a_1 X + a_2 X^2 + a_3 X^3 + b$。

> <span style="color:#7f8c8d;">Bertsekas §8.4, p.437–443</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理 + 卡点诊断）:**</span> 这一页只有两行结论，却藏着整讲的哲学分水岭：**通用 LMS 只看"信息"，线性 LMS 还看"你用什么坐标表示信息"**。前者对数据的可逆重编码免疫，后者不免疫——这个差别决定了后面一切关于特征选择的工程实践。
>
> 先回答为什么 $\mathrm{E}[\Theta \mid X] = \mathrm{E}[\Theta \mid X^3]$。条件期望的本质是"按观测值把样本空间切成格子，再在每个格子里取平均"。立方映射是一一且双向可解的：给定 $x$ 唯一确定 $x^3$，给定 $x^3$ 唯一反解出 $x$。于是"按 $X$ 切"与"按 $X^3$ 切"切出的是同一套格子，格子里的成员一模一样，格子内的平均当然一模一样。反过来说，只要变换丢掉了信息，等式立刻破裂：拿 $X^2$ 去代替 $X$，符号信息没了，若 $\Theta$ 恰恰依赖符号，条件期望就会变。
>
> 机制的关键在"函数族对变换是否封闭"。通用 LMS 在所有函数的汪洋里搜索，任何 $g(X^3)$ 都能改写成一个关于 $X$ 的函数，所以换坐标不改变可搜索的范围，答案自然不变。线性 LMS 只在 $\mathrm{span}\{1, X\}$ 这条直线上搜索，换成 $X^3$ 之后搜索范围变成 $\mathrm{span}\{1, X^3\}$——这是另一条直线，两条直线只在特殊分布下才重合。搜索范围变了，答案当然变。
>
> 给一个能完整手算的对照。设 $X$ 在 $[-1, 1]$ 上均匀分布，$\Theta = X^3$，于是 $\Theta$ 由 $X$ 完全确定，条件期望就是 $X^3$ 本身，用 $X$ 还是用 $X^3$ 做观测都得到同一个答案。可线性 LMS 的遭遇完全不同：若只喂 $X$，$\mathrm{cov}(X, \Theta) = \mathrm{E}[X^4] = 1/5$，$\mathrm{var}(X) = 1/3$，$\mathrm{var}(\Theta) = \mathrm{E}[X^6] = 1/7$，相关系数平方为 $0.84$，均方误差是 $(1 - 0.84) \times 1/7 \approx 0.023$——看着很小，可真相是误差本该为零。若改喂 $X^3$，$\mathrm{cov}(X^3, \Theta) = \mathrm{var}(X^3) = 1/7$，斜率算出来正好是 $1$、截距为零，均方误差归零。同一份数据、同样的线性估计器，只因为换了一个写法，代价从 $0.023$ 掉到零。
>
> 这就是本条要立的卡点诊断：**"线性"是一个关于坐标的承诺，不是一个关于本质的性质**。同一个随机变量，写成 $X$ 时它承载的信息是"$X$ 的全部"，但线性 LMS 只抽取其中与 $X$ 线性相关的那一薄片；写成 $X^3$ 时它抽取的是另一薄片。想知道模型看见了什么，得问"我喂进去的这几个基函数张成的空间有多大"，不能只问"我喂了几路数据"。
>
> 跨课程连接有两条。第一条是 6.042J 的划分与等价关系：把"按观测切格子"读成"由观测诱导的等价关系"，可逆变换诱导同一个划分，所以信息等价。这条视角解释了通用 LMS 的不变性与丢信息的代价，但它对线性 LMS 的差异一言不发——因为划分只说"哪些点被分到一起"，不说"你用什么函数族去拟合"。两个视角的分工正好在这里显出必要性。第二条是 CLRS 里 key 的表示决定算法能力：基数排序要求 key 能按位分解，同一批整数换一种编码，可达的最优算法就换了。数据没变，表示变了，能用的工具就变了。
>
> 工程结论落在最后一行：既然搜索空间由你提供的基函数张成，那就把 $X, X^2, X^3$ 一起喂进去，让 $\mathrm{span}$ 变大，让线性估计器在更大的空间里找最优。这套做法的名字叫特征工程，逻辑起点就是这一页——模型不是不聪明，是它的视野被你给的坐标锁死了。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Big picture（全局图景）</span>

- **标准例子**（standard examples）：
  - $X_i$ 在 $[0, \theta]$ 上 uniform（均匀分布）；对 $\theta$ 取 uniform prior（均匀先验）。
  - $X_i \sim \mathrm{Bernoulli}(p)$（伯努利）；对 $p$ 取 uniform（或 Beta）先验。
  - $X_i$ 服从均值 $\theta$、已知方差 $\sigma^2$ 的 normal（正态分布）；对 $\theta$ 取正态先验；模型为 $X_i = \Theta + W_i$。
- **估计方法**（estimation methods）：
  - MAP。
  - LMS。
  - 线性 LMS。

> <span style="color:#7f8c8d;">Bertsekas §8.1–8.2, p.412–429；§8.5, p.444–445</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 这一页把第 8 章的家底一次摊开。它不是复习清单，而是一张"可解性地图"：三个标准例子各自代表一种让后验**能被算出来**的结构，三种估计方法各自代表一种"只要多少东西就能干活"的报价。
>
> 先说三个例子为什么偏偏是这三个。均匀先验配均匀观测，代表"手工可枚举"的一路：后验靠区间端点的排序统计量直接写出来，不需要任何特殊函数，代价是积分要一段段算。伯努利配 Beta 先验，代表"共轭族"的一路：先验与似然属于同一族，乘起来之后后验仍是同族，只需更新两个参数，"先验吸收数据后形状不变"。正态配正态，代表"线性高斯"的一路：取条件运算在这个族里封闭，后验均值是精度加权、后验方差是精度倒数——上一节那个最干净的例子就是它的化身。三种结构对应三种可算性来源，这是本章的分类学，比记住三个公式有用得多。
>
> 用伯努利那条线做一次带数字的演算。取 Beta 先验，参数全为 $2$，相当于先验样本里"两成一败"；观测 $n = 10$ 次、成功 $7$ 次。后验参数变成 $9$ 与 $5$，均值 $9/14 \approx 0.643$，众数 $8/12 \approx 0.667$，而最大似然估计是 $0.7$。三个数字排成一列就看出结构：贝叶斯估计被先验往 $0.5$ 拉，$0.643 < 0.7$，拉动幅度由先验的"虚拟样本量" $4$ 与真实样本量 $10$ 的比例决定。把先验换成参数 $20$ 与 $20$，虚拟样本量变成 $40$，后验均值立刻被压到 $(27)/(50) = 0.54$，几乎不听数据。这正是前文 b 项的同一个机制在两个坐标下的投影：**先验强就收缩得狠，数据多就顶得住**。
>
> 再看三种方法的报价单，选型逻辑其实是成本核算。MAP 最便宜：只要后验的峰，不必做积分，离散时甚至只需比较几个概率；代价是它不问错多远，遇到偏斜后验会给出系统偏差。LMS 最贵也最准：要完整的后验才能算条件均值，但它在平方损失下无可匹敌，且误差有正交性这类可用的结构。线性 LMS 居中：只要均值、方差、协方差三样，模型换掉也不影响答案，代价是视野被锁在基函数张成的子空间里。三者不是进步序列，是三种预算下的最优解。
>
> 最后一段的转折才是这一页真正的价值。到此为止所有讨论都建立在一个前提上：$\Theta$ 是随机变量、有先验。下一讲把这个前提掀掉——$\theta$ 变成一个固定的、未知的常数，没有先验可言，于是"平均意义上最优"这句话整个失效，评价标准必须改成"对每一个可能的 $\theta$ 都不差"。这不是换一套公式，而是换一套正确性定义。
>
> 跨课程连接放在 CLRS 的算法分析里最贴切：平均情况分析假设输入服从某个分布、对所有输入取期望，最坏情况分析则假设有一个对手专挑最难的那一个。贝叶斯统计就是"平均情况"——先验扮演输入分布的角色，结论只对该先验平均成立；经典统计就是"最坏情况"——不假设分布，要求对一切参数成立，通常以 minimax 的形式出现。区别在于对手是谁：算法里对手选输入，统计里对手选参数；而代价也一样——最坏情况结论更稳健但更保守，平均情况结论更锐利但依赖那个你未必有把握的分布假设。
>
> 收束一句：第 8 章从这里收尾，lens 从"后验最优"切到"对一切参数一致"，而本章剩下的三样工具——完整的后验、二阶矩、单个峰顶——会成为你在新坐标系里反复回来借用的小刀。
