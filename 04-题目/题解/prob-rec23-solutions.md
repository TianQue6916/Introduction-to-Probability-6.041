<span style="color:#c0392b;">**Recitation 13 解答（Recitation 13: Solutions）**</span> <span style="color:#7f8c8d;">（Fall 2010，2010 秋季学期；2010 年 10 月 21 日）</span>

<span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b;">**Problem 1**</span>

> <span style="color:#2471a3;">**[solution]**</span>
>
> **(a)** 我们先写出 $E[Z \mid X, Y]$ 的定义：
>
> > ```math
> > E[Z \mid X = x, Y = y] = \sum_z z\, p_{Z\mid X,Y}(z \mid x, y)
> > ```
>
> 由于 $E[Z \mid X, Y]$ 是随机变量 $X$ 与 $Y$ 的函数，并且在 $X = x$、$Y = y$ 发生时（该情况以概率 $p_{X,Y}(x, y)$ 发生）等于 $E[Z \mid X = x, Y = y]$，于是由 expected value rule（期望值法则，即：若 $W = g(X, Y)$ 是 $X, Y$ 的函数，则 $E[W] = \sum_x \sum_y g(x, y)\, p_{X,Y}(x, y)$），
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一行最容易被读错的地方，是把 $E[Z|X,Y]$ 当成一个数。它其实是两个层次套在一起：先在每一对具体数值上做一次加权平均，得到纯数字 $E[Z|X=x,Y=y]$；再把小写字母换回大写，这个「输入到数字」的对应关系就成了一张表，也就是一个函数；最后把这个函数作用到随机变量 $(X,Y)$ 上，输出才是新的随机变量。上面那条公式写的是第一层，本行开始进入第二层。阅读时把这条分界线钉住：小写字母进，大写字母出。混淆这两层的代价是后面每一行都读不通，因为 (b) 与 (c) 全靠「内层是随机变量」这件事才能再取条件、再取期望。
>
> 为什么必须长成这样，而不是一个常数。假如 $E[Z|X,Y]$ 真是常数，外层再取一次期望只会把它原样吐出来，「条件期望」与「无条件期望」就完全等同，含义变成「知道 $X$ 与 $Y$ 之后对 $Z$ 的预测没有任何改进」。但信息之所以有用，恰恰因为它能改变预测值：条件从一个取值换到另一个取值，预测数跟着跳，这个跳变本身携带全部信息量。把它压平成一个数字，等于一次性抹平回归、滤波、预测编码里所有「条件起作用」的地方；摄影计时、Kalman 滤波、语音编码里真正被传输和被优化的对象，从来不是那个平均数，而是整个条件分布的形状。
>
> 给一组能算到底的数。$X$ 取 0 或 1，取 1 的概率 0.6；$Y$ 取 0 或 1，取 1 的概率 0.5；两者独立；$Z = 3X + Y$。逐格算内层：条件 $X=0$ 时 $Z$ 只剩 $Y$，均值 0.5；条件 $X=1$ 时均值 $3+0.5=3.5$。于是内层变成一个只取两个值的随机变量：取 0.5 的概率 0.4，取 3.5 的概率 0.6。再在外层取期望：$0.4 \times 0.5 + 0.6 \times 3.5 = 0.2 + 2.1 = 2.3$。另一条路直接算：$3 \times 0.6 + 0.5 = 2.3$。两条路对上，这就是 (a) 要证的等式在这组数上的落地；注意第二条路根本没用到条件，这正是等式有内容的地方。
>
> 桥搭在哪一步。第三行到第四行那次合并是全篇唯一的实质动作：把「条件概率乘外层概率」合成联合概率。之所以能做，是因为 expected value rule（期望值法则）把「随机变量函数的期望」统一翻译成「对分布求和」，两层的差别因此只剩下标：内层对 $z$ 求和，外层对 $(x,y)$ 求和，合并后成三层求和，边际化再压掉外层两层，回到 $E[Z]$。整条链的结构是「三层求和、消元、认出目标」，没有新原理，只有下标管理。写证明时这招可以直接搬：凡是两层期望套在一起，先把它们展开成求和，再看乘法法则能不能把两组下标合并成同一个联合分布。
>
> 不做这一步会塌成什么样。若坚持内层是常数，就必须解释为什么「给定信息」会退化成「没有信息」，这与 (b) 直接冲突：(b) 的左边是对内层再取一次条件期望，只有内层本身是随机变量时才谈得上「对它取条件」。数目上也能看出问题：若内层恒为 2.3，它的方差是 0，可本例的实际方差是 $0.4 \times (0.5-2.3)^2 + 0.6 \times (3.5-2.3)^2 = 1.296 + 0.864 = 2.16$，非零。这个非零的量正是「信息有多值钱」的刻度：本例把它与内层条件方差 0.25 相加得 2.41，而直接对 $Z$ 展开得 $9 \times 0.24 + 0.25 = 2.41$，两面对上，law of total variance（全方差定律）在这里不是公式而是算术。
>
> 最后一句阅读提醒：本行说它是「$X$ 与 $Y$ 的函数」，其中「函数」是关键词而不是修饰语。读成修饰语，就退回到「一个大致的数」，(b) 与 (c) 的两层结构立刻失去支撑，读者只能在符号上滑过去，事后回忆不起为什么要多设一层。
>
> > ```math
> > \begin{aligned}
> > E\big[E[Z \mid X, Y]\big]
> > &= \sum_x \sum_y E[Z \mid X = x, Y = y]\, p_{X,Y}(x, y) \\
> > &= \sum_x \sum_y \sum_z z\, p_{Z\mid X,Y}(z \mid x, y)\, p_{X,Y}(x, y) \\
> > &= \sum_x \sum_y \sum_z z\, p_{X,Y,Z}(x, y, z) \\
> > &= E[Z].
> > \end{aligned}
> > ```
>
> 〔上面第三行用到乘法法则（multiplication rule）$p_{Z\mid X,Y}(z\mid x,y)\,p_{X,Y}(x,y) = p_{X,Y,Z}(x,y,z)$；第四行用到边际化（marginalization）$\sum_x\sum_y p_{X,Y,Z}(x,y,z) = p_Z(z)$，故 $\sum_z z\, p_Z(z) = E[Z]$。〕
>
> **(b)** 我们从 $E[Z \mid X, Y]$ 的定义出发——它是随机变量 $X$ 与 $Y$ 的函数，并且在 $X = x$、$Y = y$ 时等于 $E[Z \mid X = x, Y = y]$，因此
>
> > ```math
> > E[Z \mid X = x, Y = y] = \sum_z z\, p_{Z\mid X,Y}(z \mid x, y)
> > ```
>
> 仿照上面的步骤推进，但改为在事件 $X = x$ 上取条件，得
>
> > ```math
> > \begin{aligned}
> > E\big[E[Z \mid X, Y = y] \,\big|\, X = x\big]
> > &= \sum_y E[Z \mid X = x, Y = y]\, p_{Y\mid X}(y \mid x) \\
> > &= \sum_y \sum_z z\, p_{Z\mid X,Y}(z \mid x, y)\, p_{Y\mid X}(y \mid x) \\
> > &= \sum_y \sum_z z\, p_{Y,Z\mid X}(y, z \mid x) \\
> > &= E[Z \mid X = x].
> > \end{aligned}
> > ```
>
> 〔第三行用到条件形式的乘法法则 $p_{Z\mid X,Y}(z\mid x,y)\,p_{Y\mid X}(y\mid x) = p_{Y,Z\mid X}(y,z\mid x)$；第四行用到边际化 $\sum_y p_{Y,Z\mid X}(y,z\mid x) = p_{Z\mid X}(z\mid x)$。〕
>
> 由于上式对 $x$ 的一切可能取值都成立，故有 $E\big[E[Z \mid Y, X] \mid X\big] = E[Z \mid X]$。（$E[Z \mid Y, X]$ 与 $E[Z \mid X, Y]$ 是同一个随机变量，只是书写次序不同。）
>
> **(c)** 对 (b) 中公式的两边取期望，得
>
> > ```math
> > E\big[E[Z \mid X]\big] = E\big[E\big[E[Z \mid X, Y] \,\big|\, X\big]\big].
> > ```
>
> 由 law of iterated expectations（期望迭代法则，又称 tower property（塔性质），即 $E[Z] = E\big[E[Z \mid X]\big]$），上式左边即为 $E[Z]$，从而证得所要的结果。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一行是三个证明的收口处，值得把 (a)(b)(c) 当成一架梯子回看一遍，因为梯子的搭法可以原样搬到别处。三段不是并列关系，而是「无条件 → 条件世界 → 再回无条件」：先在原始分布上把恒等式证出来，再把同一套论证搬进「给定 $X=x$」的条件世界里重做一遍，最后两边取期望、用第一段把左边收成 $E[Z]$。认得出这个骨架，比记住结论有用得多。
>
> 每一段拆开都是同一套四步。第一步，把条件期望按定义展开成对 $z$ 的求和；第二步，用 multiplication rule（乘法法则）把「条件分布乘外层分布」合成一个联合分布，这是四步里唯一的实质动作；第三步，用 marginalization（边际化）把不需要的下标求和消掉；第四步，认出剩下的表达式正好是目标。以 (a) 为例，第二步把 $z$ 与 $(x,y)$ 合成三层下标，第三步再把 $(x,y)$ 两层压掉，剩下的就是 $E[Z]$，全程没有技巧可言，只有下标管理。
>
> 为什么 (b) 不能直接引用 (a)。(a) 的外层权重是联合分布，而 (b) 需要的外层权重是「给定 $X=x$ 之后的条件分布」，两者不是同一个分布；若把 (a) 直接套上去，等于默认「条件在 $X=x$ 上不改变关于 $Y$ 的任何概率」，而那正是独立性，一般并不成立。所以 (b) 只能把四步在条件世界里重跑一遍，这也解释了为什么 (b) 的第三行出现的是 $p_{Y|X}$ 而不是 $p_{X,Y}$：进了条件世界之后，$x$ 变成固定参数，不再有下标，能被求和的只剩 $y$。
>
> 顺带说清模板的适用范围：全概率公式其实是同一模板的低配版，那里被求平均的对象是一个事件的指示变量，只有一层求和，没有内层条件期望；而这里被求平均的对象本身就是一个条件期望，于是多出一层。看清「被求平均的是什么」，就知道该用低配还是完整版，不必把两条公式分开背，也不会在只有一层时误写两层。
>
> (c) 只有一行，但它不是补充说明，而是必要的封口：对 (b) 的两边取期望，(b) 的右边正好是 $E\big[E[Z|X]\big]$，(a) 又把它压成 $E[Z]$，于是内层多出来的那个 $Y$ 被彻底消掉。至于本行末尾那句「$E[Z|Y,X]$ 与 $E[Z|X,Y]$ 是同一个随机变量」，别当成排版啰嗦：条件用的是变量的集合而不是列表，书写顺序不参与定义；这一条以后讲条件独立、Markov 性时会反复被引用，现在记牢能省掉每次重新辩一遍的力气。
>
> 拿数验一遍 (b)。沿用前一条注的设置：$X$ 取 1 的概率 0.6，$Y$ 取 1 的概率 0.5，两者独立，$Z=X+Y$。由于 $Z$ 是 $X,Y$ 的确定函数，内层就等于 $Z$ 本身。条件 $X=0$：内层是 $0+Y$，再取均值得 $0+0.5=0.5$，与直接算出的 $E[Z|X=0]=0.5$ 一致；条件 $X=1$：内层是 $1+Y$，均值 $1.5$，同样一致。再看一种常见错法：把内层误写成 $E[Z\mid X]$，左边就成了 $E\big[\,E[Z\mid X]\,\big|\,X\big]$，按定义它等于 $E[Z\mid X]$，同一句话说了两遍，什么也没证；tower property（塔性质）之所以有内容，恰恰因为内层允许动用更多信息，而结论不受影响。
>
> 最后一个隐性条件是求和次序可换。有限项时这一步无条件成立，无限项时必须有绝对可积当靠山，否则条件收敛的级数会因重排而改变和，这正是实分析里重排定理警告的事。6.041 的结论写成「期望存在时成立」不是客套话；去掉这个条件，两边可能一边有限一边发散，law of iterated expectations（期望迭代法则）就只剩形式上的写法，读者以为自己证完了，其实证的是一个空命题。

<span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b;">**Problem 2**</span>

> <span style="color:#2471a3;">**[solution]**</span> 设 $Y$ 为第一次折断后所得一段的长度，$X$ 为第二次折断后所得一段的长度。
>
> 〔模型补充：这里考虑的是一根长度为 $\ell$ 的木棍。先在 $[0, \ell]$ 上均匀随机取一点折断，取其中一段，其长度记为 $Y$，故 $Y$ 在 $[0, \ell]$ 上均匀分布；再对这段长为 $Y$ 的木棍在 $[0, Y]$ 上均匀随机取一点折断，取其中一段，其长度记为 $X$，故给定 $Y$ 时 $X$ 在 $[0, Y]$ 上均匀分布。下文 $E[X \mid Y] = Y/2$、$E[Y] = \ell/2$ 均由此模型而来。〕

<!-- ===== PDF p2 ===== -->

> **（续）**
>
> **(a)** law of iterated expectations（期望迭代法则）指出：
>
> > ```math
> > E[X] = E\big[E[X \mid Y]\big]
> > ```
>
> 我们有 $E[X \mid Y] = Y/2$（因为给定 $Y$，$X$ 在 $[0, Y]$ 上均匀分布，均值为 $Y/2$），以及 $E[Y] = \ell/2$（因为 $Y$ 在 $[0, \ell]$ 上均匀分布，均值为 $\ell/2$）。于是：
>
> > ```math
> > E[X] = E\big[E[X \mid Y]\big] = E[Y/2] = \frac{1}{2}\, E[Y] = \frac{1}{2}\cdot\frac{\ell}{2} = \frac{\ell}{4}.
> > ```
>
> **(b)** 我们用 law of total variance（全方差定律：$\mathrm{var}(X) = E\big[\mathrm{var}(X \mid Y)\big] + \mathrm{var}\big(E[X \mid Y]\big)$）来求 $\mathrm{var}(X)$：
>
> > ```math
> > \mathrm{var}(X) = E\big[\mathrm{var}(X \mid Y)\big] + \mathrm{var}\big(E[X \mid Y]\big).
> > ```
>
> 回顾：在区间 $[a, b]$ 上均匀分布（uniform）的随机变量，其方差为 $(b-a)^2/12$。由于 $Y$ 在 $[0, \ell]$ 上均匀分布，我们有
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一步的 $(b-a)^2/12$ 不是天上掉的，先把 $\ell=10$ 的情形算到底，后面才接得上几何。设 $Y$ 在 $[0,\ell]$ 上均匀，密度是 $1/\ell$。二阶矩是 $\int_0^\ell y^2/\ell dy = \ell^2/3$；均值的平方是 $\ell^2/4$；两者相减 $\ell^2(1/3-1/4)=\ell^2/12$。取 $\ell=10$：二阶矩 33.33，均值平方 25，方差 8.33，开方得标准差 2.887。原文后面要反复调用这个 12，记住它是「三分之一减四分之一」的差，而不是一个需要背下来的常数。
>
> 顺带一个数值提醒，你在 CSAPP 第 2 章见过的浮点抵消在这里会真的咬人：方差用「二阶矩减均值平方」来算，当均值远大于波动时两个大数相减会丢掉有效位，极端情况下算出负的方差；而「先减均值、再平方、再平均」的写法没有这个问题。手算用前者方便，写程序必须用后者，这不是洁癖而是正确性问题。
>
> 现在把它接到你学过的 18.06。least squares（最小二乘）要做的，是把一个向量投影到某个子空间上，投影的含义是「残差与子空间正交」。把向量换成随机变量、把内积换成 $E[UV]$，同一套话照样成立：常数 1 张成一个一维子空间，$E[X]$ 就是 $X$ 在这个子空间上的 orthogonal projection（正交投影），因为残差 $X-E[X]$ 与 1 的内积是 $E[X-E[X]]=0$，恰好正交。于是方差不是别的，正是这个残差的长度平方，也就是最小二乘里那个残差平方和。均值与方差为什么总是成对出现，原因在几何上：一个给出投影点，一个给出投影之后剩下的长度，缺一个就说不清「误差有多大」。
>
> 顺着这条线，(b) 用的 law of total variance（全方差定律）就成了一道 Pythagorean theorem（勾股定理）题。把残差再拆一次：$X-E[X]$ 等于「$X$ 减条件均值」加上「条件均值减总均值」。这两段正交，验算一下：后一段在给定 $Y$ 时是常数，于是内积等于 $E\big[(\mathrm{var}(X|Y)-E[X])\times E[X-E[X|Y]|Y]\big]$，而方括号里那个条件期望按定义是 $E[X|Y]-E[X|Y]=0$，整个乘积为 0。正交就允许用勾股定理，平方之后两段各算各的再相加，这正是全方差定律的两项：前一项是条件方差的平均，后一项是条件均值自己的方差。
>
> 回到本题的数字，把两部分分别算出。$\ell=10$ 时，前一项是 $E[Y^2/12]=\ell^2/36=2.778$，后一项是 $\mathrm{var}(Y)/4=\ell^2/48=2.083$，相加得 4.861，与 $7\ell^2/144=700/144$ 完全一致，开方得标准差 2.205。比例值得注意：位置不确定那一项占 2.083/4.861，约百分之四十三，几乎与折点处的随机性平分。这就是为什么「先随机折一刀、再在剩下那截里随机折一刀」不能简化成「在一根长一半的木棍上折一次」：后者的方差只有 2.083，比原来少了百分之五十七，低估得相当厉害。
>
> 要说清与 18.06 的区别，免得把两门课混成一门。那边的空间是有限维向量，内积是点积，投影可以用正规方程解出来；这里的空间是随机变量的集合，内积是 $E[UV]$，维度无限，投影一般没有能手解的方程，只能靠条件期望这种「按信息分组取平均」的构造给出。但正交、勾股、最短距离这三件事不看维度，所以把 18.06 的图景搬过来是安全的；真正需要新工具的地方（无限维里投影是否存在、是否唯一）留给后续课程，这里承认它存在且唯一即可，不影响任何一步计算。
>
> 不这么看会怎样：全方差定律只能当成两条公式背，考完即忘；一旦认出它是勾股定理，你就知道它为什么没有交叉项，也知道它什么时候会失效——两段不正交时（条件均值不再是最优预测时）等号就要多出一项协方差，而那一项正是「用错了信息集」的量化信号。
>
> > ```math
> > \mathrm{var}(Y) = \frac{\ell^2}{12}, \qquad \mathrm{var}(X \mid Y) = \frac{Y^2}{12}.
> > ```
>
> 已知 $E[X \mid Y] = Y/2$，于是
>
> > ```math
> > \mathrm{var}\big(E[X \mid Y]\big) = \mathrm{var}(Y/2) = \frac{1}{4}\,\mathrm{var}(Y) = \frac{\ell^2}{48}.
> > ```
>
> 另外，
>
> > ```math
> > \begin{aligned}
> > E\big[\mathrm{var}(X \mid Y)\big]
> > &= E\!\left[\frac{Y^2}{12}\right] \\
> > &= \int_0^{\ell} \frac{y^2}{12}\, f_Y(y)\, dy \\
> > &= \frac{1}{12} \cdot \frac{1}{\ell} \int_0^{\ell} y^2\, dy \\
> > &= \frac{\ell^2}{36}.
> > \end{aligned}
> > ```
>
> 〔上式中 $f_Y(y) = 1/\ell$（$0 \le y \le \ell$）是 $Y$ 在 $[0, \ell]$ 上均匀分布的密度。〕
>
> 综合以上结果，得
>
> > ```math
> > \mathrm{var}(X) = E\big[\mathrm{var}(X \mid Y)\big] + \mathrm{var}\big(E[X \mid Y]\big) = \frac{\ell^2}{36} + \frac{\ell^2}{48} = \frac{7\ell^2}{144}.
> > ```

---

<span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b;">**Problem 3**</span>

> <span style="color:#2471a3;">**[solution]**</span> 设 $X_i$ 表示第 $i$ 个箱子中 widgets（小部件）的数目，则 $T = \sum_{i=1}^{N} X_i$。
>
> 〔模型补充：这里 $N$ 是箱子的总数（一个随机变量），每个箱子里小部件的数目 $X_i$ 是独立同分布（i.i.d.，independently and identically distributed）的随机变量，且都独立于 $N$。记共同分布为 $E[X_i] = E[X]$、$\mathrm{var}(X_i) = \mathrm{var}(X)$。题目给定 $E[X] = 10$、$\mathrm{var}(X) = 16$、$E[N] = 10$、$\mathrm{var}(N) = 16$（这四个数值可由最终结果 $E[T] = 100$、$\mathrm{var}(T) = 1760$ 唯一反推得出）。〕
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这里出现的是一个有名字的结构，叫 random sum（随机和）：求和的上限本身是随机变量，而不是一个事先定好的数。它和普通求和的差别只有三处，但每一处都会改变答案：项数是一个随机量，所以「有多少项」也带信息；各 $X_i$ 独立同分布且独立于 $N$，所以箱内的大小与箱子的多寡互不相干；总量因此是两层随机叠在一起，外层决定项数，内层决定每一项的大小。看清这三条，后面的两个式子就都是自然推论，而不是要背的结论。
>
> 先看均值。条件在 $N$ 上算：$N$ 固定时是 $N$ 个相同的均值相加，得 $N\times E[X]$；再对 $N$ 取一次期望，得到 $E[N]\times E[X]$。这一步没有用到任何新工具，就是把前面两条注里的那套「先条件、再平均」重新走一遍。它给出的直觉很硬：平均而言，箱子多一倍，总量也多一倍，箱内均值大一点，总量就同比例放大，两个因子各自独立地乘进去。
>
> 再看方差，这一项才是容易被忽略的。总量对「箱子数目」的敏感度是每箱均值 $E[X]$：箱数多一个，总量平均多 $E[X]$ 个；把这份敏感度平方，再乘上箱数自身的方差，就得到 100 乘 16 那一项。它的意思是「数目的波动被每一项的平均大小放大了一次」。剩下那一项 $E[N]\times \mathrm{var}(X)$ 是箱内波动的平均，和固定项数时的方差一个意思。两项相加正是全方差定律的两个分块：一块说平均意义上的箱内抖动，一块说箱数本身抖动带来的整体平移。
>
> 代入数字看量级。这里 $E[X]=10$、$\mathrm{var}(X)=16$、$E[N]=10$、$\mathrm{var}(N)=16$：固定十箱时方差只有 $10\times16=160$，标准差 12.65；允许箱数也随机之后方差变成 1760，标准差 41.95，放大了 3.3 倍。放大几乎全部来自 $100\times16=1600$ 这一项，占总量的百分之九十一。这就是「数量的不确定」比「大小的不确定」更致命的算术理由：系数 $E[X]$ 被平方之后，小方差也能被放大成主项。
>
> 独立性一旦拿掉会塌成什么样，值得单独看一眼。设 $N$ 取 1 或 2 各一半概率，$N=1$ 时那一箱是 10，$N=2$ 时两箱各是 20。此时 $E[T]=0.5\times10+0.5\times40=25$；而边缘分布给出 $E[N]=1.5$、$E[X]=15$，乘积是 22.5，两者不等，差 2.5。原因很清楚：箱子多的时候每箱也更大，两个因子同向涨，乘积公式假设的「互不相干」被破坏。所以公式里的那句「独立于 $N$」不是形式条件，它是等式成立的前提；现实里只要存在「大箱子更容易被选中」这种相关性，就必须回到条件形式 $E[N\times E[X|N]]$ 去算。
>
> 这个结构后来长成的样子，比你想象的多。保险里一段时期的索赔总额就是它：索赔次数随机、每次金额随机、次数常按泊松分布取，于是得到 compound Poisson process（复合泊松过程），Cramér 与 Lundberg 的破产概率就是在它上面算的。排队论里一个服务台在随机到达次数下的总工作量、物理里宇宙线簇射的粒子总数、繁殖模型里一支血脉的总后代数，全都是同一个求和，最后那个是 branching process（分支过程）的入口。现代系统里也一样：一个查询的并行分片数是随机的、每片处理时间也随机，总耗时的方差就得用这个式子估，否则容量规划会系统性低估长尾。
>
> 因此这条注的价值不在复述结果，而在给出一个可迁移的判据：只要你的系统里出现「数量随机、每次大小也随机」这两层，就先检查独立性与同分布两条，再套这两个式子；两条都满足，均值和方差都是一行；只要有一条不满足，就必须退回到条件形式重算，而退回的代价通常只是多写一个内层期望。
>
> > ```math
> > \begin{aligned}
> > E[T] &= E\!\left[E\!\left[\sum_{i=1}^{N} X_i \,\middle|\, N\right]\right] \\
> > &= E\!\left[\sum_{i=1}^{N} E[X_i \mid N]\right] \\
> > &= E\!\left[\sum_{i=1}^{N} E[X]\right] \\
> > &= E[X] \cdot E[N] = 100.
> > \end{aligned}
> > ```
>
> 〔第二、三行用到 $X_i$ 与 $N$ 独立，故 $E[X_i \mid N] = E[X_i] = E[X]$；第四行 $E\big[\sum_{i=1}^{N} E[X]\big] = E[X]\, E[N]$，因为 $E[X]$ 是常数。〕

<!-- ===== PDF p3 ===== -->

> **（续）** 以及，
>
> > ```math
> > \begin{aligned}
> > \mathrm{var}(T) &= E\big[\mathrm{var}(T \mid N)\big] + \mathrm{var}\big(E[T \mid N]\big) \\
> > &= E\!\left[\mathrm{var}\!\left(\sum_{i=1}^{N} X_i \,\middle|\, N\right)\right] + \mathrm{var}\!\left(E\!\left[\sum_{i=1}^{N} X_i \,\middle|\, N\right]\right) \\
> > &= E\big[N\, \mathrm{var}(X)\big] + \mathrm{var}\big(N\, E[X]\big) \\
> > &= \big(\mathrm{var}(X)\big)\, E[N] + \big(E[X]\big)^2\, \mathrm{var}(N) \\
> > &= 16 \cdot 10 + 100 \cdot 16 = 1760.
> > \end{aligned}
> > ```
>
> 〔第三行用到 $X_i$ 独立同分布且独立于 $N$：$\mathrm{var}\big(\sum_{i=1}^{N} X_i \mid N\big) = N\,\mathrm{var}(X)$，$E\big[\sum_{i=1}^{N} X_i \mid N\big] = N\,E[X]$；第四行用到 $E[N\,\mathrm{var}(X)] = \mathrm{var}(X)\,E[N]$（$\mathrm{var}(X)$ 是常数）以及 $\mathrm{var}(N\,E[X]) = (E[X])^2\,\mathrm{var}(N)$（$\mathrm{var}(aN) = a^2\,\mathrm{var}(N)$）。〕
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 作为收尾，这一行值得把定理的来历交代清楚，因为在 1933 年之前，「条件期望」根本没有一般定义，只有两种情形能算：离散情形用比值，拿两件事同时发生的概率除以条件的概率；连续情形用条件密度除以边缘密度。原文的 Problem 2 恰好落在第二种情形：$Y$ 连续取在区间上，单点概率为零，比值那条路当场失效，只能靠「给定 $Y=y$ 时 $X$ 在 $[0,y]$ 上均匀、密度 $1/y$」这种具体写法绕过去。这不是巧合，而是那个年代唯一的可行路径。
>
> Kolmogorov 在 1933 年的 Grundbegriffe der Wahrscheinlichkeitsrechnung（《概率论基础》）里换了问法：不再问「条件期望怎么算出来」，而是问「它必须满足什么」。他的定义是：$E[Z|Y]$ 是一个由 $Y$ 决定的函数，使得对一切由 $Y$ 决定的事件 $A$，都满足 $E[Z\times 1_A]=E\big[E[Z|Y]\times 1_A\big]$。这不是一个构造，而是一份合同：凡是满足这份合同的东西，就叫条件期望。存在性由 Radon–Nikodym theorem（拉东与尼科迪姆给出的定理）保证，前提是所涉及的测度绝对连续。
>
> 为什么必须放弃构造。因为构造只能覆盖已经见过的情形：离散一套、密度一套、混合型再来一套，每遇到一种新的随机变量就要重造一次定义，理论永远不能统一，每一篇论文都要先声明「本文假定分布有密度」。合同式定义一次覆盖全部，代价是它不再告诉你「怎么算」——真算的时候仍然要回到离散求和或密度积分，这两种具体算法退化成了定理的特例，而不是定义本身。这也解释了本文为什么写得这么具体：这门课只在可算的情形里工作，抽象定义只在背后兜底，你看不见它但没有它这些式子就站不住。
>
> 代价有两个，都值得知道。第一，唯一性只在 almost surely（几乎必然）意义下成立：任何一个零概率集合上的取值都可以随便改动，合同仍然成立，所以严格说 $E[Z|Y]$ 是一个等价类而不是一个具体的函数。工程上从不为此困扰，因为我们从不关心零概率事件，但一旦要谈「处处相等」，结论就得改写。第二，存在性不是免费的：这个定理需要绝对连续作前提，一旦条件分布相对原分布不绝对连续，条件期望就可能根本不存在，那些「不可测」的病态例子正是从这里长出来的。
>
> 后来这条线分出两个方向。Doob 在 1953 年的《随机过程》里把 martingale（鞅）系统化，而它的定义式就是塔性质的一步版本：「下一步的条件期望等于当前值」，反复迭代就得到塔性质；于是本文 (c) 那一行，在整个随机过程理论里是最基本的公理级事实，而不是一个需要证明的技巧。另一边，Wald 在 1944 年发表于《数理统计年刊》第 15 卷 283 至 296 页的论文里处理随机和的均值，也就是前一条注里的第一个式子。两个方向今天分别叫鞅论和随机和理论，语言却是同一套。
>
> 最后说一句方法论，因为它比年份更有用。用方程而不是构造来定义对象，是二十世纪数学的一次范式转变，它和你熟悉的两件事同构：18.06 里用「残差与子空间正交」刻画投影，而不是先写死一个矩阵；CSAPP 里用接口和调用约定刻画模块，而不是规定它内部怎么实现。好处一样，换一种实现理论照样成立；坏处也一样，光看定义不知道具体的数怎么算，必须另外补上算法。本文的三道题就是补算法的那一半：定义在幕后，求和与积分在台前。如果这条注只留一句，就留这一句。
