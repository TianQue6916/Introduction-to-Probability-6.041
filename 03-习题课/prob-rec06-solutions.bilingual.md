本讲三条战线：导出分布收尾（一般单调公式；两个随机变量的函数之和与比）；convolution（卷积）——独立随机变量之和的分布；covariance（协方差）与 correlation（相关系数）——两个变量如何共舞的度量。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.202–218；§4.2, p.217–222</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略定位）:**</span> 本讲三条战线层层递进。其一，把上讲的两步 CDF 法压缩成一行公式——$g$ 严格单调时 $f_Y(y) = f_X(x) / |g'(x)|$，并把函数从一元推广到二元（和与比值）；其二，卷积：独立随机变量之和的分布怎么求，离散、连续各一套；其三，协方差与相关系数——不再制造新分布，而是给"两个变量的联动"造一个无量纲的度量，为下一讲的条件期望与"随机个随机变量之和"备好零件。经核对页码，§4.1 Derived Distributions（p.202 起，卷积小节在 p.213–218）本讲读完收尾，§4.2 Covariance and Correlation（标题页 p.217、总结页 p.222）随后展开——阅读说明里的"Finish Section 4.1"正指补完上讲只开了头的 §4.1。上讲铺垫的 $Y = X^3$ 与 $Y = aX + b$ 两例，将在本讲获得统一的公式化解释。
>
> 先问一个定位问题：如果两步 CDF（cumulative distribution function，累积分布函数）法已经能算一切，为什么还要额外背一条公式。答案是两步法把"求分布"钉死在一个积分上，换一个 $g$ 就要从头再积一次，无法复用。公式化的真正收益不是省事，而是把动作拆成三个能机械执行的子步骤：反解 $x = g^{-1}(y)$、算导数 $|g'(x)|$、带上定义域。三件事各自都能单独验证，出错时能定位。代价同样明确：适用条件从"任意 $g$"收紧到 strictly monotonic（严格单调），一旦不单调就必须回退到 CDF 法。用适用范围换可复用性，是工程上最典型的交换。
>
> 第二步为什么必须是 convolution（卷积），而不是别的二元函数。因为"独立随机变量之和"是唯一既高频又在结构上封闭的一类：binomial（二项）加二项仍是二项，normal（正态）加正态仍是正态，参数直接相加。封闭性意味着每算一次就留下一条能复用的结论，而不是每算一次都造出一个没有名字的新分布。反过来，若跳过卷积先讲协方差，方差和公式就失去了最自然的载体——$var(X + Y) = var(X) + var(Y) + 2cov(X, Y)$ 的第一个使用场景恰恰是"和的方差"，而这个"和"正是卷积研究的对象。
>
> 第三步是视角切换，不是继续造分布。前两步的输出都是函数（一个 density（密度）或一个 PMF（probability mass function，概率质量函数）），第三步的输出是一个数。从函数降到数看起来是信息损失，但损失掉的部分恰好是不可比较的部分：covariance（协方差）还带着两个变量的量纲，correlation（相关系数）把它除干净，于是前者只能在同一个问题里比大小，后者可以跨问题比大小。
>
> 把三步用同一对变量串起来，数字全部可手算。取 $X, Y$ 独立同分布，都在 $[0,1]$ 上 uniform（均匀），于是 $f_X = f_Y = 1$。先看卷积：$Z = X + Y$ 的 density 是 $f_Z(z) = z$（$0 < z \le 1$）、$f_Z(z) = 2 - z$（$1 < z < 2$），峰值在 $z = 1$ 处取 $1$；于是 $F_Z(1) = 1/2$、$E[Z] = 1$、$var(Z) = 1/6 \approx 0.1667$。再看比值：$W = Y/X$ 的 density 是 $1/2$ 与 $1/(2z^2)$ 两段，$E[W]$ 根本不存在——同一对变量，换成比值就没有均值了。最后看协方差：$cov(Z, X) = var(X) + cov(Y, X) = 1/12 \approx 0.0833$，$\sigma_Z = \sqrt{1/6} \approx 0.4082$，$\sigma_X = \sqrt{1/12} \approx 0.2887$，故 $\rho = 0.0833 / (0.4082 \times 0.2887) = 0.7071$，正好等于 $1/\sqrt{2}$。三个数字分别落在"有限方差""无期望""中等正相关"三个不同的位置上——三条战线的输出根本不重叠。
>
> 跨课程连接之一：CSAPP 第 6 章 cache（高速缓存）。硬件把"缺失处理"固化成一套状态机流程，命中就直通、缺失就走填充，与这里把"求分布"固化成三个子步骤是同一种设计手法——把反复出现的流程从"每次现推"改成"按表执行"。区别在于 cache（高速缓存）的替换策略是启发式，赶走谁并不保证最优，而公式是恒等式，前提满足就精确成立；所以 cache（高速缓存）能容忍几个百分点的不命中率，公式不能容忍千分之一的偏差。
>
> 跨课程连接之二：6.006 与 CLRS 的分治模板。merge sort（归并排序）的合并步骤是"把两个排好的子序列合成一个"，卷积是"把两个已知分布的变量相加得到新分布"，两者都是二元合并算子，都满足结合律，因此都能倍增地做——两两卷、四四卷、八八卷。区别在代价：合并是线性的 $O(n)$，卷积是平方的 $O(N^2)$，这笔账正是后面要用 FFT（fast Fourier transform，快速傅里叶变换）去砍的地方。
>
> 收束：本讲的顺序不是教材编排的偶然，而是"造分布的两种方式（一元换元、二元求和）加上一个不造分布的度量（协方差）"这条逻辑链，末尾再挂一条尾巴——比值分布与卷积共用同一套从 CDF 起手的动作，只是几何上换了一个区域。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">A general formula（一般公式）</span>

- 设 $Y = g(X)$，$g$ strictly monotonic（严格单调）。

> <span style="color:#7f8c8d;">图：曲线 $y = g(x)$，在 $x$ 处标注斜率 $\frac{dg}{dx}(x)$；横轴上的小区间 $[x,\ x + \delta]$ 被曲线映到纵轴上对应的小区间 $[y,\ y + \cdot]$。</span>

- 事件 $\{x \le X \le x + \delta\}$ 与 $\{g(x) \le Y \le g(x + \delta)\}$ 相同，近似地即 $\{g(x) \le Y \le g(x) + \delta\, |(dg/dx)(x)|\}$。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> **类别：图解注 + 第一性原理。** 上面那张图只有四个零件：横轴上的小区间 $[x,\ x+\delta]$、竖轴上的像区间、曲线 $y = g(x)$、以及标在 $x$ 处的那条切线斜率。读图的顺序是固定的三步：先在横轴上框出一小段，再把这段的两端顺着曲线抬到纵轴上，最后发现纵轴上也落下了一小段。关键位置是那支斜率笔——它决定了两段长度之间的兑换价，其余一切都是它的派生。看懂这一点，后面的公式就不必背了。
>
> probability density（概率密度）的数值本身没有独立含义，它只是一张汇率表，把一段 interval（区间）的长度换算成 mass（概率质量）。所以图中横轴那一段装的质量是 $\delta f_X(x)$，而不是 $f_X(x)$。为什么必须乘 $\delta$：密度的量纲是「每单位长度的概率」，只有乘上长度才回到无量纲；不乘就等于把「每公里有几个加油站」当成「有几个加油站」，量级全错。这个近似的误差来自 $f_X$ 在区间内并非严格常值，把 $f_X$ 在 $x$ 处展开，误差是 $\delta$ 的二阶小量，所以 $\delta$ 越小越准，取极限时误差彻底消失。
>
> 这一段质量被 $g$ 搬到竖轴上以后，长度变了。变化率是 $|g'(x)|$：因为 $g(x+\delta) - g(x)$ 的一阶近似就是 $g'(x)\,\delta$，这正是 Taylor expansion（泰勒展开）在一点邻域里的标准用法。跨课程连接：在 Strang 的 linear algebra（线性代数）里，一个线性映射把体积放大 determinant（行列式）的绝对值倍；一维时这个映射就是 $u \mapsto g'(x)\,u$，一个 $1 \times 1$ 的 matrix（矩阵），它的 determinant 就是 $g'(x)$。所以公式里的 $|g'|$ 不是天上掉下来的一个导数，它是 Jacobian determinant（雅可比行列式）在一维退化后的样子。这也解释了为什么多元换元的 formula（公式）里永远是 $|\det J|$，形状完全一致，只是把一维的乘数换成了行列式。
>
> 绝对值不是装饰。$g$ 递减时，像区间的两端左右互换，长度仍然是正数，而 $g'$ 本身是负的，所以必须取 absolute value（绝对值）才配称长度。真正的边界条件在 $g'(x) = 0$ 处：那里一阶近似退化为零长度，压缩比趋于无穷，公式的分母归零，说明这种情形必须回退到 CDF（cumulative distribution function，累积分布函数）法重算。$Y = |X|$ 就是典型——在 $0$ 附近两条支路被折叠到一起，质量在一点上叠加，strictly monotonic（严格单调）这个前提已经被破坏，公式对它不成立。
>
> 代数字进去看第一个例子。取 $X$ uniform（均匀）落在 $[0,1]$ 上，于是 $f_X(x) = 1$；令 $Y = 2X$，则 $g'(x) = 2$，反解 $x = y/2$，代入公式得 $f_Y(y) = 1/2$，范围 $0 < y < 2$。验算：$\int_0^2 (1/2)\, dy = 1$。反证一下不除 $|g'|$ 的后果：若错写成 $f_Y(y) = 1$，则 $\int_0^2 1\, dy = 2$，总质量变成二；而且它会推出 $P(Y \le 1) = 1$，可真实值是 $P(Y \le 1) = P(X \le 1/2) = 1/2$，当场自相矛盾。这就是质量守恒这条第一性原理的用法：任何候选密度先过「总积分为一」这一关，过不了就一定是错的。
>
> 再看一个非线性的例子。同样 $X$ 在 $[0,1]$ 上 uniform，令 $Y = X^2$，则 $g'(x) = 2x$，反解 $x = \sqrt{y}$，代入得 $f_Y(y) = 1/(2\sqrt{y})$，范围 $0 < y \le 1$。验算：$\int_0^1 \frac{1}{2\sqrt{y}}\, dy = [\sqrt{y}]_0^1 = 1$。注意 $y$ 趋于零时这个密度趋于无穷，但概率一点都没爆炸：$P(Y \le 0.01) = \int_0^{0.01} \frac{dy}{2\sqrt{y}} = 0.1$，只有一成。这条要记牢——density（密度）的绝对值大小不能用来比较「哪个更可能」，它只在与长度相乘之后才有意义。$X^2$ 把靠近零的一长段 $x$ 压进了靠近零的一小段 $y$，质量被挤稠，密度就飙高；反过来 $y$ 接近一时 $x$ 的变化被拉伸，密度降到 $1/2$。
- 因此（$y = g(x)$）：
```math
\delta\, f_X(x) = \delta\, f_Y(y)\, \left| \frac{dg}{dx}(x) \right| \qquad \Longrightarrow \qquad f_Y(y) = \frac{f_X(x)}{\left| \frac{dg}{dx}(x) \right|} .
```

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.211–213</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 这条公式的发动机是概率质量守恒，而不是微分链式法则的某种变体。一句话：density（密度）是"每单位长度的质量"，换一根坐标轴就要按长度兑换率重新折算，兑换率是 $|g'(x)|$，所以折算的动作是除法。
>
> 机制分三层，每层都能单独追问"凭什么"。第一层，质量守恒：一段区间里装了多少 probability（概率），不因为给它换个坐标系就变，它是对象的属性而不是坐标的属性。第二层，长度不是不变量：$x$ 处长 $\delta$ 的小段被 $g$ 映到 $y$ 轴上一段，长度约为 $\delta |g'(x)|$，这是一阶 Taylor expansion（泰勒展开）$g(x + \delta) - g(x) \approx g'(x) \delta$ 的直接后果。第三层，两把尺子相除：同一批质量除以两种长度，得到两种 density（密度），比值正是 $1/|g'(x)|$。三层写成一行是 $f_X(x) \delta = f_Y(y) \delta |g'(x)|$，约掉 $\delta$ 就得到 $f_Y(y) = f_X(x)/|g'(x)|$。
>
> 若不除 $|g'(x)|$ 会怎么失败，用一个具体数字看清。取 $X$ 在 $[0,1]$ 上 uniform（均匀），$f_X(x) = 1$，令 $Y = 2X$。正确结果 $f_Y(y) = 1/2$（$0 < y < 2$），总积分为 $1$。错写成 $f_Y(y) = 1$ 时，总质量积出来是 $2$；更致命的是它推出 $P(Y \le 1) = 1$，而真值是 $P(X \le 1/2) = 1/2$，当场自相矛盾。质量守恒这条第一性原理的用法就在这里：任何候选 density（密度）先过"总积分为一"这一关，过不了立刻作废。
>
> 绝对值不是装饰。$g$ 递减时像区间反向摆放，长度仍是正数而 $g'$ 是负数，只有取 absolute value（绝对值）才配称长度。走 CDF 法看同一件事：$g$ 递减时 $F_Y(y) = 1 - F_X(g^{-1}(y))$，求导自动吐出一个负号，再被 $|g'|$ 收编，两条路给出同一个正数。上讲的 $T = 200/V$ 就吃到这个负号，忘了绝对值，温度分布的符号会整个翻过去。
>
> 再来一个能一路算到底的例子，同时暴露公式的边界。$X$ 在 $[0,1]$ 上 uniform，$f_X = 1$，令 $Y = X^3$：$g'(x) = 3x^2$，反解 $x = y^{1/3}$，代入得 $f_Y(y) = 1/(3 y^{2/3})$（$0 < y \le 1$）。验算归一化：$\int_0^1 \frac{1}{3} y^{-2/3}\, dy = [y^{1/3}]_0^1 = 1$。再抽一点：$P(Y \le 1/8) = (1/8)^{1/3} = 1/2$，与 $P(X \le 1/2) = 1/2$ 逐字对上。注意 $g'(0) = 0$ 落在定义域的端点上，开区间内公式照常有效，因为端点只影响一个零测集。
>
> 换一个非单调的 $g$，公式立刻失效，必须靠分支补救。$X$ 在 $[-1,1]$ 上 uniform，$f_X = 1/2$，令 $Y = X^2$。反解有两支 $x = \pm \sqrt{y}$，每支的 $|g'| = 2\sqrt{y}$，各贡献 $(1/2)/(2\sqrt{y}) = 1/(4\sqrt{y})$，两支相加得 $f_Y(y) = 1/(2\sqrt{y})$（$0 < y < 1$），积分 $[\sqrt{y}]_0^1 = 1$。若硬套单支公式只写 $1/(4\sqrt{y})$，总质量只有一半——质量在折叠点被漏掉了，这就是 strictly monotonic（严格单调）这个前提的真实分量。
>
> 跨课程连接：Strang 的 linear algebra（线性代数）里，换元把体积乘上 $|\det J|$，$J$ 是 Jacobian（雅可比）matrix（矩阵）。一维时它是一个 $1 \times 1$ 的矩阵，determinant（行列式）就是 $g'(x)$，所以本讲的 $|g'|$ 正是雅可比行列式退化到一维之后的样子。名称归属：这套行列式得名于德国数学家 Carl Gustav Jacob Jacobi（1804–1851），他在研究微分映射时引入它。区别在于多维时方向信息被绝对值彻底抹平，只剩局部放大率；一维还能看出单调方向，这也是一维可以用"反向"解释负号、多维只能讲体积的原因。
>
> 另一个连接在本机就能跑：CSAPP 第 6 章 cache（高速缓存）的地址映射只做移位，块号等于地址右移 $b$ 位，等价于乘一个固定的兑换率 $2^{-b}$，角色与 $|g'|$ 完全相同——都是把一把尺子换成另一把。区别在于 cache 的映射是多对一的，不同地址会撞进同一块，正如 $g$ 不单调时多个 $x$ 挤进同一个 $y$；撞了以后信息丢失，公式失效的机制一模一样。
>
> 收束：$f_Y = f_X / |g'|$ 一句话就是"质量守恒除以长度兑换率"，记住这两件事公式不必背；反过来若只记形状，碰到 $Y = X^2$ 这种折叠就必然漏掉一半质量。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Example: the ratio Z = Y/X（例：比值 Z = Y/X 的分布）</span>

> <span style="color:#7f8c8d;">图：单位正方形上 $f_{X,Y}(y,x) = 1$ 的均匀联合密度（横轴 $x$、纵轴 $y$、高度 $1$）；任务是求 $Z = g(X, Y) = Y/X$ 的 PDF。</span>

**课堂填空**：
- 当 $z \le 1$：$F_Z(z) = \underline{\qquad}$
- 当 $z \ge 1$：$F_Z(z) = \underline{\qquad}$
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> **类别：第一性原理 + 证明策略模板。** 先回答「凭什么要分 $z \le 1$ 和 $z \ge 1$ 两段」。$Z = Y/X$ 定义在 unit square（单位正方形）$[0,1]^2$ 上，联合密度恒为 $1$，所以任何事件的概率都等于面积。事件 $\{Z \le z\}$ 翻译成区域 $\{y \le zx\}$。这条直线从原点出发往上扫，扫到哪条边界停下，决定了积分上限写什么。$z \le 1$ 时直线与正方形在右边界 $x = 1$ 处相交，纵坐标是 $z \le 1$，没顶到上边界；$z > 1$ 时它先撞上边界 $y = 1$，交点的横坐标是 $x = 1/z$。所以「哪条边界在起作用」在 $z = 1$ 处换班，分段点就诞生在这里。
>
> 这个现象在 6.006 反复出现：约束集合的形状由「哪一组约束取等号」决定，取等号的那组一换，解就换公式。在 linear programming（线性规划）里它叫 active constraint（有效约束）切换；在 Dijkstra 里它是「当前最短的未访问点」换人。分布推导里的分段点，本质是同一个几何事实在二维面积上的投影。
>
> 先算 $0 \le z \le 1$。用 double integral（二重积分）：对每个 $x$，$y$ 从 $0$ 走到 $zx$，再让 $x$ 从 $0$ 走到 $1$，联合密度是 $1$，所以面积直接给出概率：$\int_0^1 zx\, dx = z/2$。换个积分次序验算：固定 $y$，$x$ 从 $y/z$ 走到 $1$，得 $\int_0^z (1 - y/z)\, dy = z - z/2 = z/2$，两条路径同值。这一步的合法性来自 Fubini 定理，对连续密度恒成立，不用担心。
>
> 再算 $z \ge 1$。此时区域 $\{y \le zx\}$ 几乎占满整个正方形，直接积要按 $x \le 1/z$ 和 $x > 1/z$ 分两段，多一次讨论。改用 complement（补集）法：算剩下那个上三角 $\{y > zx\}$ 的 area（面积），$x$ 从 $0$ 走到 $1/z$，$y$ 从 $zx$ 走到 $1$，面积 $\int_0^{1/z} (1 - zx)\, dx = 1/z - 1/(2z) = 1/(2z)$。所以 $F_Z(z) = 1 - 1/(2z)$。判断用不用补集的准则很实用：目标区域「大」就补，「小」就直算；这里大区域是正方形减一块三角形，补出来的那块积分上限还带 $z$，但只需要一段。
>
> 代数字检验。$z = 1/2$：$F_Z = 1/4$，求导得 $f_Z = 1/2$。$z = 2$：$F_Z = 1 - 1/4 = 3/4$，$f_Z = 1/(2 \cdot 4) = 1/8$。$z = 1$：两边公式都给 $1/2$，故 $F$ 连续；两支求导也同在 $1/2$，故 density（密度）也连续，这不是巧合——两段本来就是同一块区域在分界线处的两种描述。尾部抽查：$P(Z > 10) = 1 - F_Z(10) = 1/20 = 0.05$，说明比值超过十的概率还有五个百分点。
>
> 把上面的动作提炼成模板，一共四步。第一步定范围：$Z$ 取哪些值，$F$ 从 $0$ 单调升到 $1$。第二步翻译事件：把 $\{Z \le z\}$ 写成 $\{(X, Y) \in D_z\}$，等价变形里凡是除以 $X$、乘过不等号的地方，都要交代 $X > 0$ 这类前提，否则符号会翻。第三步找分界：$D_z$ 的形状（被哪条边界截断）改变的地方就是分段点，通常出现在 $z$ 让直线穿过某个顶点时。第四步求导：若积分上限带 $z$，用 Leibniz rule（莱布尼茨法则）逐项求导。这套四步适用于一切「随机变量的函数」问题，比值、乘积、最大值、最小值都能套。求导之前再做一次自检：把两端的极限代进去，$F_Z$ 必须分别落在零与一，任何一段算错都会在这一步露馅。
>
> 最后留一个警钟。如果懒得分段，把 $F_Z(z) = z/2$ 一路用到 $z = 2$，会算出 $F_Z(2) = 1$，真值是 $3/4$——错得不算离谱，但机制已经全错；再求导会得到 $f_Z(z) = 1/2$ 对一切 $z$ 成立，尾部整个消失，归一化立刻崩掉。顺带一个更狠的事实：$\mathrm{E}[Z]$ 根本不存在，因为 $\int_1^\infty z \cdot \frac{1}{2z^2}\, dz = \int_1^\infty \frac{dz}{2z}$ 发散；这也对得上原始定义 $\mathrm{E}[Y/X] = \int_0^1\!\!\int_0^1 \frac{y}{x}\, dx\, dy$，内层对 $x$ 积分时在零附近对数发散。均值不存在的分布并不稀奇，比值型统计量是最常见的出处。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.215–218</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 卡点诊断）:**</span> 这条注要处理三件事：分段点从哪来、验算怎么闭合、这个分布的病根在哪里。逐段推导并验算：$F_Z(z) = P(Y/X \le z) = P(Y \le zX)$（$X \ge 0$ 可直接乘过去）。$0 \le z \le 1$：直线 $y = zx$ 从 unit square（单位正方形）切下三角形，面积 $\int_0^1 zx\, dx = z/2$，故 $F_Z(z) = z/2$ ✓。$z \ge 1$：取 complement（补集）更省事——正方形内 $y > zx$ 的三角形 area（面积）为 $\int_0^{1/z} (1 - zx)\, dx = \frac{1}{2z}$，故 $F_Z(z) = 1 - \frac{1}{2z}$ ✓。$z < 0$ 时 $F_Z(z) = 0$（两变量非负）。连续性对账：$F_Z(1^-) = 1/2 = F_Z(1^+)$ ✓；又由 $X, Y$ 地位对称，$P(Y \le X) = 1/2$ 本在情理之中。求导得 $f_Z(z) = 1/2$（$0 < z \le 1$）、$f_Z(z) = 1/(2z^2)$（$z \ge 1$）；归一化 $\frac{1}{2} + \int_1^\infty \frac{dz}{2z^2} = \frac{1}{2} + \frac{1}{2} = 1$ ✓。卡点诊断：比值分布的右尾按 $1/z^2$ 衰减得很慢——分母偶尔贴近 $0$ 会制造极端比值，这是比率型统计量的通病。
>
> 先说分段点。它不是人为选择，而是直线 $y = zx$ 与正方形边界"换班"的地方。$z \le 1$ 时这条直线与右边界 $x = 1$ 相交，交点的纵坐标是 $z \le 1$，够不到上边界 $y = 1$；$z > 1$ 时斜率变陡，它先撞上上边界，交点的横坐标是 $1/z$。起作用的那条边界一换，积分上限就换，分段点随之诞生。这也是为什么 $z = 1$ 处两支给出同一个值 $1/2$：换班点上两套描述描述的是同一块面积。
>
> 再说事件翻译里那个不起眼的隐含前提。把 $P(Y/X \le z)$ 改写成 $P(Y \le zX)$ 时，默认了 $X > 0$；若 $X$ 会取负值，乘过去要翻转不等号，事件集合被切成两支分别处理，直接乘过去就会算错。本题 $X$ 在 $[0,1]$ 上取值，$X = 0$ 只是一条线，probability（概率）为零，可以忽略——这是一句必须交代的话，不交代就是跳步。
>
> 数字检查五个点。$z = 1/2$：$F_Z = 1/4$，求导得 $f_Z = 1/2$。$z = 2$：$F_Z = 1 - 1/4 = 3/4$，$f_Z = 1/(2 \times 4) = 1/8$。于是 $P(1/2 < Z < 2) = 3/4 - 1/4 = 1/2$，恰好占了正方形的一半——用对称性也能一眼看出。尾部抽查：$P(Z > 10) = 1 - F_Z(10) = 1/20 = 0.05$，比值超过十还有五个百分点。中位数由 $F_Z(m) = 1/2$ 解出 $m = 1$，正是换班点。
>
> 病根在这里：右尾是 $1/(2z)$ 量级，衰减得比任何指数都慢，于是 $E[Z] = \int z f_Z(z)\, dz$ 在无穷远处像 $\int dz/(2z)$ 一样对数发散，期望不存在。这个诊断有工程含义：分母落在 $0$ 附近一点点，比值就能爆到很大。举个具体的：分母落在 $[0.001, 0.002]$、分子在 $[1,2]$ 时，比值轻松破千；而 $P(Z > 1000) = 1/2000$，也就是平均两千次里就会出现一次——不是童话里的罕见事件。
>
> 名称归属值得记一句：比值的分布有一个著名的特例，即两个独立标准 normal（正态）变量之商，它服从 standard Cauchy（标准柯西）分布，distribution（分布）得名于法国数学家 Augustin-Louis Cauchy。本节这对比值服从的不是柯西分布，但两者同属 heavy tail（重尾）家族，尾部量级都是 $1/z$，所以期望都不存在——这也是"均值不存在"最常见的一类出处。
>
> 跨课程连接：CSAPP 第 3 章的浮点表示。除以一个接近零的分母，机器上表现为 inf 或巨大的 finite（有限）值，数学上表现为尾部衰减慢；同一件事实的两种呈现。区别在于浮点还叠了舍入误差和 $0/0$ 得 NaN 的规则，而概率模型把零测集直接抹掉，所以数学上"几乎不会发生"，机器上"偶尔真的发生"。
>
> 再挂一条 6.006 的连接：amortized analysis（摊还分析）里"稀有但昂贵"的操作会把平均值拖垮，本节比它更极端——不是平均被拖大，而是平均直接发散。区别是摊还分析最后仍给出一个有限的分摊代价，这里连有限都给不出，只能退回中位数与尾概率来描述。
>
> 收束：比值题的三步——先定 $X$ 的符号前提，再找边界换班点，最后查尾部是否够重；三步任何一步跳过，都会得到一个"看起来归一化、实则尾部全错"的答案。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The distribution of X + Y（X + Y 的分布：离散情形）</span>

- $W = X + Y$；$X, Y$ independent（独立）。

> <span style="color:#7f8c8d;">图：二维格点图——把 $(x, y)$ 格点摆平面，质量沿斜线 $x + y = w$ 收集；图中 $w = 3$ 的对角线上标出 $(0,3), (1,2), (2,1), (3,0)$ 四个点。</span>

```math
p_W(w) = P(X + Y = w) = \sum_x P(X = x)\, P(Y = w - x) = \sum_x p_X(x)\, p_Y(w - x).
```
- **Mechanics（机械步骤）**：
  - 把两张 PMF 上下对齐摆放；
  - 翻转（flip）$Y$ 的 PMF；
  - 把翻转后的 PMF 平移 $w$（$w > 0$ 时向右移）；
  - 逐点交叉相乘再相加。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> **类别：证明策略模板 + 跨课程连接。** 先把公式的来历拆开。$\{W = w\}$ 这个事件被按 $X$ 的取值切成互斥的片：对每个 $x$，片是 $\{X = x,\ Y = w - x\}$。切法合法靠的是 countable additivity（可列可加性），片与片不重叠，并起来正好是整个事件。每一片的概率写成边缘乘条件，即 $p_X(x)$ 乘以条件概率，再用 independence（独立）把条件概率换成边缘概率 $p_Y(w - x)$。所以这条公式不是定义，是两条公理的合成物：划分给出「怎么切」，独立给出「每片多重」。
>
> 为什么 $Y$ 的指标偏偏是 $w - x$？因为一旦 $X = x$ 定下，总和要等于 $w$，$Y$ 就只剩 $w - x$ 这一条路，没有任何自由度。这就是「沿斜线收集质量」那句画意的代数版：所有和为 $w$ 的点对 $(x,\ w - x)$ 落在同一条斜线上，公式做的就是把这条线上的质量逐点累加。顺带做一次量纲检查：每片的权重必须是两个概率相乘。若误写成相加，在 $p_X = p_Y = p$ 的最简情形下每片就有 $2p$，累加几片立刻越过一，整张表就不再是分布——这是判断公式对不对最快的哨兵。
>
> flip-and-shift 里的「翻转」也不是硬造的花招。令 $j = w - x$，则 $x = w - j$：$p_Y(w - x)$ 作为 $x$ 的函数，正着走过去等于把 $p_Y$ 倒着读一遍，视觉上就是把一条纸带翻面。翻过来以后，两个序列里「脚标相加等于 $w$」的那些项正好上下对齐，逐点相乘再求和就是一次内积。这套动作与 polynomial（多项式）相乘完全同构：两组系数相乘后按次数归并，$\sum_x p_X(x)\,p_Y(w - x)$ 正是 $w$ 次项的系数。CLRS 第 30 章讲的 polynomial multiplication（多项式乘法）就是同一件事，只是换了个名字。
>
> 再往上一层，把它写成 dynamic programming（动态规划）的递推。记 $q_m(w) = P(X_1 + \cdots + X_m = w)$，则有 $q_m(w) = \sum_x q_{m-1}(w - x)\, p_{X_m}(x)$：前 $m - 1$ 个变量的和已经算好，最后一个补上 $x$。这与 6.006 的 knapsack（背包）里那条 $dp[i][s] = \sum_k dp[i-1][s-k]$ 是同一个模板——状态是「前 $i$ 件、和 $s$」，转移是「枚举第 $i$ 件的取值」。差别只在语义：背包累加的是价值，这里累加的是概率，所以输出天然仍是 probability mass function（概率质量函数）。
>
> 复杂度上，支撑集各含 $N$ 个点时一次卷积是 $O(N^2)$，$m$ 个变量逐个卷是 $O(mN^2)$；用 doubling（倍增）可以压到 $O(N^2 \log m)$，因为两两卷、四四卷、八八卷，卷的次数只按对数增长。真正把 $N^2$ 打掉的是 FFT（fast Fourier transform，快速傅里叶变换）：1965 年 Cooley 与 Tukey 在 Mathematics of Computation 上给出 $O(N\log N)$ 的算法，原理是把序列送进频率域，在那里 convolution（卷积）退化成逐点相乘。值得注意的是 Gauss 早在 1805 年为 Pallas 与 Juno 两颗小行星做轨道插值时就用过同一种分解，只是没有发表，这条算法因此在纸上被埋了一百六十年才被现代机器重新捡起来。
>
> 代入数字收尾。设 $X$ 取 $0,1,2$ 的概率为 $1/4,\ 1/2,\ 1/4$（正是二项分布 $B(2, 1/2)$），$Y$ 取 $0,1$ 的概率各为 $1/2$。则 $p_W(0) = (1/4)(1/2) = 1/8$；$p_W(1) = (1/4)(1/2) + (1/2)(1/2) = 3/8$；$p_W(2) = (1/2)(1/2) + (1/4)(1/2) = 3/8$；$p_W(3) = (1/4)(1/2) = 1/8$。四项合计为一，且与 $B(3, 1/2)$ 逐项相同；期望 $\mathrm{E}[W] = 1 \cdot \frac{3}{8} + 2 \cdot \frac{3}{8} + 3 \cdot \frac{1}{8} = 1.5$，恰等于 $1 + 0.5$，与期望的线性性吻合。这说明 binomial（二项）分布在卷积下封闭：独立二项相加，参数 $n$ 与 $p$ 各自相加，这是本讲第一个「卷积不制造新家族」的例子，下一个例子就是正态。这一点在工程上很实用：要抽一个 $B(3, 1/2)$ 样本，只需独立抽三个 Bernoulli（伯努利）变量再相加，不必为每个 $n$ 单独写一套抽样代码。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.213–218</span>

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板 + 跨课程连接）:**</span> 命名模板——flip-and-shift（翻转–平移）卷积机械：把 $p_Y$ 翻转得 $p_Y(-x)$、平移 $w$、与 $p_X$ 逐点相乘再累加，输出恰为 $p_W(w) = \sum_x p_X(x) p_Y(w - x)$。这一节的价值不在于再推一次公式，而在于把推导固化成四个能照着做的动作：翻转、平移、对位、相乘求和。
>
> 为什么模板值钱：公式一旦变成固定动作，就不必每次重推。四步里最费解的是"翻转"，理由在于求和式中两个因子对 $x$ 的依赖方向相反——$p_X(x)$ 顺着 $x$ 走，而 $p_Y(w - x)$ 是倒着走。若两支都顺着摆，要对齐的项就是"脚标之差等于 $w$"的那些，窗口斜着滑，手算必错位。翻过来以后，"和为 $w$"变成"位置对齐"，求和退化成 inner product（内积）：逐位相乘、整体相加。这是把一个卷绕的指标变换翻译成一个整齐的对位操作。四个动作的顺序也不能随意调换：先翻转再平移，与先平移再翻转再整体反射，落点是同一个分布，但前者让"和为 $w$"直接变成"位置相同"，是唯一能一眼目测对不对的排法，所以教材把它定为标准动作。
>
> 反过来检查常见错误，看看模板少了哪一步就坏。若漏掉翻转、直接写 $\sum_x p_X(x) p_Y(x)$，在均匀 $\{0, 1\}$ 的例子中每个 $w$ 都得到 $1/4 + 1/4 = 1/2$，而 $w$ 只取 $0, 1, 2$ 三个值，总质量成了 $3/2$，归一化当场崩掉。漏掉平移则质量全堆在 $w = 0$：$p_W(0) = 1$，后两点为零，期望算成零而真值是一。两步各管一件事，缺一步就错一整类。模板还顺带给出支撑集：$w$ 只能落在两个支撑集逐点相加得到的集合上，$\{0, 1\}$ 加 $\{0, 1\}$ 得 $\{0, 1, 2\}$，故 $P(W = 3) = 0$，不必算就知道。
>
> 最小验算：$X, Y$ 独立同取 $\{0, 1\}$ 上均匀，则 $p_W(0) = 1/4$、$p_W(1) = 1/2$、$p_W(2) = 1/4$ ✓，与 binomial（二项）$B(2, 1/2)$ 逐项一致；$E[W] = 1$ 对上期望线性，$var(W) = 1/2$ 对上 $1/4 + 1/4$，三条独立结论互相咬合。
>
> 再算一个不对称的例子，防止模板只在对称情形才看着顺眼。取 $p_X$ 在 $\{0, 1\}$ 上为 $(1/3,\ 2/3)$，$p_Y$ 在 $\{0, 1\}$ 上为 $(1/4,\ 3/4)$。则 $p_W(0) = (1/3)(1/4) = 1/12$；$p_W(1) = (1/3)(3/4) + (2/3)(1/4) = 1/4 + 1/6 = 5/12$；$p_W(2) = (2/3)(3/4) = 1/2$。三项合计 $1/12 + 5/12 + 6/12 = 1$ ✓。期望两条路对账：直接算 $0 + 5/12 + 1 = 17/12 \approx 1.4167$；按线性性算 $2/3 + 3/4 = 8/12 + 9/12 = 17/12$ ✓。方差也对得上：$var(X) = (2/3)(1/3) = 2/9$，$var(Y) = (3/4)(1/4) = 3/16$，和为 $59/144 \approx 0.4097$；另一方面 $E[W^2] = 5/12 + 4 \times (1/2) = 29/12$，减去 $E[W]^2$ 得 $59/144$，两条路同值。
>
> 跨课程连接之一：6.042J 的 generating function（生成函数）。独立和的 PGF（probability generating function，概率生成函数，即把 PMF（probability mass function，概率质量函数）的每一项 $p(k)$ 当作 $z^k$ 的系数拼成的幂级数）等于各自 PGF 的乘积，"多项式相乘、按 $w$ 次幂收集系数"正是 $\sum_x p_X(x) p_Y(w - x)$ 的代数化身。这条恒等式在组合数学里有专门的名字：Vandermonde（范德蒙德）convolution（卷积），$\sum_k \binom{m}{k}\binom{n}{w-k} = \binom{m+n}{w}$，1772 年由 Alexandre-Théophile Vandermonde 正式发表，更早在 1303 年元代朱世杰的著作里已使用；它就是"二项加二项仍是二项"在系数层面的写法。区别在于视角：生成函数把 convolution（卷积）变成乘法，flip-and-shift 把 convolution（卷积）变成内积，同一个对象的两种坐标。
>
> 跨课程连接之二：CLRS 第 30 章的 polynomial multiplication（多项式乘法），以及 6.006 的 DP（dynamic programming，动态规划）递推。记 $q_m(w)$ 为前 $m$ 个独立变量之和等于 $w$ 的 probability（概率），则 $q_m(w) = \sum_x q_{m-1}(w - x) p_{X_m}(x)$，与 knapsack（背包）那条 $dp[i][s] = \sum_k dp[i-1][s-k]$ 结构相同，只是累加价值换成累加概率。代价对比很硬：支撑集各含 $N$ 个点，一次 convolution（卷积）是 $O(N^2)$，$m$ 个逐个卷是 $O(mN^2)$；倍增可压到 $O(N^2 \log m)$，FFT（fast Fourier transform，快速傅里叶变换）直接压到 $O(N \log N)$。区别在适用面：DP 版本可以增量算，适合 $N$ 小 $m$ 大；FFT 版本要 padding（补零填充）到两倍长度，适合 $N$ 大而只卷一两次。
>
> 收束：这页"沿斜线 $x + y = w$ 收集质量"的格点图值得在脑中存一份——下一页它会被积分解读，离散的对角线求和变成连续的一条直线上的积分，四个动作一字不改。把这条模板背成四拍口令（翻、移、对、加），比背一行求和式更抗遗忘。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The continuous case（连续情形：卷积）</span>

- $W = X + Y$；$X, Y$ 独立。

> <span style="color:#7f8c8d;">图：把格点图换成连续平面——质量沿直线 $x + y = w$ 收集，竖直线 $x$ 固定处，$w$ 轴上平移量为 $w - x$。</span>

- 给定 $X = x$，$W = x + Y$ 只是 $Y$ 的平移：$f_{W|X}(w \mid x) = f_Y(w - x)$。
- 乘法公式展开联合密度：$f_{W,X}(w, x) = f_X(x)\, f_{W|X}(w \mid x) = f_X(x)\, f_Y(w - x)$。
- 对 $x$ 积分（边缘化）：
```math
f_W(w) = \int_{-\infty}^{\infty} f_X(x)\, f_Y(w - x)\, dx .
```

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.217–218</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Two independent normal r.v.s（两个独立的正态随机变量）</span>

- $X \sim N(\mu_x, \sigma_x^2)$，$Y \sim N(\mu_y, \sigma_y^2)$，相互独立：
```math
f_{X,Y}(x, y) = f_X(x)\, f_Y(y) = \frac{1}{2\pi \sigma_x \sigma_y} \exp\!\left( -\frac{(x - \mu_x)^2}{2\sigma_x^2} - \frac{(y - \mu_y)^2}{2\sigma_y^2} \right).
```
- 该 PDF 在椭圆 $\dfrac{(x - \mu_x)^2}{2\sigma_x^2} + \dfrac{(y - \mu_y)^2}{2\sigma_y^2} =$ 常数 上取常值。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> **类别：跨课程连接 + 图解注。** 先说这张等高线图为什么长成椭圆。把 PDF 取对数再取负号，指数上的两个平方项就露了出来：等密度线就是让 $\frac{(x-\mu_x)^2}{\sigma_x^2} + \frac{(y-\mu_y)^2}{\sigma_y^2}$ 等于常数的点集。这不是什么新对象，它就是 center（中心）在 $(\mu_x, \mu_y)$、半轴分别沿两个坐标轴的一条 ellipse（椭圆）。取常数等于 $2c$，半轴长度就是 $\sigma_x\sqrt{2c}$ 与 $\sigma_y\sqrt{2c}$；特别地取 $c = 1/2$，得到所谓的「一西格玛椭圆」，两条半轴恰好就是 $\sigma_x$ 与 $\sigma_y$——这才是「标准差是椭圆半径」这句话的准确含义。
>
> 换成 Strang 的 linear algebra（线性代数）语言，一切都对上。令 $v = (x - \mu_x,\ y - \mu_y)$，协方差矩阵写成 $\Sigma = \mathrm{diag}(\sigma_x^2,\ \sigma_y^2)$，则刚才那个表达式就是 $v^T \Sigma^{-1} v$，一个 positive definite（正定）二次型。Strang 课上讲过：正定二次型的 level set（等值集）是椭圆，主轴方向是特征向量，半轴长度由 eigenvalue（特征值）倒数开方给出。这里 $\Sigma^{-1}$ 的两个特征值是 $1/\sigma_x^2$ 与 $1/\sigma_y^2$，于是半轴是 $\sigma_i\sqrt{2c}$，与直接配方得到的完全一致。还有一条等价链值得记住：两个变量 independent（独立）等价于 $\Sigma$ 是 diagonal（对角）矩阵，也等价于 eigenvector（特征向量）正落在坐标轴上，即椭圆不旋转。三个说法是同一件事的三种语言。
>
> 代数字进去。取 $\sigma_x = 2$、$\sigma_y = 1$、均值为零。在点 $(2, 0)$ 处二次型等于 $1$，在点 $(0, 1)$ 处也等于 $1$，所以两点的 density（密度）完全相同，都等于 $\frac{1}{2\pi \cdot 2} e^{-1/2} \approx 0.0483$。原点处二次型为零，密度取其最大值 $1/(4\pi) \approx 0.0796$。两值之比是 $e^{-1/2} \approx 0.6065$，正是「离开中心一个标准差」的标准衰减倍数——这个数在单变量情形也一样，一维正态在 $\mu \pm \sigma$ 处的密度就是峰值的 0.6065 倍。
>
> 再看等轴的特殊情形 $\sigma_x = \sigma_y = 1$，等高线退化成 circle（圆），密度只依赖半径 $r = \sqrt{x^2 + y^2}$。用极坐标积一次：$P(R \le r) = \int_0^{r} \int_0^{2\pi} \frac{1}{2\pi} e^{-\rho^2/2}\, \rho\, d\theta\, d\rho = 1 - e^{-r^2/2}$。代入 $r = 1$ 得 $1 - e^{-1/2} = 0.3935$，即一个标准差圆内只装了 39.35% 的概率；$r = 2$ 时是 $1 - e^{-2} = 0.8647$。这里有个必须纠正的直觉：很多人以为「一个标准差内六成八」在二维也成立，那是单变量的一维经验法则；二维的圆面积随半径平方长，所以同一半径要掉到不足四成。
>
> 读这张图按三步走。第一步找中心，它就是 mean（均值）向量。第二步沿两条坐标轴量到等高线的距离，量出来的就是两个标准差，同一条等高线上任意方向量都是同一个「距离单位」。第三步看椭圆有多扁，扁的程度就是两个方向不确定性的比值，$\sigma_x / \sigma_y = 2$ 的那个例子扁成二比一，一眼就能看出哪个方向更「散」。等轴即圆，说明两个方向同等不确定，这就是各向同性的图形版本。
>
> 这套几何对下一节的卷积直接有用：两个独立正态相加，协方差矩阵相加，对角阵加对角阵仍是对角阵，二次型相加仍是二次型，所以等高线仍是轴对齐椭圆，和的分布仍是正态。后面那段配方运算看起来很代数，几何上只是「两个椭圆叠起来还是椭圆」。再往前一步：若 $\Sigma$ 非对角，椭圆就旋转，主轴方向由 eigenvector（特征向量）给出，把数据投到主轴上就是 PCA（principal component analysis，主成分分析），也就是 SVD 的一次应用；现代的高斯混合模型与卡尔曼滤波，全都建立在这张等高线图上。
- $\sigma_x = \sigma_y$ 时椭圆成为圆（circle）。

> <span style="color:#7f8c8d;">Bertsekas §3.4, p.157–164；§3.3, p.154</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The sum of independent normal r.v.s（独立正态随机变量之和）</span>

- $X \sim N(0, \sigma_x^2)$，$Y \sim N(0, \sigma_y^2)$，独立；令 $W = X + Y$：
```math
f_W(w) = \int_{-\infty}^{\infty} f_X(x)\, f_Y(w - x)\, dx = \frac{1}{2\pi \sigma_x \sigma_y} \int_{-\infty}^{\infty} e^{-x^2/(2\sigma_x^2)}\, e^{-(w - x)^2/(2\sigma_y^2)}\, dx \overset{\text{（代数整理）}}{=} c\, e^{-\gamma w^2}.
```
- **结论**：$W$ 是 normal（正态）的：
  - mean（均值）$= 0$，variance（方差）$= \sigma_x^2 + \sigma_y^2$；
  - 均值非零的情形用同样的论证处理。

> <span style="color:#7f8c8d;">Bertsekas §4.1, p.217–218</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 跨课程连接）:**</span> 被"代数整理"三个字吞掉的东西必须补全，否则读者只会记住结论而不会重做。把指数展开：$\frac{x^2}{2\sigma_x^2} + \frac{(w - x)^2}{2\sigma_y^2}$ 先按 $x$ 的幂归并，$x^2$ 的系数是 $A = 1/\sigma_x^2 + 1/\sigma_y^2$，$x$ 的系数是 $-2w/\sigma_y^2$，常数项是 $w^2/\sigma_y^2$。于是指数是一支关于 $x$ 的二次多项式，按 $x$ 配成完全平方之后，$x$ 的部分只剩 $-\frac{A}{2}(x - B/A)^2$，其中 $B = w/\sigma_y^2$；剩下的常数项合并后恰好是 $-\frac{w^2}{2(\sigma_x^2 + \sigma_y^2)}$，这就是 $\gamma = \frac{1}{2(\sigma_x^2 + \sigma_y^2)}$ 的来历。
>
> 为什么配完方之后常数不用硬算。被积函数现在是一个只含 $w$ 的因子 $e^{-\gamma w^2}$，乘上一个关于 $x$ 的 Gaussian（高斯）核；对 $x$ 积分时，那个因子是常数，提得出来，只剩核的积分。而核的积分可以算，也可以不算：因为 $w$ 只剩二次项，形状已经确定是 normal（正态），归一化这条约束会自动把系数钉死，故 $c = 1/\sqrt{2\pi(\sigma_x^2 + \sigma_y^2)}$ ✓。真正被"整理"掉的是这一步——正态的形状一旦确定，常数就被质量守恒唯一决定，不必再动手积分。
>
> 代数字进去，两面都能验。取 $\sigma_x = 1$、$\sigma_y = 2$、均值为零。峰值 $c = 1/\sqrt{2\pi \times 5} = 1/\sqrt{31.4159} = 1/5.6050 \approx 0.17841$。对照两个分量各自的峰值：$1/\sqrt{2\pi} \approx 0.39894$ 与 $1/(2\sqrt{2\pi}) \approx 0.19947$，卷积后的峰 $0.17841$ 比两者都低——质量被摊到更宽的支撑上，峰值必然下降，这正是 variance（方差）相加在图形上的样子。再看一点：$w = 1$ 时指数是 $-1/10$，$e^{-0.1} \approx 0.90484$，故 $f_W(1) \approx 0.17841 \times 0.90484 \approx 0.16144$；同一点上分量自己的密度分别是 $0.24197$ 与 $0.17603$，仍是卷积值最小。
>
> 交叉验证方差：零均值时 $var(W) = \sigma_x^2 + \sigma_y^2 = 1 + 4 = 5$，标准差 $\sqrt{5} \approx 2.23607$，于是 $P(|W| \le 2.23607) \approx 0.6827$，正好是单变量那条一个标准差的法则搬过来。这条结论与 Lec 07 的方差和规则给出的值完全相同，卷积与方差两条独立推导互相咬合 ✓——一条来自密度积分，一条来自二阶矩代数，两条路走到底得到同一个数，才叫验算通过。
>
> 还有一条更省力的证明值得知道：characteristic function（特征函数）定义为 $\phi(t) = E[e^{itX}]$，正态的它等于 $e^{-\sigma^2 t^2/2}$，两个独立变量之和的特征函数是两个特征函数之积，指数相乘等于指数相加，于是 $\sigma^2$ 直接相加，封闭性一行证完。区别在于：卷积要在 $x$ 上做一次积分，特征函数只要乘一个函数——代价是要先承认这个变换可逆，收益是把积分问题换成代数问题。
>
> 跨课程连接：Strang 的 linear algebra（线性代数）里，配方是"二次型相加仍是二次型"的一维情形。把两个变量写成向量，covariance matrix（协方差矩阵）是 $\Sigma = \mathrm{diag}(\sigma_x^2, \sigma_y^2)$，联合密度指数上的二次型是 $v^T \Sigma^{-1} v$，其中 $v$ 是中心化后的点。两个 independent（独立）正态相加，就是把两个对角矩阵加起来，对角阵加对角阵仍是对角阵，所以主轴仍与坐标轴对齐，可以逐坐标配方而不必求 eigenvector（特征向量）。区别在于一旦 $\Sigma$ 非对角，主轴就旋转，那时必须做 eigen-decomposition（特征分解）才能配方；本讲这一步之所以能一路顺下来，全靠 independence（独立）把矩阵压成了对角。
>
> 均值非零时怎么办：把 $W$ 拆成零均值部分加上 $\mu_x + \mu_y$，前者刚刚算完，后者只是一个平移，density（密度）整体右移而形状不变。具体地，$\mu_x = 1$、$\mu_y = -0.5$ 时新峰值出现在 $w = 0.5$，峰高仍是 $0.17841$，其余数值一律照搬。
>
> 收束：这条注的要点不是背出卷积结果，而是记住三件事——配方的目的是把 $w$ 与 $x$ 分离、分离后常数由归一化免费得到、$\sigma^2$ 相加可以从密度、从二阶矩、从特征函数三条路各自独立验证一遍。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Covariance（协方差）</span>

- 定义：$\mathrm{cov}(X, Y) = \mathrm{E}\big[(X - \mathrm{E}[X]) \cdot (Y - \mathrm{E}[Y])\big]$。
- 零均值情形：$\mathrm{cov}(X, Y) = \mathrm{E}[XY]$。

> <span style="color:#7f8c8d;">图：两张散点图——左图点云沿正向倾斜（正协方差：两个中心化变量同进退），右图点云沿负向倾斜（负协方差：一升一降）。</span>

- 展开式：$\mathrm{cov}(X, Y) = \mathrm{E}[XY] - \mathrm{E}[X]\,\mathrm{E}[Y]$。
- 多变量方差公式：
```math
\mathrm{var}\!\left( \sum_{i=1}^{n} X_i \right) = \sum_{i=1}^{n} \mathrm{var}(X_i) + 2 \sum_{(i,j):\, i<j} \mathrm{cov}(X_i, X_j).
```
- 独立 $\Rightarrow \mathrm{cov}(X, Y) = 0$（converse is not true，逆命题不真）。

> <span style="color:#7f8c8d;">Bertsekas §4.2, p.221–222</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这条注诊断两个错误直觉：一是把"不相关"当成"独立"，二是把和的方差顺口写成方差之和。"独立 $\Rightarrow$ 不相关"一行就证完：$\mathrm{E}[XY] = \mathrm{E}[X]\mathrm{E}[Y]$（Lec 07 已证），代入 $\mathrm{cov}(X,Y) = \mathrm{E}[XY] - \mathrm{E}[X]\mathrm{E}[Y] = 0$ ✓。逆命题不真——反例：$X \sim U[-1, 1]$（$U$ 即 uniform，均匀分布），$Y = X^2$。$\mathrm{E}[X] = 0$，且 $\mathrm{E}[XY] = \mathrm{E}[X^3] = 0$（奇函数在对称区间上的积分为零），故 $\mathrm{cov}(X, Y) = 0$；但 $Y$ 由 $X$ 完全决定，相依到极致 ✓。
>
> 先问那个证明到底用了什么。$\mathrm{E}[XY]$ 定义成一个二维积分，被积函数是 $xy$ 乘联合 density（密度）$f_{X,Y}$；independent（独立）给出 $f_{X,Y}(x,y) = f_X(x)f_Y(y)$，于是一个二重积分按 Fubini 定理拆成两个一维积分之积，正好是 $\mathrm{E}[X]\mathrm{E}[Y]$。不独立时这一步拆不开，差出来的部分就被定义为 covariance（协方差）。所以 covariance（协方差）的语义很明确：它是"乘积的期望"与"期望的乘积"之间的那道缺口，缺口为零只说明这道乘积分解成立，不说明任意函数都能分解。
>
> 把反例的"独立与否"用数字钉死，别只凭直觉。取 $A = \{X > 1/2\}$，则 $P(A) = (1 - 1/2)/2 = 1/4$；取 $B = \{Y \le 1/4\} = \{|X| \le 1/2\}$，则 $P(B) = 1/2$。而 $A \cap B$ 是空集——只要 $X > 1/2$ 就有 $Y > 1/4$，故 $P(A \cap B) = 0$，与 $P(A)P(B) = 1/8$ 不等，dependent（相依）确认 ✓。顺带把二阶量也算出来：$X$ 的二阶矩是 $1/3$，$Y = X^2$ 的四阶矩是 $1/5$，故 $var(X) = 1/3 \approx 0.3333$，$var(Y) = 1/5 - (1/3)^2 = 4/45 \approx 0.0889$，两个方差都不为零而 covariance（协方差）恰为零——零的是交叉项，不是各自的散布。
>
> 多变量方差公式是上讲两个"幽灵陷阱"的解剖图。设 $X$ 与 $Z$ 独立、各自方差为 $1$，令 $Y = X + Z$。直接展开：$var(X + Y) = var(2X + Z) = 4 \times 1 + 1 = 5$。套公式：$var(X) + var(Y) + 2cov(X, Y) = 1 + 2 + 2 \times 1 = 5$ ✓，其中 $cov(X, Y) = cov(X, X) + cov(X, Z) = 1 + 0 = 1$。三个极端情形一并看清：$X = Y$ 时 $cov = var(X)$，和的方差翻到四倍；$X = -Y$ 时 $cov = -var(X)$，方差对消成零；独立时交叉项全消失，方差才等于方差之和。夹在中间的一切情形，都由那个 $2 \times$ 的交叉项调节。
>
> 符号语义也要落到图上。中心化乘积 $(X - \mathrm{E}[X])(Y - \mathrm{E}[Y])$ 的符号只看两家是不是同向偏离自己的均值：同时偏高或同时偏低为正，一高一低为负。于是散点图的倾斜方向直接对应 cov 的符号，而斜率陡不陡、点云多散，对应的是绝对值。要记住的是这把尺子只量"线性同向"，点云摆成一条抛物线时正负两半互相抵消，读出来的就是零。
>
> 跨课程连接之一：6.042J 的 equivalence relation（等价关系）。等价关系要求自反、对称、传递三条齐全，而 independent（独立）只满足对称——$X$ 与 $Y$ 独立等价于 $Y$ 与 $X$ 独立，但 $X$ 与它自己不独立，除非 $X$ 是常数。所以独立不能被当成一种"分类"去切 partition（划分），它说的是"联合分布能否分解成边缘分布之积"这条方程是否成立。区别就在这里：等价关系的产物是若干互不相交的块，独立性的产物是一条乘法等式。
>
> 跨课程连接之二：Strang 的 linear algebra（线性代数）。把两个变量拼成向量，covariance matrix（协方差矩阵）$\Sigma$ 的非对角元正是 cov，独立等价于 $\Sigma$ 为 diagonal（对角）矩阵。区别在于矩阵里的零只说明二阶矩层面正交，联合密度的分解还需要更高阶的等式 $\mathrm{E}[g(X)h(Y)] = \mathrm{E}[g(X)]\mathrm{E}[h(Y)]$ 对一切函数成立；二阶矩只查了 $g$、$h$ 都取一次幂的那一格，所以逆命题的反例可以安稳地存在。
>
> 再补一个"用错工具"的具体后果。假设真把 $Y = X^2$ 当成"与 $X$ 无关"，据此断定"知道 $X$ 对预测 $Y$ 毫无帮助"——这是彻底的错误：知道 $X$ 就等于知道 $Y$，预测误差为零。真实含义只是"用 $a + bX$ 这种线性形式去预测 $Y$ 时，最优的 $b$ 恰为零"，于是线性预测的残差方差等于 $var(Y) = 4/45 \approx 0.0889$，全部方差都没被解释掉。工具没错，是问题问错了。
>
> 收束：三条诊断口令——看见"不相关"先问"独立吗"，看见"方差和"先找交叉项，看见"$\rho = 0$"先画散点图看形状；这三句比公式更能挡住错误。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Correlation coefficient（相关系数）</span>

- 协方差的无量纲（dimensionless）版本：
```math
\rho = \mathrm{E}\!\left[ \frac{X - \mathrm{E}[X]}{\sigma_X} \cdot \frac{Y - \mathrm{E}[Y]}{\sigma_Y} \right] = \frac{\mathrm{cov}(X, Y)}{\sigma_X\, \sigma_Y}.
```
- $-1 \le \rho \le 1$。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> **类别：历史与人物 + 第一性原理。** 这个量不是 Pearson 一个人造出来的。1846 年法国矿物学家 Bravais 研究测量点的误差椭圆时，第一次写下二维正态的联合密度并引入乘积矩，所以老文献里它叫 Bravais coefficient（布拉维系数）。Galton 在 1886 年分析九百多名成年子女与中亲身高，发现等高线是同心椭圆，并造出 regression（回归）一词来描述「极端父母的子女没那么极端」这一现象。Pearson 在 1895 年 9 月提交、1896 年发表在 Philosophical Transactions of the Royal Society A 第 187 卷 253 至 318 页的那篇长文里，才把它整理成今天的公式与符号。代价要记住：Pearson 的推导假设二维正态，而样本相关系数的精确分布直到 1915 年才由 Fisher 在 Biometrika 第 10 卷 507 至 521 页给出，这中间十几年想对 $\rho$ 做显著性检验，只能靠查表凑。
>
> 第二层问题是：界为什么恰好是正负一。把两个变量各自中心化再除以标准差，得 $u = (X - \mu_X)/\sigma_X$ 与 $v = (Y - \mu_Y)/\sigma_Y$，这两个新变量的平方期望都是 $1$。在随机变量空间上定义 inner product（内积）为 $\langle A, B\rangle = \mathrm{E}[AB]$，则 $u$、$v$ 都是单位向量，而 $\rho = \langle u, v\rangle$ 正是夹角余弦。于是 $|\rho| \le 1$ 根本不需要技巧：它是 Cauchy–Schwarz（柯西–施瓦茨）不等式的直接推论。
>
> 端点也直白：$\rho = 1$ 意味着 $u = v$，两者完全正比例；$\rho = -1$ 意味着 $u = -v$，完全负比例。中间的值只是「线性成分」的带符号刻度，没有额外语义。顺便补一段命名史：这个不等式 1821 年由 Cauchy 在《Analyse algébrique》中对有限和给出，1859 年 Bunyakovsky 给出积分形式，1888 年 Schwarz 独立证明并把思想推广到内积空间，三个名字各挂一段历史，所以有的书把它写成 Cauchy–Bunyakovsky–Schwarz（柯西–布尼亚科夫斯基–施瓦茨）不等式。
>
> 代数字检查一个最容易误读的地方。设 $X \sim N(0, 1)$，$\varepsilon \sim N(0, 1)$ 与 $X$ 独立，令 $Y = X + \varepsilon$。则 $\mathrm{cov}(X, Y) = \mathrm{var}(X) + \mathrm{cov}(X, \varepsilon) = 1$，$\sigma_Y = \sqrt{1 + 1} = \sqrt{2}$，所以 $\rho = 1/\sqrt{2} \approx 0.7071$。注意 $Y$ 有一半的方差来自纯噪声，$\rho$ 仍然给出 $0.707$——把 $0.7$ 读成「七成线性」是错的，$\rho$ 与方差占比不是同一个刻度。要问方差占比，看的是 $\rho^2 = 1/2$，它恰好等于可由 $X$ 解释的那部分方差比例，这才是平方 $\rho$ 的正当理由。
>
> 再看这个量的边界在哪。$\rho$ 只认线性，$Y = X^2$ 这种完全相依也能给出零，所以后续发展分成两路。第一路改秩：把每个样本换成它在样本里的排名，再算同样的乘积矩系数，得到 Spearman rank correlation（斯皮尔曼秩相关），它对单调非线性敏感、对 outlier（离群点）稳健，代价是丢掉数值之间的距离信息。第二路换度量：Székely、Rizzo 与 Bakirov 在 2007 年 Annals of Statistics 第 35 卷第 6 期 2769 至 2794 页提出 distance correlation（距离相关），它是第一个满足「取零当且仅当独立」的相依度量，代价是要算 $n^2$ 的距离矩阵，样本一多就吃不动。
>
> 最后给一条读法。$\rho$ 的符号给方向，绝对值给线性强度，平方给可解释比例；它对方差里的大偏差格外敏感，因为每一项都带平方，一个 outlier（离群点）就足以把 $0.9$ 拖到 $0.3$。它也不能倒过来推因果：两个变量同受第三个变量驱动时，$\rho$ 照样很高。这三句话比公式本身更值得记牢——公式翻手册就有，误读的代价却要由用它的人自己承担。
- $|\rho| = 1 \iff (X - \mathrm{E}[X]) = c\, (Y - \mathrm{E}[Y])$（linearly related，线性相关）。
- 独立 $\Rightarrow \rho = 0$（逆命题不真）。

> <span style="color:#7f8c8d;">Bertsekas §4.2, p.221–222</span>

> <span style="color:#1e8449;">**[note] Note（译者注，验证 + 跨课程连接）:**</span> 界的验算：对任意实数 $t$，$0 \le \mathrm{var}(X/\sigma_X + t\, Y/\sigma_Y)$，展开得 $0 \le 1 + t^2 + 2 t \rho$；取 $t = \pm 1$ 得 $0 \le 2 \pm 2\rho$，即 $-1 \le \rho \le 1$ ✓。端点语义：取等时该线性组合的方差为零，退化成常数，故 $\lvert \rho \rvert = 1$ 当且仅当标准化后的 $X, Y$ 严格线性相关 ✓。
>
> 先补一句"为什么取 $t = \pm 1$ 就够了"。那个关于 $t$ 的二次式 $1 + t^2 + 2t\rho$ 是一条开口朝上的抛物线，顶点在 $t = -\rho$，最小值是 $1 - \rho^2$。所以真正的完整不等式是 $1 - \rho^2 \ge 0$，取 $\pm 1$ 只是两组最省事的特殊值，恰好把两个端点同时逼出来。更好的一步是直接把 $t = -\rho$ 代进去：$0 \le \mathrm{var}(Y/\sigma_Y - \rho X/\sigma_X) = 1 + \rho^2 - 2\rho^2 = 1 - \rho^2$，一步得到 $\rho^2 \le 1$，而且顺带看清了 $\rho$ 的身份——它就是"用 $X$ 的标准化值去线性逼近 $Y$ 的标准化值时，让残差方差最小的那个系数"。
>
> 端点用数字钉一下。取 $Y = 2X + 3$，$var(X) = 1$，则 $cov(X, Y) = 2 var(X) = 2$，$\sigma_Y = 2$，$\sigma_X = 1$，故 $\rho = 2/(1 \times 2) = 1$，正的完全线性。再取 $Y = -0.5X$，则 $cov = -0.5$，$\sigma_Y = 0.5$，$\rho = -0.5/0.5 = -1$。两个例子都验证那条等价：标准化后两者只差一个正负号，方差为零，于是取等。
>
> 无量纲化到底省掉了什么，用一次单位换算看清。设 $X$ 以厘米计、$Y$ 以千克计，把 $X$ 改成米（除以 $100$）、$Y$ 改成克（乘 $1000$），covariance（协方差）就乘上 $1000/100 = 10$，数值变了十倍；correlation（相关系数）因为分子分母同时乘十倍而毫无变化。这就是为什么跨问题比较只能用 $\rho$ 而不能用 cov：cov 的数值是"兄、千克"这种复合单位下的读数，换一把尺子就换一个数。
>
> $\rho^2$ 的含义也从这里出来，而且可以算到底。回到上一节那个 $Y = X + \varepsilon$（$X$ 与 $\varepsilon$ 独立、各为 $N(0,1)$）的例子：$\sigma_Y^2 = 2$，$\rho = 1/\sqrt{2}$，故 $\rho^2 = 1/2$。用 $X$ 做线性预测时，残差方差等于 $\sigma_Y^2(1 - \rho^2) = 2 \times (1 - 1/2) = 1$，正好等于 $\varepsilon$ 的方差 ✓——噪声是 $1$、信号也是 $1$，一半方差可解释、一半不可解释。这个数才是"相关强度"的正当读法，而 $0.707$ 只是它的平方根。
>
> 跨课程连接：Strang 的 linear algebra（线性代数）里，$\langle A, B \rangle = \mathrm{E}[AB]$ 是一个 inner product（内积）：对称、双线性、正定三条全对得上，条件是方差有限。在这个空间里，标准化后的两个变量都是单位向量，$\rho$ 就是它们夹角的 cosine（余弦），$-1 \le \rho \le 1$ 只是 cosine（余弦）取值范围的翻译。区别在于：欧氏空间里的正交是一个纯几何事实，而这里"内积为零"同时背负着独立与不独立两种可能，$Y = X^2$ 那个反例就是正交但不独立的活样本。
>
> 这条连接在工程里已经变成常用工具：信息检索里的 cosine similarity（余弦相似度）把文档向量归一化后取内积，与本节的标准化再取期望是同一个动作；区别在于文档向量的分量是非负词频、内积恒非负，读不到负相关，而随机变量的 $\rho$ 能取负值，因为中心化把"低于均值"变成了负数。
>
> 还要守一条边界条件：$\rho$ 要求两个 variance（方差）都有限且不为零。上一节那个比值分布就是反例——它的期望都不存在，也就谈不上 $\sigma_Z$，$\rho$ 对它没有定义。重尾世界里能用的只有中位数与尾概率，这类"连二阶矩都没有"的对象，相关系数这件工具根本递不过去。
>
> 收束：一句话把这条注收住——$\rho$ 是标准化向量之间的夹角余弦，界 $-1$ 到 $1$ 是余弦的界，$\rho^2$ 是可解释方差比例，三个身份各自对应一条可验证的等式；再往上一层还有"独立强化不相关、反之不然"这条单向箭头，它把线性世界与概率世界分在两处。
