<span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b;">**Problem 1**</span>

> <span style="color:#2471a3;">**[solution]**</span>
>
> **a)** 时刻 $n$ 剩余绿鱼的数目，已经完全决定了系统全部历史中所有与预测未来状态相关的信息。这里要看到的是：下一次「钓起一条绿鱼」的概率只取决于当前绿鱼的数目，而与该数目是如何一步步到达的无关。因此，绿鱼的数目就是系统的状态，且该过程具有马尔可夫性（Markov property）：
>
> ```math
> P\left(X_{m+1}=j \mid X_m=i,\ X_{m-1}=i_{m-1},\ \ldots,\ X_1=i_1\right) = P\left(X_{m+1}=j\mid X_m=i\right).
> ```
>
> 也就是说，给定「现在」的状态 $X_m=i$，过去各时刻的取值 $i_1,\dots,i_{m-1}$ 不会再提供任何关于「未来」$X_{m+1}$ 的额外信息。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条把 state（状态）当成「随手取的量」了，实际上它不是。Markov property（马尔可夫性）不是对世界的简化假设，而是对「什么叫状态」的定义：一个量能当 state，当且仅当它把历史里所有对未来的影响吸收干净了。换一种说法，state 是一个压缩映射——它把所有「到达同一个当前值的不同历史」全部归为一类，并宣称这些历史对未来不可区分。绿鱼数之所以合格，是因为钓鱼这件事没有记忆：鱼不知道自己昨天被钓走几条，也不会因此变得更警觉或更迟钝。
>
> 为什么必须长成这样，可以从「能不能在有限内存里推进」来问。要给未来分布一个递推，你手头就必须只有有限个数字。绿鱼数只取 $k+1$ 个值，所以只要一张 $(k+1)\times(k+1)$ 的表就够了；如果未来的概率还依赖昨天钓了几条、前天钓了几条，那张表就得按历史长度不断膨胀，永远写不完。马尔可夫性就是「递推能够闭合」这件事的数学表述，等价于说：给定现在，过去与未来条件独立，即满足 conditional independence（条件独立）。
>
> 去掉这个条件会塌成什么样？假设绿鱼被钓走后剩下的鱼变得更难钓，即下一次成功的概率依赖上一轮钓到了没有。这时当前鱼数 $i$ 就不足以决定下一步：同样是 $i$，上一轮成功和上一轮失败给出两个不同的 $p$。症状非常具体——$p_{ij}$ 这张表你根本填不出来，因为同一个 $(i,j)$ 有两个值。补救办法不是放弃马尔可夫性，而是扩大 state：把「绿鱼数」与「上一轮结果」合成一个新的 state，状态数变成 $2(k+1)$，马尔可夫性立刻就回来了。这说明选 state 的标准只有一条：它必须足够，也就是「够用」。
>
> 跨课程看，这条思路你在 CSAPP 里天天用而不自知。context switch（进程切换）之所以只保存寄存器、PC、页表就能恢复，是因为体系结构保证了这套状态足以继续执行——这是硬件层面的马尔可夫假设。一旦存在没保存的隐状态，比如还没刷回内存的 store buffer 里的数据，恢复就会读到旧值；这和「state 选得不全、$p_{ij}$ 依赖历史」是同一个错误的两个化身。区别在于：CSAPP 的转移是确定性的，给定 state 下一步唯一；这里给定 state 得到的是一整个分布，所以转移用一个矩阵来记，而不是一个函数。
>
> 再往算法那边接一点：dynamic programming（动态规划）的 optimal substructure（最优子结构）讲究「只看当前子问题、不管怎么走到这里」，形式上就是马尔可夫性。但两者求解的对象不同：动态规划在取最小值那一类代数上做极值，马尔可夫链在做概率相加——第 5 条注会把这个「同一副骨架、两套代数」讲实。本条真正要拿走的一句是：马尔可夫性是你对建模对象提出的要求，不是定理；你必须负责证明它是真的（本例中就是「鱼没有记忆」这个物理事实），否则后面所有 $p_{ij}$ 都是空的。
>
> 还有一个常见的误读要提前拆掉：马尔可夫性说的是「给定现在，过去对未来没有额外信息」，而不是「过去与未来无关」。这两句话差别很大——绿鱼数确实与历史强烈相关（鱼少就说明前面被钓走了很多），但一旦把现在固定住，这份相关就断掉了。凡是看到「无记忆」三个字就以为「历史没有留下痕迹」的，都是在这一步滑倒的。
>
> **b)** 当 $j>i$ 时，必有 $p_{ij}=0$，因为绿鱼的数目只会减少、不会增加——蓝鱼永远不会被涂成绿色。对 $0\le i,\ j\le k$，有：
>
> ```math
> p_{ij} = P(\text{一次试验后绿鱼数由 } i \text{ 变为 } j \mid \text{当前绿鱼数为 } i) =
> \begin{cases}
> \dfrac{n-i}{n}, & j=i,\\[8pt]
> \dfrac{i}{n}, & j=i-1,\\[8pt]
> 0, & \text{其他情形}
> \end{cases}
> ```
>
> 这里每次试验只钓起一条鱼：若钓到的是蓝鱼（共 $n-i$ 条），绿鱼数不变，对应 $j=i$；若钓到的是绿鱼（共 $i$ 条），绿鱼数减一，对应 $j=i-1$；一步之内不可能减少两条及以上，故其余 $j$ 的概率为零。
>
> **c)** 状态 0 是吸收态（absorbing state），因为一旦绿鱼被全部钓光，此后每次试验都只会钓到蓝鱼、绿鱼数永远保持为 0，即 $p_{00}=1$、系统再也出不去。因此，0 条绿鱼的状态是唯一的常返态（recurrent state），从而其余所有状态都是非常返态（transient state）。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条把 0 判成唯一的 recurrent state（常返态）、其余全是 transient（非常返态），依据只是「一旦到 0 就出不去」。看着像一句显然的话，但它背后站着两段历史。先说结构上的要点：把状态按「能不能互相到达」分组，任何一组如果所有出边都落在组内就叫 closed（闭类）。吸收态 0 自己构成一个闭类，所以它常返；其他状态都能到 0 却回不来，概率质量不断往 0 漏，所以非常返。这套按类讨论的语言就是教材第 7.3 节的内容，本件是那一节的第三次习题课。
>
> Markov chain（马尔可夫链）这个名字来自 Andrey Markov，1906 年他在《大数定律关于相依变量的扩展》里第一次写出这种环环相扣的序列。动机并不纯粹：当时 Nekrasov 主张大数定律需要独立性，并借这一点论证「相互依赖的人类行为落在概率论之外」。Markov 用构造的方式回应——他造了一列并不独立、却仍满足大数定律的相依变量，「独立性不是必要条件」这句话因此有了具体模型。1907 年他还用《叶甫盖尼·奥涅金》里元音与辅音的先后依赖做了实证检验，这是拿真实数据检验一个概率模型的早期样本。
>
> 至于「被吸收」这件事，源头更早。1654 年 Pascal 与 Fermat 的通信处理了 problem of points（点数问题）：一局被打断的赌局，赌注怎么分。同一族问题里最朴素的一个就是 gambler's ruin（赌徒破产）：资金 0 与总额 N 是两端吸收态，中间全是 transient，问最终落到哪一端。今天看来它就是一个 absorbing chain（吸收链）。两人给了两条不同的路：Pascal 用 backward induction（倒推），从终局往回算；Fermat 数路径，用组合计数把每条路径的概率加起来。
>
> 这两条路在本文件里都出现了，值得对照着读。(a)(c)(d)(e) 偏 Fermat 式：把事件写成走某条特定路径，概率是沿途 $p_{ij}$ 的乘积再对路径求和；(b) 偏 Pascal 式：从「第一次转移去哪」分段，用全概率与条件概率倒着拼回来。同一道题两种写法都通，选哪个只看哪种把路径数得更少——这是概率题最实用的一条经验。
>
> 教材坐标：这套分类在 Bertsekas 与 Tsitsiklis 的 Introduction to Probability（概率论导论，Athena Scientific，2008 年第 2 版）第 7 章，6.041 Fall 2010 的 LEC 16 到 18 就读这一章。顺带说清一个常见误解：常返说的不是「一定会回来」，而是「以概率 1 回来」；在有限状态链里这两者恰好等价，但在无限状态链上，「以概率 1 回来」与「回来的期望时间有限」是两件不同的事，后者叫 positive recurrent（正常返）。本题状态有限，你不必区分，但要知道这个坑存在。
>
> 补一个更硬的论证，说明有限链里闭类为什么必然存在：概率质量总量恒为 1，每一步只是在状态之间搬运，既不会凭空产生也不会蒸发。如果每个状态都有一条出边把质量送到外面，而外面又能继续往外送，那就等于要求 1 份质量被切成无穷多份散掉，有限个状态做不到这件事。所以质量必然在某个位置停住，那个位置集合就是闭类。反过来，一旦状态有无穷多个，质量就真的可以漏光——比如在整数轴上一直往右走永不回头，此时可能一个常返类都没有。这正是有限与无限的分水岭，也是后面讨论稳态分布存在性时唯一真正用到有限性的地方。

<span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b;">**Problem 3**</span>

<span style="color:#1e8449;">**[note]** 本题题面（含状态转移图）因版权限制未收录于本 PDF，下面的转移结构系由解答反推重建，供读者对照阅读。状态集合为 $\{s_0,s_1,s_2,s_3,s_4,s_5\}$，过程从 $s_0$ 出发，逐次「试验」即逐次状态转移。由解答可知：$s_0$ 以概率 $\frac{1}{3}$ 转移到 $s_3$，以概率 $\frac{2}{3}$ 转移到 $s_1$ 或 $s_5$（二者各自的具体概率原文未给，但本题只用到其和 $\frac{2}{3}$）；$s_3$ 以概率 $\frac{1}{4}$ 停留、$\frac{1}{4}$ 转到 $s_2$、$\frac{1}{2}$ 转到 $s_4$；$s_2$ 以概率 $\frac{1}{2}$ 转到 $s_1$、$\frac{1}{2}$ 停留（见 (c)、(d)）；$s_1$ 与 $s_5$ 是吸收态，进入后永不离开，故也永不会进入 $s_4$。本题关心的核心事件是「过程是否进入 $s_4$」，以及首次进入 $s_1$、$s_2$、$s_3$ 的时机。</span>

> <span style="color:#2471a3;">**[solution]**</span>
>
> **（a）** 令 $A_k$ 为过程在第 $k$ 次试验（trial）首次进入状态 $s_2$ 的事件。要在第 $k$ 次试验首次进入 $s_2$，唯一的方式是：第一次试验进入 $s_3$，在接下来的 $k-2$ 次试验中停留在 $s_3$，最后一次试验进入 $s_2$。于是
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 题面里的状态转移图因版权被删了，只剩解答。读这种残件有一个稳定办法：把解答里每一个被用到的 $p_{ij}$ 看成图上的一条有向边，权就是那个数；再反过来用答案推断哪些边必然存在。下面把这张图复原一遍，以后遇到只有解答的习题都可以照这个流程走。
>
> 第一步，从 (a) 的乘积 $p_{03}\,p_{33}^{k-2}\,p_{32}$ 读出三条边：$s_0\to s_3$ 权 $\frac13$，$s_3\to s_3$ 这条 self-loop（自环）权 $\frac14$，$s_3\to s_2$ 权 $\frac14$。第二步，从 (b) 的「第一步到 $s_1$ 或 $s_5$ 的概率是 $\frac23$」读出存在两条出边，各自的值未知但和为 $\frac23$——这里「未知」是合法的，因为本题所有问题只关心会不会进 $s_4$ 或 $s_2$，而 $s_1$ 与 $s_5$ 在这两个问题上完全等价。
>
> 第三步最容易被跳过：由 (b) 的条件概率 $\frac{1/4}{1/4+1/2}=\frac13$ 反解出 $p_{34}=\frac12$。推理是：离开 $s_3$ 的总概率必须是 $1-p_{33}=\frac34$，而那个条件概率的分母 $\frac14+\frac12=\frac34$ 正好等于它，于是 $p_{32}=\frac14$ 与 $p_{34}=\frac12$ 相互印证。第四步，从 (c) 读出 $p_{22}=\frac12$ 即停留，从 (d) 读出 $p_{21}=\frac12$，两者相加为 1，所以 $s_2$ 只有两条出边，而且没有回到 $s_3$ 的边——这保证了进入 $s_2$ 之后要么原地踏步要么去 $s_1$，正是后半部分所有计算的前提。
>
> 图上有四处是关键的，读图时先找它们。其一，$s_3$ 的自环 $\frac14$：它是整道题里「时间可以被无限拖长」的唯一来源，没有它所有概率都是有限项的乘积，(a)(c)(e) 里的无穷级数根本不会出现。其二，$s_3$ 两条出边之比 $\frac14:\frac12=1:2$：这意味着离开 $s_3$ 后去 $s_4$ 的机会是去 $s_2$ 的两倍，所以最终进 $s_4$ 的概率 $\frac29$ 小于不进的 $\frac79$。其三，$s_1$ 与 $s_5$ 是吸收态，等于给路径封口，而且 $s_5$ 从 $s_0$ 一步可达，于是大量质量在第一步就永久离场。其四，$s_0\to s_1$ 与 $s_0\to s_5$ 的具体值是缺口，但这个缺口不影响任何答案。
>
> 最后一点值得单独记：两个状态如果对你要回答的全部问题都不可区分，就可以合并成一个，这叫 lumping（状态合并）。它既是读图的技巧，也是将来处理大状态空间时唯一能救命的办法——真实系统的状态数动辄上亿，只能先合并再算。自查方法也顺便给你：把所有从 $s_0$ 出发、长度不超过 3 的路径列出来，概率相加应得 1；单独挑出经过 $s_4$ 的那些，应得 $\frac29$。凑不出这两个数，说明你反推的图有一条边错了。
>
> 为什么读图要先找自环和吸收态？因为这两类边分别决定时间轴和概率轴的两端：自环决定「一步」能不能被无限重复，从而决定答案里会不会冒出级数；吸收态决定质量会不会中途被封存，从而决定「最终」这个词有没有意义。中间的普通边只负责分配比例，改一个数只改答案的数值，不会改答案的形状。由此得到一条实用判据：卡住时先问自己这题有没有自环、有没有吸收态——没有自环，答案必然是有限项乘积；有自环但算出的公比大于等于 1，那几乎肯定是某条边的权抄错了，因为概率之和不可能超过 1。
>
> 顺带把 (d) 在读图上的含义说清：要「第 3 次试验才首次进入 $s_1$」，图上就要求前两步一步不停、第三步正好踩到 $s_1$，可行路线只剩 $s_0\to s_3\to s_2\to s_1$ 这一条，所有自环都被排除，因为每踩一次自环就要多花一步。而原文末尾那行脚注（†）说明这类小问对 6.431 是必做、对 6.041 是选做，两档的难度差多半正落在这一层「路径唯一性」的推理上。
>
> ```math
> P(A_k) = p_{03}\cdot p_{33}^{\,k-2}\cdot p_{32} = \left(\frac{1}{3}\right)\left(\frac{1}{4}\right)^{k-2}\left(\frac{1}{4}\right) = \frac{1}{3}\left(\frac{1}{4}\right)^{k-1}\qquad (k=2,3,\ldots)
> ```
>
> 这里 $k$ 从 2 起是因为最短也要两步（$s_0\to s_3\to s_2$）；当 $k=2$ 时，$p_{33}^{\,k-2}=p_{33}^{\,0}=1$，对应「不在 $s_3$ 停留」的情形。
>
> **（b）** 令 $A$ 为过程永不进入 $s_4$ 的事件。$A$ 发生有三种可能的方式。前两种是第一次转移从 $s_0$ 到 $s_1$ 或从 $s_0$ 到 $s_5$，这发生的概率为 $\frac{2}{3}$；一旦进入 $s_1$ 或 $s_5$ 这两个吸收态，过程就再也到不了 $s_4$。另一种是第一次转移从 $s_0$ 到 $s_3$，且其后状态的下一次改变是转到状态 $s_2$。我们知道从 $s_0$ 到 $s_3$ 的概率是 $\frac{1}{3}$；在此发生的前提下，若从状态 $s_3$ 发生一次状态改变，则所转移到的是状态 $s_2$ 的概率就是
>
> ```math
> \frac{1/4}{1/4+1/2} = \frac{1}{3}.
> ```
>
> 这个条件概率的含义是：在 $s_3$ 上，离开它的总概率是 $p_{32}+p_{34}=\frac{1}{4}+\frac{1}{2}$（分子分母同除以「离开」这一前提），其中转到 $s_2$ 的那一支概率为 $\frac{1}{4}$，故在「确实离开 $s_3$」的条件下转到 $s_2$ 的概率为 $\frac{1/4}{1/4+1/2}$。
>
> 于是，从 $s_0$ 转移到 $s_3$ 并最终转移到 $s_2$ 的概率是 $\frac{1}{9}$（即 $\frac{1}{3}\times\frac{1}{3}$）。因此，永不进入 $s_4$ 的概率是
>
> ```math
> \frac{2}{3} + \frac{1}{9} = \frac{7}{9}.
> ```

**（续 Problem 3）**

> **（c）** 事件「过程进入 $s_2$ 并在下一次试验离开 $s_2$」意味着：过程在某一时刻首次进入 $s_2$，而紧接着的下一时刻就离开了它。由于 $s_2$ 有 $\frac{1}{2}$ 的概率停留（$p_{22}=\frac{1}{2}$），故「在 $s_2$ 的下一步离开它」的概率为 $\frac{1}{2}$。
>
> ```math
> P(\{\text{过程进入 } s_2 \text{ 并在下一次试验离开 } s_2\}) = P(\{\text{过程进入 } s_2\})\,P(\{\text{下一次试验离开 } s_2\}\mid\{\text{在 } s_2\})
> ```
>
> ```math
> = \sum_{k=2}^{\infty} P(A_k)\cdot\frac{1}{2} = \sum_{k=2}^{\infty} \frac{1}{3}\left(\frac{1}{4}\right)^{k-1}\cdot\frac{1}{2} = \frac{1}{6}\cdot\frac{1/4}{1-1/4} = \frac{1}{18}.
> ```
>
> 这里 $\sum_{k=2}^{\infty}P(A_k)$ 是「（在任何一次试验）首次进入 $s_2$」的总概率；最后的等比级数求和利用了首项 $\frac{1}{4}$、公比 $\frac{1}{4}$ 的几何级数公式 $\frac{a}{1-r}=\frac{1/4}{1-1/4}=\frac{1}{3}$。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一行是全题的技术核心，值得把它拆成一个可以反复搬用的模板。模板只有三步：先把「某事件最终会发生」改写成「它在第 $k$ 次试验第一次发生」，列出 $k$ 的取值范围；再声明这些首次命中事件互斥、并且并起来恰好就是「最终会发生」；最后把和式化成 geometric series（几何级数）。凡是题目里出现「首次」「在之前」「直到」这类词，第一步几乎必然是「按首次发生的时刻分割」，别的技巧都只是它的变体。
>
> 具体到本题，求和是 $\sum_{k=2}^{\infty}P(A_k)=\frac13\sum_{k=2}^{\infty}\left(\frac14\right)^{k-1}=\frac13\cdot\frac{1/4}{1-1/4}=\frac13\cdot\frac13=\frac19$。这里要盯住两处最容易翻车的地方。第一处是求和下标：$k$ 从 2 起，第一项不能当成 $k=0$ 那一项；原文已经把 $P(A_k)$ 化简成 $\frac13\left(\frac14\right)^{k-1}$，代入 $k=2$ 得 $\frac1{12}$，正好是「两步走到」的 $\frac13$ 乘 $\frac14$。第二处是公比：几何和是首项除以「1 减公比」，首项是 $k=2$ 那一项，不是 $k=0$ 那一项。这两处任一处错位，答案就差一个 $\frac14$ 的因子。
>
> 这里有一处表述需要修正，标出来免得你照着背错。原文在得到 $\frac1{18}$ 之后说，$\sum_{k=2}^{\infty}P(A_k)$ 是首次进入 $s_2$ 的总概率，而「最后的等比级数求和」给出 $\frac13$。严格算，$\frac{1/4}{1-1/4}=\frac13$ 只是几何和本身的值，它前面还挂着一个因子 $\frac13$，所以首次进入 $s_2$ 的总概率是 $\frac19$，不是 $\frac13$。这不是咬文嚼字：前面 (b) 已经算过「从 $s_0$ 到 $s_3$ 并最终到 $s_2$ 的概率是 $\frac19$」，两者指的是同一个事件，必须相等。若照原文读成 $\frac13$，这一问的结果会变成 $\frac16$ 而不是 $\frac1{18}$，与给出的答案直接冲突。
>
> 这个交叉检查本身就是本条最值得内化的技巧：同一个量用两条相互独立的路径各算一次，答案不等就说明中间有一处错了，而且错在哪一段从差值就能反推。本题给出的另一条核对线是补事件：进不了 $s_2$ 的概率是 $1-\frac19=\frac89$，它可以拆成 $\frac23$（第一步直接去 $s_1$ 或 $s_5$）加 $\frac29$（进了 $s_3$ 却从 $s_4$ 走掉，即 $\frac13\times\frac23$），三项刚好凑齐。这三条核对线彼此独立，任何一条对不上都必须回头查原始转移概率，而不是硬着头皮往下算。养成「用补事件再算一遍」的习惯，比背公式有用得多。
>
> 还有一步值得停下来看：为什么可以写成「进入 $s_2$ 的概率」乘「已知在 $s_2$ 时下一步离开的概率」这种乘积形式？因为马尔可夫性把「什么时候进来」和「进来之后干什么」解耦了：给定当前在 $s_2$，下一步离开的概率恒为 $1-p_{22}=\frac12$，与你是第几步进来的无关。这一步同时用到 time-homogeneous（时齐）与马尔可夫性两条性质；若转移概率随试验次数变化，这个乘积立刻失效，整段算法都要改。
>
> 最后补一个能替代死记的直觉：$s_3$ 的自环让等待变成 geometric distribution（几何分布），参数是离开概率 $\frac34$，期望停留 $\frac43$ 步。但「等多久」与「往哪走」是独立的——先在 $s_3$ 空转若干次，再按 $\frac13$ 对 $\frac23$ 的份额挑一条出边，所以 $P(A_k)$ 才能写成 $p_{03}$ 乘 $p_{33}^{\,k-2}$ 乘 $p_{32}$ 三个因子直接相乘。把「自环空转」与「真正跳走」分开处理，是所有带自环的链的统一手法；将来换成连续时间，同一个分解会以「指数分布的等待加上条件去向」的形式再现。
>
> **（d）** 该事件只可能在状态转移序列恰如下列时发生：
>
> ```math
> s_0 \longrightarrow s_3 \longrightarrow s_2 \longrightarrow s_1.
> ```
>
> 这是因为，要在第 3 次试验就首次进入 $s_1$，前三次转移必须一步不落、且中途不在任何状态停留，唯一能这样走通的路径就是 $s_0\to s_3\to s_2\to s_1$。于是，$P(\{\text{过程在第 3 次试验首次进入 } s_1\}) = p_{03}\cdot p_{32}\cdot p_{21}$：
>
> ```math
> p_{03}\cdot p_{32}\cdot p_{21} = \frac{1}{3}\cdot\frac{1}{4}\cdot\frac{1}{2} = \frac{1}{24}.
> ```
>
> **（e）** 要在第 $n$ 次试验后恰好处于 $s_3$，必须第一次试验就从 $s_0$ 转入 $s_3$，且此后连续 $n-1$ 次试验都停留在 $s_3$；停留 $n-1$ 次的概率正是 $\left(\frac{1}{4}\right)^{n-1}$。于是
>
> ```math
> P(\{\text{过程在第 } n \text{ 次试验后立即处于 } s_3\}) = P(\{\text{第一次试验转移到 } s_3 \text{ 且随后 } n-1 \text{ 次试验停留在 } s_3\}) = \frac{1}{3}\left(\frac{1}{4}\right)^{n-1}\qquad (n=1,2,3,\ldots)
> ```
>
> 这里 $n=1$ 对应「第一次试验就进入 $s_3$ 且随后零次停留」，即 $p_{33}^{\,0}=1$。
> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> $p_{33}^{\,0}=1$ 这个约定看着琐碎，其实是在替矩阵语言腾位置。把所有 $p_{ij}$ 排成一个矩阵 $P$，行是「现在」、列是「下一步」，则「$n$ 步之后从 $i$ 到 $j$」的概率就是 $P^n$ 的第 $(i,j)$ 个元素，这正是 Chapman–Kolmogorov equation（查普曼–科尔莫戈罗夫方程）：$(P^{m+n})_{ij}=\sum_k (P^m)_{ik}(P^n)_{kj}$。本行算出的 $\frac13\left(\frac14\right)^{n-1}$ 就是 $P^n$ 的 $(s_0,s_3)$ 元——只不过这个 $P$ 特殊到幂可以手算，你不必真的去乘矩阵。
>
> 这个方程和你已经会的 Floyd–Warshall 是同一副骨架。CLRS 里 $d_{ij}\leftarrow\min(d_{ij},d_{ik}+d_{kj})$ 的第三层循环干的事就是枚举中间点 $k$，写成矩阵形式是 $(D\odot D)_{ij}=\min_k(D_{ik}+D_{kj})$；把取最小再加换成取加再乘，就得到 $(P^2)_{ij}=\sum_k p_{ik}p_{kj}$，也就是「枚举中间点、把两段的概率相乘再相加」。同一个三层循环，换一套代数：一边算最短路，一边算路径概率总和。你在算法课背过的循环结构在这里换了名字重新出现，这不是巧合，而是两者都是同一个可结合乘法上的幂运算。
>
> 再接线性代数。$P$ 每行和为 1，这种矩阵叫 stochastic matrix（随机矩阵），于是必然有特征值 1：把全 1 列向量乘进去，每一行得到的仍是 1 的倍数，直接验证即可。stationary distribution（稳态分布）就是对应的左特征向量，也就是 $\pi P=\pi$ 的解——这仍然是求特征向量的老问题，只是矩阵不保证对称，所以左右特征向量必须分清。收敛速度由第二大特征值的模决定：本件里 $s_3$ 的自环是 $\frac14$，其余部分很快被吸收，所以 $P^n$ 迅速趋近一个每行相同的秩一矩阵；若把自环改成 $0.99$，链就要跑很久才能混匀。
>
> 为什么极限是秩一？因为状态 0 是唯一的吸收态，也就是唯一的闭类，所有质量最终都堆在它上面，$P^n$ 的每一行都趋向「第一列为 1、其余为 0」。这同时解释了有多个闭类时会怎样：若有两个吸收态，极限矩阵就不是秩一，而是每个闭类各占一块，最终落点依赖初始分布，「稳态唯一」随之失效。可见稳态唯一不是定理白送的，而是链的结构——irreducible（不可约）且 aperiodic（非周期）——挣来的。
>
> 再往前看，同一套 $P^n$ 结构后来长出三样很硬的东西。HMM（hidden Markov model，隐马尔可夫模型）把 state 藏起来、只让你看见观测，于是要反推最可能的隐藏路径，用的是 forward-backward（前向-后向）递推，本质仍是 $P^n$ 上的动态规划。Markov chain Monte Carlo（马尔可夫链蒙特卡洛，简称 MCMC）反着用：想从某个复杂分布采样，就造一条以它为稳态分布的链，跑长了近似就是在采样。PageRank（网页排序）把网页当 state、超链接当转移，用 damping（阻尼）保证链不可约且非周期，稳态分布就是排名分。
>
> 三者的共同点不是数学多高明，而是把「一次巨大的全局求和」换成「一次局部转移」——这正是第 1 条注讲的状态压缩。也正因为如此，它们的工程难点几乎全在「链要跑多久」而不是「极限存不存在」：存在性由特征值 1 保证，速度由第二大特征值的模决定。你已经有的谱知识在这里直接变成了工程上的等待时间，而这条从「一张表」到「一个特征向量」的链路，是本讲唯一需要真正带走的东西。
